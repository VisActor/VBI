# @visactor/vbi-react

React hooks for `@visactor/vbi`.

## Documentation

Run `pnpm --filter @visactor/vbi-react run g` to regenerate API documentation and
website section metadata.

Example pages are maintained directly in
`apps/website/docs/zh-CN/vbi-react/examples/`, including `index.md` and `_meta.json`.
This directory is their source of truth; generation does not copy or overwrite it.
