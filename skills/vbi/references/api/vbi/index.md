# VBI API

从 `packages/vbi/src/index.ts` 的公开导出生成，并递归收录签名引用的本地类型及子 Builder。私有、受保护和 `@internal` 成员不属于公开 API。声明保留 JSDoc、重载、泛型、可选参数和推导返回值；Zod DSL 类型展开为字段定义。

此处保留公开 API 的参考快照。接口变更时按对应包的公开 TypeScript 声明更新签名与关联类型。
