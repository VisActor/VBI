# 地图看板

用户需要地图时使用本篇，用地图、悬浮指标和空间动效呈现数据。

由 [Dashboard 看板入口](../../SKILL.md)按需加载，与 [visual-query](../visual-query/SKILL.md)共同使用。本篇组织地图场景与模板实践；查询、渲染和服务接入复用通用能力。

## 核心方法论：基于 Dashboard 模板构建

**先选模板、打通数据和交互，再调整布局与视觉。** 新建看板以已有完整模板为起点，阅读其 HTML、启动说明与相关实践，查看可运行页面的布局和交互。默认沿用已实现的页面骨架、查询入口、筛选范围、刷新与清理机制，按真实数据替换分析定义；不要先另起一套页面，再补查询与必要交互。修改已有页面时沿用其宿主与结构，选取对应模板机制补齐功能。

模板提供实现与质量基线，业务内容由任务决定。地域层级、指标、单位、报告时区、主题色和刷新节奏必须适配实际来源。超市字段、中国坐标、固定卡片数量、配色及动画参数仅是示例；没有相应数据时不伪造趋势、目标或实时事件。调整布局可以重排模块，但不能丢失已确定的核心分析和交互路径。

新建完整看板先完成这条可验证的主路径：**数据接入 → 范围筛选 → 地图与指标联动 → 趋势或适合数据的比较视图 → 明细下钻与返回 → 刷新及空错状态**。依赖不可用时明确记录未验证部分；功能未闭合前，不扩展新的装饰、布局选择器或分析面板。

## 构建阶段

1. **选型与运行。** 确认分析目标、来源、地域范围和展示终端，按上表选模板。优先复用已有接入，其余按[数据接入判断](../server-runtime/SKILL.md#数据接入判断)选择。定位字段、查询、地图、交互和清理入口，先验证页面加载与最小查询。
2. **分析与口径。** 明确一行数据代表什么、指标怎么算、哪些条件影响哪些视图；按 [地图接入](references/open-street-map.md)处理地域身份与坐标。先核对整体、一个地域，以及有时间字段时的一个时间范围，再组织页面。
3. **页面与交互。** 沿用模板模块，按 [布局](references/layout.md)和 [L-Card](references/L-card.md)安排主次；按 [控件与联动](references/open-street-map.md#控件与联动)区分定位、筛选和详情。一次调整一个模块，并核对主路径。
   指标深入分析按 [metric-analysis](../metric-analysis/SKILL.md)选择内容与动线，复用宿主分析面板；保持地图主屏简约，用户主动进入后再逐步展开。
4. **验收与交付。** 实际操作连续筛选、定位、下钻返回和刷新，核对地图、指标与明细的范围；检查空结果、未定位记录、地图失败与重试，以及桌面／窄屏遮挡。支持全球或底图切换时，再检查跨日期线定位、切换后筛选与视野是否保留。交付页面或项目目录、必要资源及启动说明。
