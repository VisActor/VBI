# 超市经营地图看板示例

本篇记录现有超市模板的经营分析与地图实现。新看板先按 [模板驱动流程](../../SKILL.md#构建阶段)和各主题实践完成业务适配；下文的中国层级、超市字段、默认范围、配色和动效参数仅描述本示例，不是通用要求。

按需查看：[运行](#数据接入与运行) · [指标与交互](#数据口径与交互) · [地图实现](#地图实现入口) · [省市联动](#省市联动) · [坐标来源](#坐标来源) · [二次分析](#分组结果的二次分析) · [代码结构](#布局与代码结构) · [验证](#验证)。

[超市经营模板](template-supermarket.html)沿用[地震地图示例](../template-earthquakes.html)的二维地图与悬浮面板结构，采用石墨灰底图与烟灰液态玻璃卡片，选中态、关键指标与本期趋势使用香槟金 `#d8b45c`；负数、下降比较项与亏损图形统一使用暖红色。主屏保留经营指标、客户与动销规模、地图联动、趋势、商品利润榜和实时订单；移除品牌栏及右侧两张卡片。客户、品类、地域、盈亏、交叉透视与交易明细统一放在右上角三点入口中。入口用 4.8 秒轻量循环高亮提示可点击，悬停、键盘聚焦或菜单展开时停止；减少动态效果偏好下不播放。

外层卡片、分析弹层和更多菜单共用半透明玻璃材质：14px 背景模糊、轻薄银白反光、细渐变边缘与柔和投影；主屏卡片的深色底层不透明度为 40%，让底图纹理透出，菜单和分析弹层保留更深底色保障阅读。内层指标卡只叠加轻薄反光，不重复模糊；成交额卡片使用薄金色反光。主屏、更多菜单、分析弹层、VChart 与 VTable 使用一致的中性色系，层级图使用压暗的多色调，保持标签可读。

卡片成交额、货币符号、正向同比环比与趋势读数统一使用柔和金色 `--accent-text: #dfc38b`。成交额卡片的底色、描边与内高光由主题变量混合透明色生成，避免单独硬编码亮黄；数字光晕保持轻微，负值仍用暖红。

桌面采用左侧嵌套指标、右侧宽幅地图，底部三张等高卡片；顶部操作浮于地图上方，概览上移到页面边缘。1200 px 以下折为两列并允许纵向滚动，700 px 以下单列。主屏与分析面板全部使用 VTable 表格；主屏预览最近 100 条，展开明细一次查询最多 10,000 条，原生虚拟滚动，无分页器。
常驻文字只保留标题、指标与单位、时间范围和必要署名。地图标题随筛选显示“全国经营分析”或“四川经营分析”，清除筛选后恢复全国；移除重复的地区/品类标签和配置导出入口。成交额精确值与指标公式放在悬停信息中；不重复呈现操作教学、统计口径段落或英文副标题。

## 数据接入与运行

MySQL 连接、启动命令与服务生命周期统一见 [server-runtime 的超市示例接入](../../../server-runtime/references/mysql.md#运行超市地图看板示例)。本篇维护超市业务指标、布局和交互，数据源配置由服务端管理。

## 加载与刷新

首次打开和整页刷新先显示同色系 loading。页面在隐藏但可测量的状态下完成取数、字体、排版和画布调整，再定位初始地图视野；等待地图样式、当前视野的底图瓦片与地名完成加载和渲染后，统一显示底图并淡出 loading，再以翻书式动效展开面板：左侧概览沿左边缘绕 Y 轴翻入，下方三张卡片沿底边绕 X 轴向上翻入。每张翻转 1600 ms，上一张结束后下一张再开始；页面就绪后概览延迟 380 ms，下方依次延迟 1980 / 3580 / 5180 ms，避开 loading 的 360 ms 淡出。CSS 用统一时长与卡片顺序计算延迟。翻转平滑减速至最终位置。只动画 transform 与 opacity，结束后释放变换；刷新不重复播放，减少动态效果时直接显示。以最终视野的 MapLibre `idle` 事件及 `loaded()`、`areTilesLoaded()` 为准，不能用固定延时、数据查询完成或地图首次 `load` 代替。首批数字直接显示真实值，后续数据变化继续使用数字动画。

自动刷新保留当前画面，不反复打断阅读。手动周期、商品榜、明细和清除筛选操作立即显示触发按钮 loading、受影响面板的顶部进度提示及查询状态；地图和原生图表点击显示面板反馈。快速请求也至少保留 240 ms 的反馈。查询结束或失败均清除 busy 状态，处理中避免重复提交。首次连接或地图加载失败显示错误与“重新加载”入口，依赖迟迟未就绪时在 25 秒后提供重试；失败或超时后保持错误状态，迟到的成功响应不会显示半成品页面，重新加载后再开始初始化。后台刷新失败仍保留上一次数据。减少动态效果偏好会关闭页面自定义过渡动画。

首屏并行读取连接信息与加载视图依赖，地图直接使用最终全国视野开始请求瓦片；布局变化时批量调整尺寸，仍以完整就绪作为显示条件。数字格式化器按精度复用。刷新时比较当前渲染输入，数据不变的趋势图、商品榜与订单表跳过重绘；订单表列配置保持不变时用 `setRecords()` 更新数据，同范围保留滚动位置，切换范围回到顶部。页面不可见时暂停自动查询，返回前台立即补一次更新；用户手动暂停后不会因切换前后台而自动恢复。

## 数据口径与交互

- 成交额：`SUM(sales)`；利润：`SUM(profit)`；售出商品：`SUM(amount)`。
- 连带件数：售出件数 / 去重订单数。比率分母无效时显示 `—`，保留负利润和负利润率。
- 成交订单：`COUNT(DISTINCT order_id)`；订单均额：成交额 / 订单数；利润率：利润 / 成交额。
- 折扣销售占比：`discount > 0` 的明细成交额 / 全部成交额；不是平均折扣率。
- 亏损明细损失：`-SUM(profit WHERE profit < 0)`。涉亏订单：这些明细按订单号去重；涉亏占比 = 涉亏订单 / 全部订单。同一订单整体仍可能盈利，不称为净亏损订单。
- 商品利润榜：按 `product_id` 汇总销售、利润和件数，名称取 `MAX(product_name)`。默认显示累计利润最低且小于零的 5 个商品，可切换累计利润最高且大于零的 5 个商品。不是将亏损明细单独汇总后冒充商品整体利润。
- 品类盈利在“更多 → 品类结构”中查看，利润率为该品类汇总利润 / 汇总销售额；支持子品类层级图和明细下钻。
- 明细：按 `id DESC` 展示最近 100 条商品记录，同时显示销售与利润，订单数与明细数不同。支持局部“仅亏损”过滤；点击商品榜仅筛选明细中的对应商品，其他经营卡片继续保留全局范围，可通过商品标签的关闭按钮返回。
- 页脚区分“取数时间”和当前范围“最新订单时间”，不把服务刷新当成新的成交。
- 默认今日，支持近 7 / 14 / 30 天、本周、本月、本季度、今年。滚动范围包含今日，起点为 N−1 天前零点，截止当前时刻；环比为前 N 天窗口的相同已过时长。北京时间由 MySQL 时钟校准；周一为周起点，月/季度/年从自然期初开始，截至当前时刻，查询使用 `[start, end)` 半开区间。今日按小时，周/月/季度按日，今年按月。
- 零成交时段补零，仅用于图表的时间轴完整性。边界分钟/小时只统计筛选范围内的明细。未发生时段不补未来数据。
- 不限定 `MOCK-`，统计所选时间内的全部订单，不等同于模拟器“本次运行累计”。历史 `DATE` 转换后的午夜记录不伪造时分秒。
- 地域筛选联动与省市导航见 [省市联动](#省市联动)；“更多”与展开明细继承省份和城市范围。
- 每轮完成后等待 4 秒刷新，无请求重叠；本期七个查询（含独立省份与城市聚合）与两个基期汇总组成一个 9 查询批次，共用一个只读事务快照；随后两个历史趋势查询使用第二个只读快照，两批共享固定的时间截止点。两个快照之间若有回填历史数据，可能短暂不一致，下一轮刷新恢复；不是跨批次的全局事务。超过 15 秒取消浏览器请求；数据库查询限制 4 秒，网络取消不代表已取消数据库执行。
- 主屏订单流由 VTable 绘制；主屏、明细与透视表均保留 VSeed 生成的默认 VTable appear 配置，不额外叠加整块容器滑动动画。同一筛选刷新保留滚动位置，切换筛选回到顶部。
- 概览、趋势峰值、地图金额和明细计数使用 800 ms 数字动画；VChart 图表使用原生 600 ms 更新动画。相同值不重播，连续更新从当前显示值继续。表格入场交给 VTable 原生动画；系统减少动态效果时关闭页面自定义动画。
- 页面暂停仅停止自动取数，不暂停订单模拟器。断线保留上次结果并显示错误；重启服务后点击页面刷新按钮重新建立会话。
- `DECIMAL` 在 MySQL 中完成汇总，图表接口转换为 JavaScript number；这是可视化展示，不承诺任意精度的财务账本运算。主要金额按两位小数展示；明细中非零且不足一分钱的值使用三位小数，与当前 `DECIMAL(18,3)` 数据精度一致，避免亏损误显为负零。

### 同比与环比

成交额、利润、利润率、订单数、客单价、售出件数、连带件数显示同比与环比。增长率 = `(本期 / 基期 - 1) × 100%`，仅在基期有订单且分母为正时计算；利润率显示百分点差 `pp`。基期不存在、为零或为负而不适合计算增幅时显示 `—`，不伪造增长；可悬停查看精确基期数值、起止范围。

- 环比：上日、上周、上月或上季度的相同已过时长；基期较短时最多比较到该期结束。这样日序对齐的趋势与指标使用完全相同的范围，不会跨入下一个月份。
- 同比：去年同期；周按 52 周前同一周几对齐。日/月/季度同样比较自期初起相同已过时长，并以基期结束为上限。
- 今年：截至去年同月同日同时刻，闰日钳制到有效日期。今年的环比与同比基期相同，因此只展示一次同比。
- 经营趋势支持销售/利润切换，显示本期、上期同期、去年同期三条原生 VSeed/VChart 曲线。按小时序、日序或月序对齐；基期完全无记录时不画虚假的零线，短基期结束后的点为 null。切换销售/利润使用已缓存的 VBI 查询结果，无额外数据库请求。

未提供真实目标、库存余额或实际履约状态，不生成目标达成率、缺货与履约告警。

### 更多分析与明细

六个分析模块共用一个工作区、查询取消、原生表格呈现和列定义。展示方案由模块固定，移除图形、指标、行列维度和视图选择器；用户直接阅读分析结果、选择明细下钻及刷新。分析查询、全量汇总、亏损汇总通过相同取消信号合并为同一只读快照。打开时固定时间截止点；切换模块保持范围，点击“刷新分析”更新截止点。关闭时取消浏览器请求并清理 busy 状态。

- **品类结构**：固定矩形树图，品类 → 子品类，面积表示销售额。右表显示销售额、利润、加权利润率、销售贡献和订单、件数。
- **客户分析**：成交客户数、期内复购率（至少 2 笔去重订单的成交客户占比）、户均消费、TOP 10 客户销售贡献；客户贡献 TOP 15 图及完整客户汇总表。期内复购不称为历史留存，源表没有注册与访问数据。客户/商品图使用 ID 区分实体，名称仅用于展示。
- **地域分析**：国家 → 大区 → 省份 → 城市，固定旭日图展示销售额结构，搭配城市盈利明细。`area` 是大区，不误称区县。城市数按国家/省/市组合去重。
- **盈亏分析**：净利润、盈利明细利润、亏损明细损失、净亏损商品数。默认呈现商品整体净利润为负的商品及亏损贡献 TOP 10，不再提供展示配置选择器。不能用亏损明细损失代替商品净亏损。
- **交叉透视**：固定大区 → 品类为行、客户类型为列，并列展示销售额与利润。VSeed 构建 VTable PivotTable，保留行列总计；不对跨品类去重订单数简单相加。上方订单数由独立全量去重查询提供。
- **交易明细**：订单时间、商品、成交金额、利润、件数、折扣、客户及类型、省市、品类、配送、订单号和实体 ID 等 19 列。按 ID 倒序，最多 10,000 条；固定首列，支持列排序、滚动、选区复制，不分页。主屏“展开明细”继承局部商品/亏损条件；品类、客户、地域、盈亏分析的表格单击数据行即进入对应交易明细，继承当前时间和地区等筛选；“返回汇总”回到原分析范围。表头点击仍用于排序，交叉透视和交易明细本身保留原生表格操作。

达到 10,000 条时显示上限提示，可缩小筛选范围。全量汇总指标不从截断表格估算；必须完整分组才能计算的期内复购率、客户集中度、亏损商品数和城市数在截断时显示 `—`。表格销售占比分母来自完整范围销售额，利润率和客单价按每组汇总计算。空数据、错误重试与关闭取消均保留明确状态。

## 图表实现边界

查询到呈现的链路、字段 ID 与实例复用按 [visual-query](../../../visual-query/SKILL.md)执行；批次、刷新与取消见 [共享组合指南](../../../visual-query/references/composition.md)。本节保留超市业务对应的图形与表格选择：

- 经营趋势：VBI `line` 查询本期与两组基期，呈现适配层按时间序对齐并增加比较字段，VSeed 生成 VChart 三期趋势图，复用实例 `updateSpec()`。
- 商品利润榜：VBI `bar`，利润编码至 `xAxis`、商品 ID 至 `yAxis`，名称、销售额和件数为提示字段；VSeed 生成横向条形图，点击图元下钻。空榜不向 VSeed 传空 dataset，也不展示上一轮图形。
- 经营指标：HTML 文本卡片，使用 VBI 聚合结果与同一批派生口径，不属于自绘图表。
- 地图：[地图接入](../../references/open-street-map.md)。
- 订单流及分析表：VBI 查询 → VSeed 表格规格 → VTable ListTable；公共适配器按实际 schema 与 Builder 聚合语义声明可见列，投影对应数据后交给 VSeed，统一列序、金额、比率与亏损格式。
- 层级与透视：保留 VBI 字段 ID，VSeed `hierarchy` / `row` / `column` 编码生成固定层级图与双指标透视表，不手绘布局或透视计算。

## 地图实现入口

| 入口                                                 | 当前职责                                              |
| ---------------------------------------------------- | ----------------------------------------------------- |
| `supermarketCityPoints`                              | 用省内地名索引解析中国城市的代表坐标。                |

## 省市联动

- 省份与城市分别通过 VBI 查询汇总，省份去重订单不从城市去重数相加。全国视图缩放低于 4.6 显示省份，放大后显示城市；选中省份时直接显示该省城市。当前没有国家概览层。
- 点击省市联动概览、趋势、商品榜与明细；选城市后保留同省其他点。“返回全省”清除城市；全国复位按此示例产品规则清除地域、商品和亏损筛选。“更多”和明细继承省市范围，标题使用当前地域。
- 仅使用行政父子关系，不做屏幕距离聚类，不把相邻城市合为匿名点。未匹配城市不回退到省会，仍计入经营汇总及地域明细。
- 自动刷新不 fit，相机仅在初始布局、主动选择与复位时调整；只有容器尺寸变化才 resize。

## 地图视觉与动效参数

- MapLibre GL 5.6.2；NASA Blue Marble 地形影像搭配 OpenFreeMap / OpenStreetMap 边界和地名。保留来源署名，CDN、瓦片和字体需要联网；业务地点在本地解析，不向外部地理编码服务发送订单或地名。
- 地图点大小表示销售额。点位为香槟金玻璃材质，亏损用暖红；选中增强描边。tooltip 显示销售额、利润、利润率和去重订单。当前没有层级／指标选择器、城市定位选择器、图例或每点行政代表位置提示。
- 当前时间、地域范围内最新 3 笔去重订单产生涟漪，同地点合并。订单按时间、明细 ID 降序；商品与亏损明细筛选不影响地图事件。未知地点不使用旧订单补位。
- 涟漪为 3.2 秒循环，两圈间隔 1.6 秒，扩散至 2.5 倍；新焦点 550ms 渐入，旧焦点保留扩散进度并在 1.1s 内淡出，退出中重入沿用进度。
- 飞线按这 3 笔订单由旧到新连接相邻落点，最多两条活动曲线，表示装饰性的订单接力，不表示配送路线。同地点不连线，未知地点不跨过连接。
- SVG 曲线端点由 MapLibre `project()` 计算，移动与 resize 同步投影。光尾 2.8 秒循环，飞线同样使用 550ms 渐入、1.1s 退出；相同订单对不重播。
- 缩放跨过阈值或点击省份时，清理上一层标记和飞线，当前层独占动效。地图暂停同时冻结光圈与光尾；减少动态效果时关闭装饰动效；离开页面释放节点和动画。

## 坐标来源

[data/china-locations.json](data/china-locations.json) 是中国省内地名 → WGS84 代表坐标的静态索引，共 6541 个别名。代表位置不是门店、客户或送货地址。

来源：[88250/city-geo](https://github.com/88250/city-geo)，Mulan PSL v2 许可证见 [LICENSE-city-geo.txt](data/LICENSE-city-geo.txt)。2026-10-13 获取的原始 `data.json` SHA-256：`b58b44590804554698eedcc3f0542c11b3fe8461b7aadd0e360a51be67004dcc`。

原始百度坐标通过 [coordtransform 2.1.2](https://github.com/wandergis/coordtransform) 的 `bd09togcj02` → `gcj02towgs84` 转为 WGS84，保留四位小数。MIT 许可证见 [LICENSE-coordtransform.txt](data/LICENSE-coordtransform.txt)；获取的 `index.js` SHA-256：`6037d92d149615c8557985ec5d025052dafda804cee8464b1e5ad7bf1915c89d`。这条转换链只适用于此来源，工具只在离线准备数据时使用。

预置索引仅去中国行政后缀，并保存全名与简写。市与同名县优先市级代表点；同优先级歧义不进入索引。2026-10-13 验收的 323 组省市名称中 285 组匹配，其余包含旧地名、乡镇名或省市组合不一致；未修改业务记录，未定位记录保留在经营统计与地域表中。

HTML 用空的 `<script type="application/json" id="map-locations" data-src="./data/china-locations.json"></script>` 声明资源。[通用 Runtime](../../../server-runtime/references/protocol.md#页面与资源注入) 相对于 HTML 读取 JSON、转义 `<` 并注入，页面从 `#map-locations` 解析索引；服务没有中国地图专属分支。启动方式见 [server-runtime 的超市示例接入](../../../server-runtime/references/mysql.md#运行超市地图看板示例)。

## 分组结果的二次分析

客户复购、TOP 10 贡献、净亏损商品数和成交城市数属于对分组结果的二次分析。模板将本轮完整结果作为临时 VQuery 数据源，仍由 VBI Builder 查询统计；结束或取消时释放连接器和数据集。达到 10,000 组上限时，不展示需要完整分组结果的派生指标。页面只计算比率、单位换算和视觉适配，不用数组聚合代替查询。

## 布局与代码结构

页面仍是单个 HTML，无前端构建步骤；交付完整的 [supermarket 项目目录](README.md)，其中包含服务入口、运行时、依赖清单和地图资源。样式按主题、布局、指标、图表、地图、加载、弹层与断点组织，同一个组件不再叠加旧版本规则。宽度至少 1200px 时，主容器固定为 `100dvh`，上、下两排使用可收缩网格轨道分配剩余高度，表格不会把页面撑高。小于 1200px 时转为内容驱动的两列布局并允许页面纵向滚动；700px 以下单列。较矮桌面使用紧凑间距，极端高度下概览内部可滚动访问全部指标。

CSS 是呈现尺寸的唯一来源；一个 ResizeObserver 同步地图、VChart 和 VTable 的容器尺寸，不再按 VTable 内容反向写入桌面容器高度。主屏与分析弹层共用 Builder 筛选入口；可见字段顺序由各视图指定；标题、宽度和特殊格式集中在 `columnPresentation`，源字段类型来自 context.schema，聚合结果类型由 Builder 的聚合语义确定。

表格数据由 `tableRecords` 一次投影到可见字段，仅在需要时计算利润率、客单价和销售占比，主屏后续刷新复用同一入口。`tableOptions` 负责 VSeed 配置及表格布局，`styleTableColumn` 集中处理列宽、对齐、负值颜色和格式化，避免数据转换与列样式交织。

维护模板时按以下边界定位代码：

- `business-metrics` 保存不依赖 DOM 的指标、时间窗口、地图层级及查询结果适配函数。`queryFieldIds()` 统一解析 VBI 字段 ID，`queryRows()` 将结果转换为业务别名，`queryFieldTypes()` 根据 schema 与聚合语义确定结果类型；图表和表格不再各自重复解析。
- `createChart()`、`addDimension()` 和 `applyFilters()` 负责调用公共 Builder API。公共经营聚合与省市聚合分别共用定义，筛选、排序、去重与日期分桶仍由 Builder 管理。
- `refresh()` 只编排请求：`configureQueries()` 设置本期与比较期范围，两批查询完成并通过过期响应检查后，由 `renderDashboard()` 更新视图。汇总值作为参数传给 `displaySummary()`，趋势结果与商品榜供交互复用；渲染输入签名仅用于跳过重复绘制，不缓存或替代实时查询结果。
- 主屏、地图、分析工作区的状态与生命周期分组声明。分析预设、列定义和原生 VChart / VTable 适配器各自集中维护；页面不额外引入框架或前端构建步骤。

- `summaryCards` 是主屏指标的唯一呈现定义，集中管理名称、精度、单位、比较项和分析入口；`displaySummary` 统一执行数值动画和同比环比更新。
- `buildQueries` 以命名对象执行并行 Builder 查询并传递取消信号；结果按 `summary`、`trend`、`details` 等名称读取，不依赖数组位置。
- `chartSpec`、`styleAxes` 统一主题与坐标轴样式；`productsSpec` 生成商品榜配置，`renderProducts` 统一处理空数据、更新与交互入口；`renderChart` 在同类图中更新实例，切换图表类型时先释放旧实例。没有重写 VSeed 的图形或透视能力。
- `selectRegion` 统一处理省市切换、返回全省与全国复位时的筛选清理、刷新和相机定位；具体入口只决定目标省市。
- `analysisMetricCards` 定义各分析视图的指标名称、值、单位与说明；`renderAnalysis` 负责渲染编排。视图配置中的 `tableOnly` 统一标识交易明细和交叉透视，控制图表区域与表格下钻入口。`pivotOptions`、`analysisChartSpec` 分别产生原生透视和分析图配置，`clearAnalysis` 统一清理关闭或空数据状态。

启动加载、自动刷新、手动 loading、取消与重试仍保留各自明确的状态边界。`waitForMinimum` 共用最短反馈时间的计算；`waitForInitialMap` 在完成或失败时通过 AbortController 清理 DOM 监听，并解除地图事件监听。模板无需额外前端框架或构建产物。

卡片入场共用 `card-flip` 关键帧，统一维护淡入和翻转。`--reveal-from` 配置翻转方向，`--reveal-duration` 和 `--reveal-order` 控制时长与顺序；左侧只覆盖方向和旋转原点。

## 验证

通用功能与交付按 [构建阶段](../../SKILL.md#构建阶段)中的验收要求检查。此示例另外验证省内匹配、未知地点、行政两层、各层独立去重汇总、相邻城市、筛选与相机 resize、涟漪及飞线交接清理。单国验收不能证明跨国同名、缺失层级或跨日期变更线已受支持。

服务端测试与数据源验收见 [server-runtime 的验证与交付](../../../server-runtime/SKILL.md#验证与交付)。修改模板后通过实际页面检查筛选、刷新、空数据、错误恢复和窄屏布局。首屏加载额外检查瓦片慢于数据、地图命中缓存、样式或瓦片失败，以及 25 秒超时后资源才返回：未全部就绪时保持 loading，失败后保持可重试错误，重试成功后才显示完整页面。

图表默认开启 VSeed/VChart 原生 tooltip 与可交互 legend；图例位于图表上方，条目较多时原生翻页。趋势图图例直接来自当前可用比较系列，无基期数据时不生成对应系列。弹窗中的图表和 VTable 提示挂载在 dialog 内，避免被浏览器顶层遮挡。
