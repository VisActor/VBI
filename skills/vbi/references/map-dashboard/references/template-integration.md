# 模板接入

新建地图看板时先读本篇，再按任务补读其他实践。模板入口见 [map-dashboard](../SKILL.md#模板选择)。目标是保留可运行的分析与交互骨架，逐项完成业务适配。

## 选择并检查起点

完整经营或地域分析优先使用 [超市项目](../templates/supermarket/README.md)，复制 HTML、启动入口、服务文件、依赖清单、锁文件和所需数据资源；配置本次任务的数据源。已有宿主应用时，将对应查询和交互机制接入宿主，不额外创建一套运行环境。只做地图表现时，可参考 [地震示例](../templates/example.html)的视觉与相机行为，查询流程仍按 [visual-query](../../visual-query/SKILL.md)完成。

阅读源码时先定位容器、查询定义、统一刷新、渲染实例和清理入口；查看运行页面的默认状态、一次筛选和一次下钻返回。没有数据源或依赖尚不可用时，可以先核对结构，但不能把源码检查当作已完成运行验收。

## 先保留哪些机制

| 模块           | 适配时保留                                               | 根据任务替换                                   |
| -------------- | -------------------------------------------------------- | ---------------------------------------------- |
| 页面外壳       | 地图可操作区域、概览与分析区、控件和明细入口。           | 模块顺序、主辅比例、文案、主题和断点。         |
| 数据接入       | Connector、schema 获取、查询 DSL 传输、错误反馈。        | 实际来源、认证配置、字段类型和接入边界映射。   |
| 分析定义       | Builder 查询、结果命名、字段 ID 映射、查询与渲染分离。   | 维度、度量、去重键、时间范围、排序和条数限制。 |
| 交互           | 筛选作用域、选中反馈、下钻返回、统一刷新及过期响应处理。 | 业务层级、可用筛选、明细字段和分析入口。       |
| 呈现与生命周期 | 图表实例更新、尺寸监听、空错状态、关闭与卸载清理。       | 图表编码、数字格式、颜色和适合任务的动效。     |

超市模板的 `createChart`、`configureQueries`、`buildQueries`、`renderDashboard` 和 `renderAnalysis` 可用来定位这些职责；函数名与参数不是新项目的接口标准。具体入口见 [示例代码结构](../templates/supermarket/GUIDE.md#布局与代码结构)。不要为了保留函数名而继续依赖无关的超市字段。

## 替换顺序与检查点

1. **接通来源。** 配置服务或内置数据，核对 schema。最小汇总查询和一条明细能返回正确类型；先处理连接或字段错误，再增加视图。
2. **替换分析。** 按 [数据分析流程](data-analysis.md)映射指标、地域和时间。先完成概览、一个地图层级、一张主图和明细；移除不适用的示例模块时，同时清理其查询、控件和状态。
3. **连接主路径。** 按 [交互范围](interaction.md#先定义作用域)实现全局筛选、地域选择、明细下钻与返回。对比筛选前后结果，确认标题、数字、图表和选择状态一致。
4. **适配呈现。** 调整 [布局](layout.md)与 [UI](design.md)，保留可读的数字、真实图表、表格交互和加载反馈。每次布局变化都检查地图 padding、图表尺寸与弹层。
5. **补齐运行状态。** 验证刷新、取消、空数据、请求失败、重试和关闭；再添加任务所需的比较期、更多分析或事件动效。

## 产物边界

带服务的看板交付完整项目，使用相对路径定位模板自带资源；连接配置留在服务端，不带出实际 `.env`。静态单文件交付按 [共享 HTML 接入](../../visual-query/references/html-integration.md)内置数据。启动、停止、端口和联网依赖随产物说明。

模板与业务示例直接保留最终成品，不为一次性复制或调整留下额外生成脚本。通用运行能力继续参考 [server-runtime](../../server-runtime/SKILL.md)；页面查询、聚合与图表生成继续复用通用库。
