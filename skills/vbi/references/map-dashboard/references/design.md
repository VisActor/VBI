# UI 设计

先沿用模板已经完整的阅读层级，再适配业务主题。地图承担空间信息，面板承担数字与证据；色彩、材质和动效应帮助区分这些层次。布局结构见 [布局](layout.md)。

## 稳定的阅读面

选择与任务、已有品牌及展示环境匹配的明暗主题。底图降低与业务无关的彩度和对比，让边界、业务点位及选中范围可辨；暗色地形不是所有地图的默认背景。

悬浮面板可使用克制的半透明底面、细边框和柔和阴影。必须在底图最亮、最暗和纹理最密处检查文字与曲线；必要时提高面板不透明度，而不是层层增加模糊和光晕。指标卡、菜单、分析弹层与表格共用一套材质，嵌套区域不重复堆叠高光。

## 颜色角色与设计变量

| 角色           | 作用                                     | 约束                                                   |
| -------------- | ---------------------------------------- | ------------------------------------------------------ |
| 背景与阅读面   | 分隔地图、卡片、弹层与内容层级。         | 保持稳定底色，图表透明背景也需要清楚的阅读面。         |
| 正文与次要文字 | 表达主值、名称、单位、范围和时间。       | 次要信息可以弱化，不能弱到难以辨认。                   |
| 主强调色       | 标记核心指标、当前系列、选中控件与地域。 | 默认一套强调角色，避免每张卡片各用一种装饰色。         |
| 语义色         | 表达告警、亏损、改善或恶化。             | 根据指标方向定义；增长不一定有利，负数不一定代表告警。 |
| 分类与比较色   | 区分实体、分组或比较期。                 | 固定身份对应固定颜色，结合图例、线型与文字。           |

用共享变量统一面板底色、边框、主辅文字、强调与状态色、字号、间距和圆角；图表配置消费同一组主题值。改变 DOM 颜色时同步更新图表 Spec，不用 Canvas 滤镜代替真实配置。具体 API 查 [可视化配置](../../vseed/SKILL.md)。

香槟金、烟灰玻璃或暖红属于超市示例的选择，不固定为新业务主题。先保留清晰层级，主题变化后核对所有选中态、负值、tooltip 与图例。

## 字号、数值与控件

主指标、辅助指标和分析指标分别定义字号 token，同层级共用；数字使用等宽数字特性，单位独立呈现。长金额优先合理缩写并提供精确值，不随每次查询结果改变字号。金额、比率和计数的语义见 [指标卡](metric-card.md)。

时间与地域选择、刷新、暂停、返回保持稳定位置。图标按钮提供可访问名称、可见焦点和选中状态；有明确业务动作的卡片应呈现可点击线索。少量次要分析可以进入“更多”，核心范围和恢复入口不要隐藏在深层菜单中。

## 动效与运行状态

- 首次加载完成查询和尺寸准备后再展示内容，初始数字直接显示实际值。页面隐藏准备时，图表容器仍需可测量。
- 后续同范围更新可使用数字插值和渲染器原生过渡；重复数据不反复播放入场，不用整屏闪烁表达刷新。
- 用户触发筛选时立即给出控件或受影响面板的反馈，完成与失败都结束 busy 状态；后台刷新保留阅读位置，显示取数时间与更新状态。
- 地图涟漪或飞线必须有事件或关系依据，语义与清理规则见 [地图指南](map-guide.md#实时事件与动效生命周期)。静态分析无需制造“实时”动效。
- 减少动态效果时直接呈现最终数字与图表状态，关闭装饰动画；键盘与触屏无需悬停也能完成核心操作。

底图不可用、业务数据为空和业务查询失败使用不同提示。地图失败不阻塞已有经营视图；查询失败保留旧数据时标明旧范围和时间，不把旧图表当作新筛选结果。

最终页面使用业务名称、指标和操作语言。技术名称仅用于实现和必要的运行说明，保留地图、数据与第三方资源要求的署名。验收见 [视觉与运行检查](visual-acceptance.md#视觉与运行检查)。
