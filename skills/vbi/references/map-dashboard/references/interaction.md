# 筛选与下钻

沿用模板的统一筛选和刷新入口，在绑定点击前先定义作用域。Builder 条件管理、查询复用与状态恢复见 [共享组合流程](../../visual-query/references/composition.md#筛选作用域与配置恢复)；本篇补充地图看板的操作关系。

## 先定义作用域

为每个控件写清“改变什么、更新哪些视图、保留哪些状态”。下表是完整看板的常见起点，按业务调整并在界面表达范围。

| 交互               | 常见影响范围                                     | 保留的状态                                               |
| ------------------ | ------------------------------------------------ | -------------------------------------------------------- |
| 时间、全局业务筛选 | 范围汇总、地域、趋势、排行、明细及对应比较查询。 | 合法的地域路径、布局与相机；范围失效时明确清理相关选择。 |
| 地域选择           | 当前地域范围的指标、主分析和明细。               | 时间与无关业务筛选。                                     |
| 单张卡片或排行条件 | 该模块与明确声明的下游明细。                     | 其他模块的全局口径。                                     |
| 悬停查看           | 当前图表或声明联动的临时读数。                   | 原筛选与范围汇总；退出后恢复。                           |
| 平移、缩放、配色   | 视野、呈现层级或主题。                           | 业务范围；查询语义未变时复用结果。                       |
| 明细下钻           | 当前分析范围叠加所选实体或分组条件。             | 可返回的上一级分析状态。                                 |

全局与局部条件同时存在时，通过条件 ID 或分组维护各自部分。清除一个控件只移除它拥有的条件，不因方便调用 `clear()` 丢掉恢复配置或其他控件条件。

## 筛选器与反馈

将高频时间和地域范围放在稳定可见位置，已选业务条件以标签或清晰控件状态表达。选项来自任务配置或数据查询，不能复制模板中实际不存在的业务类别。大量选项可搜索；少量选项可平铺，不为所有筛选增加折叠菜单。

交互后统一更新分析状态、Builder 条件和受影响查询。立即显示 loading 或 busy 反馈，完成后同步标题、范围、卡片、图表与控件状态；失败后保留可恢复的状态与重试入口。快速连续操作只展示最后一次有效范围，不能让旧请求覆盖新选择。

“清除地域”“返回上级”和“全部重置”应有不同含义。只有明确的全部重置才清除所有业务条件；默认值按本任务定义，不照搬模板的今日或某个国家。

## 地图导航

业务选区与地图显示层级分别管理。点击地域建立或更新选择路径，返回上级只去掉对应子级。显示名称与查询键分开：查询用稳定 ID 或完整父级路径，标题显示用户能理解的名称。

缩放可切换可见层级，通常不改变分析范围；平移通常不重算经营指标。只有任务明确采用视口分析时才将当前视野作为条件，并提供可见提示。点击选区可调整相机，后台刷新保持相机。完整层级和坐标规则见 [地图指南](map-guide.md#聚合筛选与视图层级)。

## 下钻与返回

1. **建立上下文。** 从卡片、图元或表格行读取稳定实体键，继承当前时间、地域和业务范围；记录上一级模块、所选项与阅读位置。
2. **打开分析。** 复用模板的弹层或详情区，显示标题、范围及返回入口。所需明细、汇总和图表按各自口径查询，不能用有限明细估算总计。
3. **继续细化。** 类别 → 子类别或地域 → 子地域仅在真实层级存在时提供。实体维度已到末级时进入记录明细，不制造空层级。
4. **返回与关闭。** 返回恢复上一级条件和展示状态；若数据已经过期，按原范围重新查询。关闭取消请求、释放临时图表和监听，将焦点交回触发入口。

表头排序、文本选区、复制与表格滚动继续使用原生能力，不把这些动作都解释为行下钻。只有数据行或明确入口触发下钻。弹层 tooltip 保持可见，Escape 和关闭按钮均能退出。

## 刷新与暂停

自动刷新沿用模板的单一调度入口，上一轮完成后再安排下一轮；频率由来源更新节奏和查询成本确定。手动刷新立即反馈，明确更新当前分析还是整页。分页、滚动、相机和有效选择在同范围刷新后尽量保留。

下钻视图可固定打开时的截止点并提供刷新，也可随主屏更新；选择一种明确策略并同步显示时间，避免标题范围与内容错位。暂停取数与暂停地图动效语义独立，前者不会停止上游系统产生数据。

## 检查点

验证全局筛选、地域往返、局部筛选、下钻再返回、关闭中取消、快速切换和失败重试；核对每次作用范围与保留状态。键盘、触屏和减少动态效果下均能完成主路径，详见 [验收清单](visual-acceptance.md#交互主路径)。
