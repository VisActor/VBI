# 指标卡

指标卡回答当前范围的核心结果，并提供进一步分析入口。沿用模板的主辅层级和统一数值更新，业务指标按 [数据分析流程](data-analysis.md)重新定义。

## 内容与层级

| 层级     | 内容                                   | 呈现方式                                             |
| -------- | -------------------------------------- | ---------------------------------------------------- |
| 主指标   | 当前任务最重要的规模或结果。           | 占据概览视觉中心，数值与单位清楚，必要时附基期比较。 |
| 辅助指标 | 解释主结果的质量、效率、规模或风险。   | 统一字号与格式，成组排列，避免所有数字都争夺重点。   |
| 分析读数 | 当前地域、图表悬停或下钻对象的局部值。 | 明确范围，结束局部查看后恢复对应汇总。               |

一张卡片至少表达名称、值与单位；范围可以由概览区统一说明。比较期、口径和精确值通过次要文本、聚焦提示或分析入口提供，不在每张卡片重复长段说明。卡片数量由问题决定，不保留与数据无关的模板占位项。

## 口径与显示

基础数值来自查询结果，不能从屏幕上的点、排行或有限明细重算。金额、数量、实体数、比率各用适当格式；单位与币种由来源确认，不给无币种数据擅自加货币符号。

- 比率先聚合分子与分母，再按已定义公式相除；跨地域不平均局部比率。
- 去重数依赖业务 ID，主指标与子区域合计不一定相等；不要强行修成“加总正确”。
- `0`、缺失、加载中与失败分别呈现。仅在来源完整且指标语义允许时把无记录解释为零；未知值显示 `—` 或明确状态。
- 保留负值和有意义的小数。小数位与缩写规则在同类卡片间一致，较小负值不能格式化成看似正常的零。

## 比较与状态

比较必须使用相同业务范围、可比时间长度和明确基期。时间对齐见 [趋势图](trend.md#比较期)。

| 类型           | 常见表达                                             | 不可比较时                                                                 |
| -------------- | ---------------------------------------------------- | -------------------------------------------------------------------------- |
| 总量的相对变化 | 在口径允许且基期为正时，`(本期 / 基期 - 1) × 100%`。 | 基期为零、负数或缺失时，不机械显示无限增长；按业务改用绝对差或显示不可比。 |
| 比率的差异     | 本期比率减基期比率，以百分点表示。                   | 任一分母无效或范围不可比时显示缺省状态。                                   |
| 目标达成       | 实际值与真实目标比较，目标范围和单位相同。           | 没有目标数据时不生成进度或完成率。                                         |

上升、下降与业务好坏分开定义。成本上升可能不利，负增长也可能代表风险下降；方向未知时使用中性比较色。颜色同时配合符号或文字，不能成为唯一状态信息。

## 更新与联动

用一份指标呈现定义集中管理显示名、精度、单位、比较项及分析入口。主屏、弹层和 tooltip 复用相同格式规则，避免同一指标出现不同口径。首批数字直接显示查询结果；后续变化可从当前显示值平滑过渡到目标值，同值不重播，减少动态效果时立即更新。

主图悬停若联动指标卡，应同时更新临时范围说明；退出时恢复当前筛选范围的汇总。局部查看不覆盖全局指标定义或下一轮查询条件。

点击卡片进入相关分析时继承当前时间、地域与业务范围，标题说明要查看的对象，支持返回。没有分析动作的卡片不制造可点击外观。辅助迷你图如有必要，使用同一查询结果经 VSeed 和渲染器生成，不以 CSS 图形代替实际数据。

验收重点：数字与源查询一致，比较基期正确，零值与未知可区分，更新不改变字号或撑开布局，卡片下钻与返回保持范围。整体路径见 [验收清单](visual-acceptance.md)。
