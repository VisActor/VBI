# 趋势图

趋势用于解释当前业务范围随时间的变化。沿用模板的主趋势容器、指标切换、原生提示与实例更新；根据数据重新选择时间字段、粒度和比较方式。

## 时间与查询

先确认时间代表事件发生、业务完成还是快照采集，并固定报告时区。过滤边界和分桶使用同一口径；一轮刷新共享截止点，常用 `[start, end)` 避免相邻窗口重复，但具体边界需与源数据及查询能力一致。

粒度根据分析跨度、数据频率和可读性选择，短时监测可以按分钟或小时，长期观察可以按日、周或月。不把模板的“今日按小时”或固定刷新频率当作所有场景规则。没有可信时间字段时改用分布或类别比较。

时间分桶、聚合、排序和峰值查询由 Builder 描述，调用 `buildVSeed()` 得到结果；VSeed 生成配置，再由 VChart 渲染。字段 ID、映射与复用见 [查询与渲染](../../visual-query/references/query-and-render.md)。不要从整表数组重新聚合趋势或手绘折线。

## 缺失、零值与未完成时间段

| 数据含义                       | 呈现规则                                       |
| ------------------------------ | ---------------------------------------------- |
| 已确认来源完整，该时段没有事件 | 对事件数、销售量等适用指标可补零，说明其语义。 |
| 采集缺失、延迟或覆盖未知       | 保留缺口或未知标记，不能补零制造骤降。         |
| 当前尚未结束的时段             | 标明部分时段；同比环比按同等已过时长比较。     |
| 未来时间或不存在的比较窗口     | 不补未来数据，不延伸基期曲线。                 |

展示层可对齐时间桶与比较系列，但不重新聚合事实。补零只完善已确认完整范围的时间轴，不把快照、温度等测量值缺失解释为零。

## 比较期

同比、环比或目标线只有来源与任务需要时才加入。各查询共享地域、类别等业务条件，时间窗口分别计算；图例与 tooltip 表达实际日期和比较角色。

- 完整自然周期可比较完整基期；当前未结束周期按相同已过长度对齐。周起点、闰日、夏令时及不同月长按报告日历处理，不简单减去固定毫秒数冒充所有日历周期。
- 叠加比较按小时序、日序或月序等相对位置对齐，同时保留各点原始时间标签。基期较短时不越界读取下一周期。
- 基期没有可比记录时省略该系列或显示缺失状态，不生成一条虚假的零线；卡片比较也采用同一可用性判断。
- 当前期与比较期使用稳定的颜色、明暗或线型，并保留图例。比较多到难以阅读时减少默认系列或提供明确选择。

## 图形与交互

折线适合连续变化，柱图适合离散时段量；平滑曲线只有在不扭曲业务含义时使用，不能跨缺口补造波动。面积填充保持克制，负值保留真实方向和必要的零基线。不同单位优先切换指标或拆图；需要双轴时明确单位和关系，不让尺度变化暗示不存在的关联。

tooltip 提供时间、值、单位与可比系列，图例使用渲染器原生能力。指标切换仅在已有 seed 包含所需字段且范围相同时复用缓存；更换粒度、时间或筛选才重新查询。悬停若联动指标卡，退出后恢复范围汇总；点击下钻的范围按 [交互](interaction.md)明确声明。

同类图使用现有实例更新 Spec，改变图表类型时正确释放旧实例；不要在每次刷新时重建画布和订阅。ResizeObserver 按容器尺寸调整图表，后台刷新保留用户正在查看的范围与状态。

## 检查点

核对时间边界、跨日与跨月、当前部分周期、无基期、缺失时段、零值和负值。只有可加且完整覆盖的同口径分桶才应与总计相等；跨时段去重数、快照或比率不能直接相加。切换指标不应改变全局筛选，刷新不应增加重复实例或事件订阅。
