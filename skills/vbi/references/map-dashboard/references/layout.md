# 布局

从已选模板的模块关系开始调整。先给地图与核心分析留足空间，再安排次要信息；模块数与比例由任务决定。代码接入见 [模板接入](template-integration.md)，视觉样式见 [UI 设计](design.md)。

## 阅读层级

| 区域       | 首先回答                             | 布局要求                                                   |
| ---------- | ------------------------------------ | ---------------------------------------------------------- |
| 范围与操作 | 现在看哪个时间、地域和业务范围？     | 时间、已选范围、刷新状态有固定位置；控制项不压住关键地域。 |
| 地图主区   | 业务分布在哪里，哪里值得查看？       | 保留连续、可操作的地理视野，选中地域与标题对应。           |
| 概览区     | 当前范围的规模、质量和效率怎样？     | 一个主指标带动辅助指标，同层级字号与间距一致。             |
| 分析区     | 随时间如何变化，哪些对象贡献或异常？ | 主趋势获得足够横向空间，排行与构成作为辅助证据。           |
| 明细与下钻 | 汇总由哪些事实构成？                 | 主屏提供入口或摘要，展开后保留当前范围与返回路径。         |

完整看板通常保留地图、概览、主分析与明细。没有可信时间字段时，用分布或比较视图替换趋势，并说明适用范围；不要为了填满区域虚构时间轴。

## 沿用模板骨架

默认从超市项目的“悬浮概览＋地图主区＋底部分析”起步。根据阅读任务做有边界的变化：

| 任务               | 可以调整                                 | 仍需保留                               |
| ------------------ | ---------------------------------------- | -------------------------------------- |
| 地域分布与经营概览 | 调整侧边概览宽度、主趋势与明细比例。     | 地图选区对概览、趋势和明细的联动。     |
| 实时事件监测       | 放大地图与事件列表，缩减不相关的排行。   | 事件定位、时间与来源、暂停及查看明细。 |
| 趋势驱动的地域比较 | 增加趋势宽度或高度，将次要分析移入弹层。 | 地域范围显示、地图选择入口和返回路径。 |

调整模块位置不改变其筛选作用域。若更换图表类型，要同步确认字段、编码与交互仍能表达原分析问题；只换标题和颜色不能完成业务适配。

## 地图与悬浮面板

桌面上可让地图铺满外壳，面板悬浮其上；相机 padding 应扣除真实遮挡区域。初始布局稳定、用户选区或主动复位时调整视野，自动刷新不重新 fit。地图控件、署名和点位提示不能被面板覆盖。

装饰覆盖层使用 `pointer-events: none`，实际面板和控件恢复可交互。地图容器、浮层、tooltip、菜单和弹窗明确分层；弹窗内图表的提示挂载到弹窗可见层，避免落在顶层对话框背后。

## 尺寸与响应式

- 宽屏若采用一屏模式，可用 `100dvh` 外壳与可收缩网格分配空间；图表和表格容器设置合理最小尺寸及 `min-height: 0`。内容不适合一屏时允许滚动，不把所有区域压扁。
- 断点根据内容是否拥挤决定。中屏可改两列，窄屏改纵向阅读，地图有独立高度，范围与核心指标优先可见；不要简单缩放整个桌面画布。
- 表格长内容在自己的区域内滚动。布局尺寸由 CSS 决定，避免用表格内容高度反推外壳，再触发无限 resize。
- 使用容器尺寸监听统一更新地图、VChart 和 VTable；隐藏弹层在打开后获得有效尺寸再渲染。数字变化不应触发地图重定位。

需要保存或恢复布局时按 [共享页面组合](../../visual-query/references/composition.md#资源关系与布局)使用 Dashboard DSL；临时悬浮、焦点与滚动仍由页面管理。

## 检查点

在目标宽屏、较矮桌面与窄屏检查：地图仍可点击和平移，关键地域处于可见范围，指标与图表标签完整，筛选可操作，明细可滚动，弹窗可关闭。完整动作按 [验收清单](visual-acceptance.md)执行。
