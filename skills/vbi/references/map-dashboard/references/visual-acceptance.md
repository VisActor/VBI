# 验收与交付

用于基于模板生成或修改的地图看板。先核对已选模板和本任务的功能基线，再检查业务适配与视觉；不能用一张看似完整的截图代替真实查询和交互。通用数据与渲染检查见 [visual-query](../../visual-query/SKILL.md#验证与交付)。

## 核心功能检查

| 检查       | 通过条件                                                                           |
| ---------- | ---------------------------------------------------------------------------------- |
| 启动与来源 | 按交付说明能启动并打开正确页面，schema 与实际来源一致，地图资源可解析。            |
| 范围汇总   | 整体、一个地域和一个时间窗口的指标可核对，去重、分母、单位与时间边界正确。         |
| 地域呈现   | 选中地域与标题一致，点位或边界身份正确，未定位记录仍留在业务汇总中。               |
| 趋势或比较 | 图表来自真实查询，粒度、排序、空值与基期正确；不具备时间数据时提供适当的替代分析。 |
| 明细与下钻 | 明细继承应有范围，可进入、返回和关闭；上限明确，不从截断行数推断总计。             |
| 刷新与状态 | 首次加载、主动刷新、后台更新、空数据和失败重试均有明确结果。                       |

未通过的核心功能先修复或说明具体数据／环境缺口，不能通过删除该入口、填入示例数字或添加装饰掩盖。

## 交互主路径

在实际页面依次验证，下列地域层级和筛选项按任务已有能力选择：

1. 从默认范围切换时间或业务条件，确认指标、地图、主分析、明细和比较期同步到声明范围。
2. 选择地域，再进入实际存在的下级，返回上级。检查地域键和标题，不丢失无关业务条件。
3. 设置局部卡片或排行筛选，确认只更新声明的下游视图；清除局部条件后恢复原范围。
4. 打开指标、图元或表格行的分析入口，继续查看明细，再返回和关闭；范围、阅读位置和焦点可恢复。
5. 快速连续筛选、刷新中关闭弹层、暂停再恢复。旧响应不覆盖新状态，没有重复请求循环、图表或地图图元累积。

额外核对零值、负值、无比较期、缺失坐标、重复实体和查询截断。跨国、跨日期变更线或缺失中间行政层级只在任务涉及时单独验收；中国示例不能证明其他地域已经适配。

## 视觉与运行检查

- 对照所选模板查看默认、筛选后和下钻状态：主次清楚，必要模块与交互仍完整，业务数据替换后没有残留无关字段或文案。
- 检查目标宽屏、较矮桌面和窄屏：地图能操作，面板不遮住关键范围，数字、坐标轴与图例可读，表格可滚动，弹窗可退出。
- 检查键盘焦点、触屏入口和减少动态效果。tooltip 不被弹层遮挡，装饰层不抢点击，状态不只靠颜色表达。
- 在真实浏览器查看控制台与失败请求。分别检查业务接口失败、地图或字体加载失败、空结果；重试后能恢复，旧数据有清楚的范围和时间。
- 同范围刷新不抢相机、不重置阅读位置、不反复播放入场；离开页面或关闭分析后取消请求、计时器与事件，释放临时数据和实例。

## 交付

带服务的页面提供完整项目目录、所需静态资源、依赖清单与锁文件、环境配置示例及启动／停止说明；不包含实际凭据。静态单文件交付遵循 [HTML 接入](../../visual-query/references/html-integration.md)。保留地图与数据来源署名，说明前端 CDN、瓦片或字体的联网需求。

交付说明记录实际验证过的数据范围、操作和运行方式；环境阻塞或尚未验证的部分如实列明。示例是可直接使用的最终产物，不需要附带一次性生成过程。
