# 通用地图指南

生成或修改带地图的大屏时阅读本篇。适用于单国、跨国，以及国家／省级行政区／城市的地域分析；“省级”是分析层级，不要求数据源使用“省”这个名称。具体国家、业务指标、坐标资源与视觉参数由任务决定。页面空间组织见 [布局](layout.md)，跨视图作用域与下钻见 [筛选与下钻](interaction.md)。

本篇沉淀当前实现中可复用的规则，不代表现有超市 HTML 已支持多国。维护该模板时再读 [超市示例](../templates/supermarket/GUIDE.md#地图实现入口)，不要直接把其中的中国地名规则、坐标表和缩放值复制到其他数据源。

## 接入与职责边界

- 地域查询与跨视图筛选遵循 [visual-query](../../visual-query/SKILL.md)；本篇补充地域身份、层级和地图呈现。坐标投影、相机与地理动效由地图集成层管理。
- 优先复用 VSeed 支持的图表。需要地理底图、相机或地理飞线而所用版本不支持时，交给 MapLibre 等地图引擎。引擎负责底图、投影、缩放、平移和地理坐标定位，业务浮层不要另写投影公式。
- 数据层提供行政层级与业务汇总；地理适配层将地域标识解析成位置或边界；渲染层按稳定标识更新图元。适配层不重新决定业务聚合或筛选口径。
- 选择覆盖目标区域、语言和缩放范围的底图，保留署名。确认数据坐标系与底图匹配、网络环境能加载瓦片和字体；地图资源加载失败不应阻断其他经营卡片。

## 地域标识与层级映射

先核对数据字段和真实父子关系，再选择可显示层级。以下是逻辑角色，映射到源字段即可，不要求新建固定字段或额外配置框架：

| 角色             | 用法                                                                       |
| ---------------- | -------------------------------------------------------------------------- |
| 国家标识与显示名 | 标识优先使用源数据的稳定代码；可采用统一国家代码。显示名与语言独立于标识。 |
| 行政区标识与父级 | 将州、省、地区等映射到实际分析层级，保留国家及完整父级关系。               |
| 城市标识与父级   | 优先稳定城市代码；只有名称时，至少使用国家＋行政区路径＋城市组成键。       |
| 位置或边界       | 经纬度／几何、坐标系、来源，以及实际位置或行政代表位置的含义。             |
| 业务事实与事件   | 指标值、事实粒度、事件 ID 和发生时间；与地域标识关联。                     |

- 同名城市、同名行政区不能跨国家或父级合并。键应包含层级和父级路径，或使用全局唯一地域 ID；采用无歧义的元组序列化，避免简单分隔符拼接造成碰撞。
- 标签、别名、翻译与行政后缀用于显示或查找，不能覆盖业务原值。别名归一化按国家和来源执行，不对所有地区统一“去省／市后缀”，也不通过展示文本判断国家。
- 国家／省级／城市是常见路径，不强制三层齐全。城市国家、没有省级字段或存在多级行政区时，使用可信的实际父子关系，允许跳过缺失层；不要伪造行政区或把未知城市归到首都、省会。
- 单国任务可以直接从省级或城市开始；跨国任务可增加国家概览。默认范围来自用户任务与数据，不预设某一国家、经纬度范围、语言或时区。

## 聚合、筛选与视图层级

行政地域分析优先按行政父子关系聚合：城市 → 对应行政区 → 对应国家。相邻城市即使屏幕上重叠，也仍是独立业务实体；不要把它们变成没有行政含义的聚合点。只有任务明确需要大量门店、设备等实际点位的空间聚类时，才单独采用距离聚类。

- 各层从原始事实按完整地域键独立汇总；可加指标在确认无重复后可逐层相加。去重客户／订单数不能累加子层结果；利润率、客单价等从该层分子与分母重新计算，不能平均子层比率。
- 先定事实粒度和地域归属。一个订单跨多个地区时，明确按订单、履约单或明细分析；不要用 `MAX(城市)` 随意选一个位置冒充整单归属。
- 汇总、比较期和事件查询使用一致的时间与业务范围。完整聚合后再排序或截断；地图范围内的缺失坐标不从经营指标中扣掉，不把截断结果包装成完整区域统计。
- 跨时区业务先确定统一报告时区或各地本地日口径，查询与标签保持一致；事件次序使用可比较的时间戳。不要从国家显示名推断时区，也不沿用示例固定的北京时间。
- 将业务选择范围 `selectedScope` 与当前可视层级 `displayLevel` 分开。缩放改变呈现粒度，不隐式修改业务筛选；平移也不自动按视口重算指标，除非产品明确采用“当前视野分析”。
- `displayLevel` 由可用层级、选择范围、缩放及可读性决定。阈值根据区域大小、点密度和容器校准；可使用不同的进入／退出阈值减少边界抖动。不要把某个国家上的缩放数值当作全球规则。
- 点击地域通过 Builder 联动卡片、图表和明细，标题使用当前地域显示名。返回父级只清除相应子级选择；回到初始范围的重置规则与产品其余筛选一致，不擅自清除无关业务条件。
- 初始定位、主动选择地域或复位时调整视野；自动刷新保留用户相机位置。全球范围、跨日期变更线、离岛或不连续区域的范围计算交给支持这些情况的地图引擎，不简单对经度取最小最大值。

## 坐标与资源

优先使用经过确认的业务经纬度或可靠的行政边界／代表点；只有地名时，在国家与父级限定的索引内解析。歧义、缺失、越界或无法确认坐标系的记录不猜测定位，保留其统计与明细。根据任务提供未定位清单或排查入口，不在每个点上反复加说明。

- 显式核对经纬顺序、有限数值、有效范围及坐标系。WGS84、GCJ-02、BD-09 等转换按来源和目标执行，不对全球数据套用某一国家的转换，也不重复转换已经处理的数据。坐标合法不等于地点正确，还需复核行政归属。
- 明确点位语义：行政区域代表位置可用于地域汇总，不可当作门店、客户地址或物流起终点；源数据若有实际坐标，不用城市代表点覆盖它。
- 本地静态索引按稳定地域键组织，随模板保留数据成品、来源、版本、许可证与坐标处理说明；更新时核对覆盖范围、歧义和坐标系，边界版本与统计地域版本应能对应。
- 地图 JSON 由 HTML 自己声明，例如 `<script type="application/json" id="map-locations" data-src="./data/geo-locations.json"></script>`；路径相对于 HTML。使用共享 server-runtime 时，按 [页面与资源注入](../../server-runtime/references/protocol.md#页面与资源注入) 读取。服务不硬编码国家、资源路径或地理编码逻辑。
- 瓦片加载与业务地理编码是不同数据流。优先复用已有坐标或离线索引；采用外部地理编码服务前核对接入、许可和数据传输范围，不在刷新循环里逐条发送业务地址。

## 渲染、布局与交互

- 一个地域键对应一个图元，按键增量更新坐标、值和状态；删除时释放节点、动画与事件。相同数据不重建整张地图。
- Marker 的定位 transform 由地图引擎管理。尺寸、悬浮与涟漪放在子元素上，不覆盖父节点的投影变换；飞线端点使用同一引擎的 `project()`，随 move、zoom、resize 同步更新。
- 图元尺寸、颜色、tooltip 与图例来自明确的指标语义；同屏保持一致。玻璃材质、光晕和强调色用于层次与焦点，不让所有点同时高亮。标签优先选中项、重点项和足够空间中的项目。
- 装饰层不拦截地图手势或点选；交互点保留地域可访问名称、选中态、键盘操作和悬停／聚焦提示。不要额外叠加难以理解的技术说明 tooltip。
- 悬浮卡片下方仍保留完整地图画布，使用真实可见区域计算相机 padding。布局稳定后再 fit；只在实际尺寸变化时 resize，避免数字更新或动画触发布局循环。
- 点位规模增大时使用地图引擎的批量图层与命中能力；少量 DOM Marker、少量 SVG 飞线可保持实现简单，不把逐点 DOM 方案当作所有数据量的默认。

## 实时事件与动效生命周期

先决定事件含义、唯一 ID、时间范围和焦点数量 N。按事件去重，再按发生时间及稳定次序取最新 N 个；不要按商品明细数、销售排名或请求完成时间冒充新事件。同地点合并视觉提示，缺失位置不使用更旧事件补足数量。

涟漪与飞线共享当前 `displayLevel`、事件集合和位置解析。事件可以映射到城市，也可以映射到它所属的行政区或国家；同一时刻只呈现当前层级的动效，子级出现时不继续播放父级动效。

| 场景                         | 更新规则                                                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 同层级、同范围，新事件到达   | 新动效渐入；旧动效保留运动进度并淡出，完成后移除。                                                                           |
| 相同事件再次返回             | 复用图元和时间线，不重新播放。                                                                                               |
| 退出中的事件重新进入焦点集合 | 取消退出并从当前状态恢复，避免闪跳。                                                                                         |
| 国家／行政区／城市层级切换   | 清理上一层标记、飞线和待退出动画，再创建当前层；不跨层淡出叠加。                                                             |
| 切换业务范围                 | 取消或忽略过期响应，不把上一范围的事件当作新范围焦点。                                                                       |
| 同层级平移、缩放、resize     | 只更新投影；不重启动画，也不强制重新取数。                                                                                   |
| 暂停、减少动态效果、离开页面 | 地图暂停同时控制涟漪和飞线；减少动态效果时关闭装饰动画；离开时取消动画、计时器、请求和监听。取数暂停与动效暂停保持语义独立。 |

选择有业务依据的飞线语义：有真实起终点时展示真实关系；仅为了装饰时可按事件顺序连接相邻地点，但不要把它标成运输、流量或配送路线。聚合到当前层级后，同一地点不画零长度线，缺失地点不跨过连接。若连接最新 N 个相邻事件，最多 N−1 条活动飞线；退出中的旧线也必须限时清理，不能随刷新累积。

路线键包含层级、事件或关系 ID 与地域端点。曲线可用轻量弧线与流动光尾，使用柔和透明度退出，避免一帧消失或每次刷新从头闪现。颜色、时长、曲率与焦点数量由主题、地图尺度和事件频率决定，不固定某一模板参数。

## 验收重点

- 单国、跨国、跨国家同名城市，以及缺失中间层级：身份不串联、不伪造父级，能回到正确上级。
- 各层指标与源查询一致，尤其是去重数、比率、比较期和未定位数据；空结果、全部未定位时保留可理解的页面状态。
- 国家 → 行政区 → 城市往返：仅当前层级存在标记与动效，另一层级没有待退出飞线残留；相同层级更新保持动画连续。
- 快速筛选、连续刷新、暂停恢复：旧响应不覆盖新范围，节点和动画数量不会持续增长；地图点选不被装饰层遮挡。
- 缩放、平移、容器变化：点和飞线端点贴合；刷新不抢相机；窄屏卡片不遮住全部可操作区域。跨日期变更线或极区在涉及这些地域时单独验收。
- 真实浏览器检查地图资源失败、字体、署名、控制台、键盘焦点和减少动态效果。测试覆盖实际规则与生命周期，不仅匹配代码文字。
