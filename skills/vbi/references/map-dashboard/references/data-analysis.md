# 数据分析流程

本篇定义地图看板要分析什么、如何核对。具体 Builder、Connector 与 Spec 调用按 [visual-query](../../visual-query/SKILL.md)执行，不在场景文档维护另一套查询或绘图实现。

## 从任务映射到数据

先写清看板需要支持的判断，例如“识别服务需求集中的地区，并查看变化和相关记录”。围绕这个判断选择主指标、地域层级、时间和明细，避免把可用字段全部放到主屏。

| 核对项     | 需要明确的内容                                                   | 对页面的影响                                               |
| ---------- | ---------------------------------------------------------------- | ---------------------------------------------------------- |
| 事实粒度   | 一行代表事件、业务明细、实体快照还是已聚合记录；稳定 ID 是什么。 | 决定计数、去重、求和与下钻对象。                           |
| 字段与单位 | 字段类型、空值、量纲、币种及显示名。                             | 数值和日期在接入边界规范，不能靠图表强制转换掩盖类型问题。 |
| 时间       | 事件时间或快照时间、报告时区、数据覆盖范围、更新延迟。           | 决定筛选边界、时间粒度、比较期和“实时”是否成立。           |
| 地域       | 稳定地域标识、父级关系、实际坐标或代表位置。                     | 决定地图层级、下钻和未定位数据的处理。                     |
| 分析完整性 | 查询条数上限、分页、源数据覆盖和可用基期。                       | 决定哪些总计、占比和二次统计可以展示。                     |

字段不存在时，删去或替换相应业务模块及其查询；缺少核心来源时报告缺口。没有可信时间序列就不制造趋势，没有目标或阈值就不输出达成率与告警。地域映射详见 [地图指南](map-guide.md#地域标识与层级映射)。

## 定义指标口径

为每个指标明确：名称、分析对象、维度、基础聚合、筛选范围、单位、分母、比较规则和缺失值处理。聚合通过 VBI Builder 描述，由 VQuery 或数据源执行。

- 明细数、事件数与实体数分别命名；业务对象跨多行时按稳定 ID 去重。
- 比率从同一范围的分子与分母计算；区域比率不能直接取平均，去重实体数不能直接累加子区域。
- 金额、数量等可加指标也需确认没有重复事实；库存、余额等快照不能按时间直接相加。
- 相对变化、百分点变化、正负方向和基期缺失按 [指标卡](metric-card.md#比较与状态)处理。
- 地图未定位记录仍属于业务范围，保留在概览和明细中；定位覆盖率与业务总量分别表达。

## 组织查询清单

沿用模板按业务名称组织 Builder 与结果的方式。下面是角色示例，按实际模块增减，不要求固定查询数或固定字段名。

| 查询角色   | 粒度与用途                             | 常见边界                                                    |
| ---------- | -------------------------------------- | ----------------------------------------------------------- |
| 范围汇总   | 当前范围整体聚合，供指标卡及分母使用。 | 总量不能从排行榜或截断明细中计算。                          |
| 地域分布   | 按当前地域层级的完整身份分组。         | 各层去重和比率独立计算，按源事实汇总。                      |
| 时间趋势   | 相同业务范围按选定时间粒度分组。       | 分桶、排序由查询完成；本期和基期各用自己的时间窗口。        |
| 排名或结构 | 按实体或类别聚合，再按度量排序。       | 对聚合结果的条件使用 `havingFilter`，先筛选分组再限制名次。 |
| 明细与事件 | 查询需要核对的事实、ID 与时间。        | 明细上限与完整汇总分开；新事件不能用请求完成时间代替。      |

原始记录条件用 `whereFilter`，分组后的条件用 `havingFilter`。页面统一修改相关 Builder 后调用 `buildVSeed()`；Connector 执行传入的 DSL。服务端 SQL 编译、参数绑定与来源访问交给 [server-runtime](../../server-runtime/SKILL.md)及查询库，页面不手写 SQL 或重做分组聚合。

## 一轮查询与视图消费

刷新开始时固定本轮时间截止点和筛选状态，各查询据此生成范围；同一快照的批次按服务能力组织，不把多个独立批次称为全局一致快照。过期响应、取消和实例更新使用 [共享组合流程](../../visual-query/references/composition.md)。

同范围、同字段、同粒度的结果可以复用给卡片与图表；不同口径应独立查询。保留 Builder 产生的字段 ID，在统一呈现边界解析名称和类型。VSeed 生成 VChart / VTable 配置；HTML 指标仅消费结果、格式化或计算已定义的比率。地理适配层负责位置解析与投影，不补算业务聚合。

对分组结果再统计时，优先让数据源查询完成；需要临时中间数据集时，仍通过 VQuery 接入并由 VBI Builder 查询，结束或取消后释放。若中间结果被截断，不能据此报告完整实体数量、复购比例或集中度；扩大查询能力或明确该指标暂不可用。

## 核对后再扩展

准备可核对的小范围：整体、一个地域、一个时间窗口，分别比较卡片、地图、趋势和明细。覆盖重复 ID、零值、负值、缺失位置、空结果、无基期以及截断结果。核对通过后再扩展面板和主题，最终按 [验收清单](visual-acceptance.md)检查。
