# 验收标准

首次生成 Dashboard 产物时，执行以下验收标准。

## 核心发现

- 必须有至少一句具有深度见解的总结性评价，结合数据说明关键变化及其业务意义。
- 必须展示多个北极星指标的数据，体现当前业务表现。
- 必须有**重要衍生指标依据**，明确计算口径和支撑总结性评价的数据。

## 页面样式

1. 背景采用大面积模糊渐变与柔白斜光。
2. 筛选器按[标准实践](./filter.md)使用胶囊平铺或定制 Select；检查选中、hover、焦点、菜单关闭和窄屏边界，打开浮层不挤动页面。
3. 整体使用无边框卡片布局，搭配适当圆角。
4. 按[入场时序](./layout.md#卡片按顺序延时入场)检查实际启动时刻：数据与图表就绪后，首张等待 480ms、相邻模块间隔 560ms、单次动画 1600ms；桌面和窄屏都按当前阅读顺序出现。筛选、悬停与重排不重播；减少动态效果时直接显示最终状态，并能在播放中立即结束剩余动画。
5. 小型卡片有 3D 倾斜效果，大型卡片没有 3D 倾斜效果。
6. 数值文本有数字动画，图表有入场和更新动画。
7. 同层级指标字号一致，长数字不裁切，数值更新时字号不跳动。

## 页面布局

1. 首屏可见核心发现：先展示一段总结性文本，再用多行展示北极星指标与衍生计算指标。
2. 指标卡同时展示 mini 图表和指标数值；mini 图隐藏坐标轴、图例和常驻数据标签，hover 时仍可读数。
3. 主要内容宽度为 1140px，两边留白；窄屏采用响应式布局，适配 PC 和移动端。

## 功能交互

1. 提供多种筛选器。
2. 支持切换多种时间粒度。
3. hover 主图时更新关联指标，hover 小图时只更新所属卡片；移出后恢复汇总值。
4. 明细默认展开，可以折叠；筛选后保留展开状态。

## 指标深入分析

1. 主页保持简约，指标标题右侧的轻量图标可进入分析；键盘与触屏均可操作。
2. 按 [metric-analysis 的交互与平滑更新规范](../../metric-analysis/SKILL.md#交互与平滑更新)验收
