# Dashboard 截图对照验收

创建页面或调整布局、字体、配色、图表样式后使用。局部修改只比较受影响区域及相邻布局。数据与交互检查按 Skill 的验收要求执行；截图用于确认实际呈现和视觉取舍，不能证明指标口径正确。

## 确定参照与截图条件

适配业务与视觉时，选定用户提供的参照、已有宿主页面或[轻量看板示例](../../examples/dashboard/lightweight-dashboard.html)的一种布局。记录主区域、字号层级、默认展开内容，以及为当前业务保留或调整的结构；具体骨架和密度规则见[布局最佳实践](./layout.md)。新视觉方案以已确认的设计目标为参照，不强行匹配轻量示例。

对照前统一浏览器视口、缩放和展开状态。轻量页面默认检查 1440 × 1000 的桌面视口及 390 × 844 的窄屏视口，用户目标设备优先；嵌入式看板还检查真实宿主容器。尺寸变化由容器驱动，不能只把桌面截图缩成手机宽度。需要检查 375px 或 1920px 时沿用布局文档的适配范围。

仓库 `demo1.png`、`demo2.png`、`demo3.png` 可用于选择风格，但它们的像素尺寸与展开状态可能不同。精确对照时在同一视口运行示例 HTML、选择相应布局并统一展开状态，再截图；避免直接比较不同缩放比例下的数字大小。若示例无法运行，可参照现有图片判断层级，并明确没有完成同视口对照。

## 等待内容实际就绪

截图前确认以下状态，优先等待应用现有的就绪信号与可见内容，不以固定延时或 `networkidle` 单独判断：

- 数据查询已完成，关键指标不再是占位符；字体就绪，布局与图表容器尺寸稳定。
- 每张有数据的图表已完成首次绘制，实际可见图形、标签或预期标记。出现 Canvas/SVG 节点、拿到 Spec 或成功 HTTP 响应都不足以证明绘制完成。
- 无数据时显示明确空状态，失败时显示错误反馈。整块空白、持续加载和未处理的失败请求需要修复，不能当作正常留白。
- 入场动画结束，截图不处于淡入中途；默认视图不被意外 Tooltip、悬停倾斜或弹层遮挡。动效本身另行交互检查。

## 查看截图并修正差异

保存首屏截图以检查注意力与控件占比；长页面另存全页截图检查节奏和明细。实际打开截图，与同视口参照并排查看。浏览器 DOM 检查和截图文件存在不能代替图像检查。

| 对照维度     | 检查问题                                                   | 常见修正                                                   |
| ------------ | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 视觉重心     | 能否迅速找到主要结果？是否所有 KPI 和图表同等醒目？        | 调整主辅卡面积、位置和字体层级，合并相关指标。             |
| 字号比例     | 主数字相对辅助数字是否突出？单位、比较基准和标题能否读清？ | 恢复主辅字号关系，为长数值留空间；不整体缩小文字。         |
| 信息密度     | 是否比参照多出重复的洞察、指标条、整图或明细？             | 合并重复内容、缩小辅助图形、按需展开次要内容。             |
| 留白与节奏   | 外壳、卡内、卡间留白是否协调？是否有无意义空洞？           | 调整内边距、网格跨度和绘图区高度，核对图表已绘制。         |
| 图表重量     | 柱体、环图、网格、图例和标签是否抢过主指标？               | 按图表任务调整尺寸、条宽、标签与辅助元素，保留必要读数。   |
| 控件占比     | 筛选和操作是否压过标题与结果？                             | 区分高频与低频操作，明确全局与局部范围。                   |
| 阅读面与配色 | 背景、边框、阴影是否比数据更突出？                         | 恢复稳定的中性阅读面，降低装饰强度，核对文字与图形可读性。 |
| 窄屏顺序     | 主结果是否仍易找到？图形是否被压扁或数值裁切？             | 按业务阅读顺序重排，允许自然增高与滚动，调整图表尺寸。     |

业务差异不要求逐像素一致。数据分布、语言长度、必要坐标与用户要求造成的差异可以保留，并说明理由；不能为匹配截图修改真实数值、编造趋势或隐藏用户要求的信息。

窄屏网格按阅读顺序连续排列，重新计算各卡的行起点，不直接保留桌面的行坐标；检查全页截图中的卡间距离，避免单列出现空行和大段无意义留白。条形图数值标签应有足够对比度，并为条外读数预留空间。

发现明显偏差后，先修正重心与密度，再处理字体、留白和细节；重新截图并查看受影响视口。确认同一问题已经解决后不重复无变化检查。若浏览器、依赖或数据访问阻塞验收，记录原因与未验证项，不宣称通过。

## 必要交互逐项验收

采用轻量示例风格时，以下项目是必要检查，不能只根据静态截图宣称通过。以所选[趋势主导模板](../../examples/dashboard/template1.html)、[指标先行模板](../../examples/dashboard/template2.html)、[分段叙事模板](../../examples/dashboard/template3.html)或[基础模板](../../examples/dashboard/template.html)为参照；业务没有日历日期时验收分组比较与逐项查看，配色按所选模板核对。

| 项目           | 实际操作与通过条件                                                                                                                                                                                         |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 图表完整       | 所选模板的四张图实际可见，类型与数据相符，Tooltip 显示真实数值；环图分组有数据依据，涉及负值时保留。                                                                                                       |
| 首屏与刷新     | 模拟模块尚未加载、查询未完成及加载失败；标题与加载或错误反馈可见，未布局卡片不闪现、不挤成单列窄条，隐藏主体不可聚焦；就绪后图表尺寸正确，后续筛选不重新收起主体或重播入场。减少动态效果模式同样检查首屏。 |
| 实例更新与动画 | 按模板切换实际筛选项并快速恢复，如年份范围与发展阶段、年龄与高血压记录、活动水平与人群；实例与 Canvas 保持复用，调用 `updateSpec()`，图形有约 600ms 更新过渡，无重建闪白。                                 |
| 平铺选择器     | 全局筛选集中在页面标题行最右侧，桌面同排，主图内无重复全局筛选；选中状态清楚，Tab / Enter 可操作，初始化禁用，390px 不溢出。模板无布局与配色控件；基础模板为浅蓝，新模板按各自蓝、紫、暖橙配色验收。       |
| 小卡倾斜       | 鼠标移动到小卡边缘及图表上，倾斜仍正常，目标约 1.5°、包括弹性过冲在内整体 ≤2°；离开、滚动、失焦复位，主图与洞察保持平面。                                                                                  |
| 默认明细       | 首次打开时表格已展开；手动折叠，再筛选后仍折叠；若实现布局或配色切换，也保留折叠状态，重新展开可读。                                                                                                       |
| 曲线与指标动画 | 有真实时间字段时主趋势与 mini 趋势平滑，真实点值不变；筛选、悬停、恢复时核心与衍生指标都过渡，首次显示不从虚构零值开始；图表标签在尺寸变化后仍显示真实读数。                                               |
| 卡内联动       | 主图年份或分组联动全部指标及环图，小图只联动所属卡；移出恢复同作用域汇总；快速移动、换筛选后无旧值覆盖，悬停不增加查询次数，范围洞察保持不变。                                                             |
| 洞察与衍生指标 | 核心发现同时展示核心与重要衍生证据，范围一致；占比、覆盖率、单件热量等从汇总值复算，百分点与百分比不混用，零分母不制造值。切换筛选后重算，局部悬停保留范围结论，详见[洞察验收](./insight.md#验收)。        |
| 降级与清理     | 图表方向键 / Esc 与逐项按钮可用；触屏关闭倾斜，减少动态效果立即完成数值并停止图表、倾斜与入场动画；卸载无残留帧、定时器与监听。                                                                            |

动效检查至少记录更新前、更新中和稳定后的数值或连续帧，以及最终准确值。调试日志、临时断点或隔离的验收插桩可用于确认实例与查询次数，交付页面不保留调试面板。截图之外明确记录实际检查的交互、结果和未验证范围。

## 交付证据

交付说明中提供最终截图的路径或链接、实际页面 URL、视口和参照布局，简要说明修正结果及保留的业务差异。截图与最终代码一致；修正后不能继续使用旧截图。涉及筛选、明细展开或布局切换时，说明实际检查过的状态与结果。

示例记录格式：`桌面 1440 × 1000 / 窄屏 390 × 844；参照 focus；已合并重复 KPI、恢复主辅字号关系；最终截图：…；业务差异：无时间字段，主区使用岗位比较；未验证：…`。将内容替换为本次实际结果，无未验证项时省略对应字段。
