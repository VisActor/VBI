# 数据分析使用说明

从业务问题选择 data-analysis 方法，通过 VBI / VQuery 形成可复算的证据，再组织发现与下一步；主动探索按 [deep-analysis](deep-analysis.md)接入。已有页面局部修改沿用已确认目标，只重审受影响部分。

## 问题与方法

- 明确使用者、要判断或核查什么、可采取的行动及约束；缺少会改变结论的定义时澄清，其余继续取证，不要求固定表单。
- 确认粒度、业务键、时间含义、单位、覆盖、维度与缺失，区分快照、事件和汇总；比较前核对两组范围与口径。
- 优先使用已有目标、历史或可比群体；缺少参照时描述分布与差异，缺少过程、成本或结果字段时说明解释与收益判断的边界。

先选方法再选图形，按[共享方法索引](../../../references/data-analysis/guide.md#按问题选择方法)选读透视、贡献、分布、转化、留存、路径、实验、目标或生命周期；地域影响判断时补读[空间分析](../../../references/data-analysis/map.md)。常见判断的证据要求如下，不要求每页凑齐。

| 判断                   | 证据与呈现                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------ |
| 变化来自哪里           | 可比两期与明确的可加总关系；趋势、差异排行或瀑布。多因素分解说明方法及交互项。       |
| 均值掩盖什么           | 记录级数值或有效分布统计，明确分箱、有效样本与异常判据；直方图、箱线图或分位数对照。 |
| 高数量来自规模还是效率 | 联合比较规模、结果与有效分母，同时看数量和比率。                                     |
| 结果集中在哪些类别     | 类别与分母明确，检查类别重叠；排行、累计贡献或结构比较。                             |
| 哪些组合值得核查       | 交叉维度、足够样本与比率，并检查构成差异；矩阵、分组或可比条件下的分层比较。         |
| 哪步流失、哪些群体留存 | 真实事件顺序、实体键与窗口，阶段去重及队列分母一致；漏斗、路径或留存表。             |

## 计算与查询

- 聚合、筛选和排序交给公开 Builder，按 [visual-query](../../../references/visual-query/guide.md)复用结果；衍生值消费同范围未格式化结果，不在 DOM 中重新聚合。
- 比率按业务定义汇总同范围分子分母再相除；总体均值按有效记录或权重重算，不直接平均局部比率或累加重叠分组去重数；区分构成变化与组内变化。
- 保留合法零、负值与缺失；空范围计数为 0，无定义值和零分母比例显示 `—`，中间计算不舍入。
- 变化明确基数；负基期按指标语义定义，零基期保留本期值并说明不可比。10% 到 12% 是增加 2 个百分点、相对增加 20%；增减是否改善由业务定义。
- 样本比例不自动代表总体，缺失不当作零。Top N 仅限制展示，抽样、分批加载与不完整期间说明覆盖，不从可见记录估算总体。

方法须有真实查询或计算支持，能力不足时说明缺口，不虚构 API。需保存、重算或跨宿主复用的方法、公式、条件与依赖归所属 DSL 和 Builder，按[派生计算与状态](../../../references/visual-query/references/query-and-render.md)接入。

## 发现与交付

- 事实说明范围、基准、幅度与证据，结合影响规模、比率和有效记录，不仅凭最高或最低决定优先级；保留会改变判断的重要反例。
- 区分观察、候选解释与已验证原因；检查样本量、分母、缺失和构成，稀疏或不稳定结果按方法补充不确定性、反证或敏感性核查，关联不写成因果。
- 下一步对应可核查对象、待验证假设与观察指标；成本、收益、可控性不足时给核查路径，情景估算写明假设，不当作已兑现收益。
- 首页突出主要发现和必要证据，基准与重要限制就近可见，长公式按需展开；不机械复述卡片、重复筛选摘要或补充显而易见的操作说明，不编造目标、阈值和原因。证据足够时停止扩图。
- 筛选后重算发现与依据；hover 仅临时查看，不改写全局结论。

通过 `insight.setContent(content)` 保存内容，Dashboard 引用同一 Insight；写入和解析协议同步维护，行序属于页面协议，UI 用 `textContent` 与原生列表呈现。Insight Builder 不执行模型推理；模型只消费已计算数值、公式、单位、范围、比较及有效性，保存结论不等于保存可重算定义。

用独立源记录或查询核对总体与有效筛选范围，按方法验证守恒、对齐、去重或统计假设；承诺恢复时做定义与结果往返。订阅、释放与资源快照见[组合指南](../../../references/visual-query/references/composition.md)，交付按[验收标准](acceptance.md)。
