# 验收标准

首次生成时检查语义、视觉和运行结果；修改已有页面时检查受影响的部分。自动检查通过只说明对应检查项通过，不能代替视觉对照。

## 语义与核心发现

- 每张卡的标题、主读数、图形与交互回答同一个分析问题；不同指标的关系有可见说明。悬停切换范围时同步范围提示，切换指标时同步标题与单位，或只在 Tooltip 中展示。
- 无需悬停也能识别图形表达的类别、时间或分布。不能把国家排行画成无说明的迷你走势；必要类别标签优先于 mini 图的简化规则。
- 核心发现表达一个主要判断，证据可复算；不重复罗列全部卡片，不展示制作配方、指标数量或执行日志。缺少比较数据时不编造趋势、原因或阈值，见[洞察规范](insight.md)。

## 页面布局与视觉对照

选定参考模板后，将模板和产物在**相同视口、浏览器缩放和动效状态**下并排检查。独立页面可用 1440×900 或 1920×1080 桌面视口及 390px 窄屏；嵌入页面按宿主实际容器检查。等待数据、字体和图表就绪、入场结束后截图，同时看首屏和完整页面。

| 检查对象     | 判断依据                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| 阅读主次     | 第一眼能找到主要结果和当前范围；辅助文字、控件和背景不抢重点。允许改变构图，不要求像素复刻。                         |
| 密度与留白   | 核对外壳与实际阅读面宽度、卡间距、内边距、说明行数；不靠压小文字或裁切强塞一屏。                                     |
| 字体与控件   | 检查实际 computed style，而非只看 CSS 声明；同层级数字一致，标题、说明、证据有层次，触控命中区不必等于控件可见高度。 |
| 图表融合     | Canvas 与卡片底面连续，没有意外白色矩形、标签描边或重复轴线；主图标签完整，位置策略一致，颜色有语义。                |
| 窄屏与长内容 | 检查长标签、最长数值、浮层边界及阅读顺序；卡片不横向溢出，必要的宽表在自己的容器中滚动。                             |

对明显弱于参考的部分先修改，再对照。交付说明只需简述检查过的视口、关键调整及未验证项；截图和运行报告留在交付材料，不写进业务页面。

## 功能交互

- 核对默认值及一次有效筛选后的图表、指标、明细和核心发现；覆盖当前数据适用的空结果、缺失值、零分母和负值。只提供数据支持的筛选维度与时间粒度。
- 主图只联动已声明的关联指标，小图只联动所属卡片。检查每类悬停读数、范围提示及移出恢复，旧查询和旧动画不能覆盖新状态。
- 复用实例调用 `updateSpec()`；图表与数值更新都有过渡。首次入场按[布局时序](layout.md#全页缓动入场)，筛选与重排不重播；减少动态效果时直接显示最终状态。
- 弹窗的维度胶囊、分组选择、清除、重试与展开按钮沿用主页控件的圆角、材质、选中、悬停和焦点样式。取数时只让触发该请求的控件在文字右侧转圈；菜单选项选择后在可见的菜单触发器显示，快速切换只保留最新控件的 loading，完成、失败和关闭都能清理。更新时不重复显示“正在更新”文字，错误和空结果反馈保留。连续切换维度、选择与清除时，文字和图表不闪白或反复淡入；数值从当前读数接续，表格不重播入场。
- 分析弹窗从指标入口展开并轻微回落，再在就绪后同步揭示摘要、控件、图表和明细；关闭入口始终可见，退场从当前姿态开始，结束后恢复焦点与滚动；延迟加载不能提前播完内容动画，筛选与滚动不重播。检查动画中关闭、关闭重开、加载失败重试和播放中开启减少动态效果；不支持模糊或减少透明效果时仍有清晰底面。
- 检查筛选器的选中、焦点、关闭及触屏操作；小卡倾斜不改变命中区，大卡保持平面。明细默认展开，筛选保留用户折叠状态。
- 筛选取数立即让本次点击的筛选选项在文字右侧转圈，并显示更新状态，等待期间保留原布局并标记内容忙碌，筛选器仍可操作，转圈只跟随最新点击项，其他筛选组不转圈；图标平时不占位，出现与消失时控件宽度平滑伸缩。用慢请求核对持续反馈、成功收起、失败重试及连续切换；旧请求不能提前收起状态或覆盖最新选择，更新不重播首次入场。
- 有分析入口时按 [metric-analysis](../../../references/metric-analysis/guide.md#交互与平滑更新)检查局部范围、下钻、返回与 VTable；保存恢复时核对 Dashboard 及所引用资源，销毁时释放实例与监听。
- 检查控制台错误、资源加载失败及真实图表内容；有 Canvas 节点不等于图表已正确绘制。

表格默认态、悬停与选中态均消费[统一 token](../../../references/visual-query/references/table-theme.md)。主页和分析明细都使用 VTable，不显示分页器；验证完整记录可滚动到末行、清除筛选后恢复结果、展开与折叠后尺寸正确，主题更新保留列宽。实际选中单元格后验证 Tab / Shift+Tab 能按顺序离开表格，分析弹窗内仍可到达其他控件与关闭入口。

初始化专项：缓存命中时全局 loading 也至少显示 800ms；慢加载持续占位，整个页头、筛选、卡片与页脚不提前泄露。数据和图表就绪后统一入场，整组 2000ms 内稳定，区域按位置轻微错峰启动。验证依赖失败、初始化失败、超时和重试；失败与页面销毁后不能迟到揭屏。后续筛选使用轻量更新状态，hover 不触发加载。减少动态效果时保留等待文案与就绪门槛，停止转圈并直接显示最终场景。

主页 VTable 默认无外框、无行分隔线，使用宿主 `#overview-table` 的透明 `--table-frame` 与 `--table-divider`；保留表头、轻斑马纹、行悬停、选中和键盘焦点。确认 Canvas 实际边框消失，不能只检查 DOM 的 CSS border。

入场覆盖顶栏、Header（含筛选）、核心发现、卡片、明细、页脚和图表，所有区域起始不可见，按实际 top/left 位置排序。检查区域间隔不超过 60ms、最后一个区域延迟不超过 420ms，图表比所属面板晚 100ms 启动；沿 chart-editor 的缓动平滑落位，无弹簧回弹；图表从下向上展开，整组最多 2000ms。增加区域不增加总时长；窄屏缩小位移与缩放幅度；结束后释放 transform 与 clip-path，减少动态效果立即结束，筛选与重排不重播。
