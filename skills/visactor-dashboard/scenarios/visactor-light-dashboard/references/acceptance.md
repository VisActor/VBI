# 验收标准

按本次任务的影响范围检查；新页面覆盖完整分析与体验，局部修改核对受影响部分。自动检查用于验证具体约束，视觉与交互仍需实际对照。

## 分析与证据

- 使用者与主要问题清楚，图表、指标和发现支持同一判断；各模块或后续探索能提供新的比较、定位、解释或核对依据。
- 比较有可见基准且口径一致；最高、最低、变化或相关性有其业务含义，不直接当作异常、改善或原因。
- 关系图的两轴有业务含义，不默认用来源记录数或恒定国家数作为解释轴；实际检查有效配对、变化范围、缺失和筛选后单值情况，不能用缩放坐标伪造关系。点选、菜单和明细保持相同业务身份与条件。
- 关系图的 X、Y 均值线通过 VSeed 标注配置绘制，取当前范围各指标有效值的 VBI 查询均值，不对可见点重新平均；局部点选不改变范围基准。标签在绘图区内完整显示，带轴向、数值与单位；桌面、390px 窄屏、筛选及换色后无裁切或遮挡。
- 结论能定位到真实查询结果；影响规模、比率、样本量和重要反例按当前问题纳入判断。稀疏或不稳定结果的限制可见。
- 观察事实、可能解释和待验证假设可区分。提供行动或情景估算时，其依据、假设与验证方式清楚；数据不足时说明需要补充什么证据。

## 数据与口径

核对默认范围与一个有效筛选范围的关键读数、图形和发现，按适用情况覆盖去重、比率分母、百分点、负值、缺失、空结果和不可比基期。明细粒度与指标关系明确，完整查询结果可访问，Top N 不截断总体计算。

保存恢复承诺涉及的条件、布局与资源应可重建；若包含公式重算，验证公式和依赖而非仅保存结论文本。具体规则见[分析设计](insight.md)与[指标深入分析](../../../references/deep-analysis/interaction.md)。

## 页面布局与视觉对照

模板与产物在相同视口、缩放和动效结束状态下检查首屏与完整页面。独立页面检查桌面及 390px 窄屏，嵌入页面以实际容器为准：

- 主次和阅读顺序清楚，数字、标题、图形与必要口径完整，长内容自然增长；不以缩字、裁切或大片无意义留白维持布局。
- 指标驱动的柱图颜色通过 VSeed `color` 编码与连续色阶生成；实测不同原始值有相应色差，同值同色，Tooltip 不重复，负值语义和空集、单值呈现正确；切换主题后颜色与读数、筛选保持一致。
- 实际 computed style 的同角色排印一致。Canvas 融入阅读面，标签清楚，无意外白底、描边或重复标注；颜色、玻璃叠层和降级后的对比足够。
- 控件、浮层和独立触控命中区可用，页面无横向溢出；宽表在自身容器内滚动。
- Card、Modal 与菜单的近白灰底、局部反光和单层上沿高光保持同一材质；透明边框区域不叠加填色或下沿硬线，Card、Modal、菜单及筛选器的收起与展开态均只有单一轮廓。浮层能透入背景颜色，正文与图形仍清楚。Modal 遮罩只分隔内容，内部按钮与嵌套图表不重复模糊；选中项无外阴影，减少透明或模糊不可用时使用稳定实底。

## 外观设置

- 四份模板的设置三点按钮位于标题右侧筛选区域的最右侧，外部高度为 36px，图标使用中性次级色，复用筛选器的材质、指针光泽、白色 hover、柔和内阴影和按压回弹；桌面和 390px 窄屏无横向溢出。玻璃浮窗在视口内，外部点击、Escape 和关闭按钮有效，关闭后可返回入口焦点。
- 色板覆盖[设计参考](design.md#参考色板)的八种主题，名称均为两个字；四份 HTML 各有明确且不同的默认主题。换色同步页面、主图、迷你图、表格与随后打开的分析 Modal，业务语义色保持原义。
- 玻璃强度实时改变 Card、Modal、菜单与筛选器材质；默认强度与设计 token 一致，低值通透、高值凝实，文字和图形保持清楚，轮廓无重复边线。减少透明与不支持模糊时仍可操作设置。
- 刷新恢复主题和强度，各模板偏好互不覆盖；恢复默认只清理当前模板的外观偏好，保留业务条件与读数。无效存储或存储不可用不阻断页面与设置。
- 换色复用查询结果，经 `updateSpec` / `updateTheme` 更新已有实例；滑块不触发数据查询或图表重建。快速切换及查询进行中调整后呈现最新主题，表格范围、记录与必要状态保持。

## 迷你图

- 按[迷你图规范](metric-card.md#文本与迷你图配合)逐张检查真实 VSeed 配置与渲染结果：仅允许渐变 `column`、无点渐变 `area`、`donut`，同一模板类型不重复；不能仅更换颜色或指标后重复图形。
- 渐变柱的默认、正负值条件、hover 和选中态均无描边，面积图顺序有业务含义；donut 的分项非负、分母一致，数值说明不遮挡扇区。缺失、空结果和正负值真实呈现，不为凑类型伪造趋势、取绝对值或修改统计口径。
- 实际验证 Tooltip、卡内 hover / 键盘查看、移出恢复与筛选更新，读数和明细口径一致；现有图表实例保持复用。桌面与 390px 预览和模板实现同步。

## 可复用筛选组件

- 必须使用可复用的平铺和 Selector 组件：主页与 deep analysis Modal 均调用模板内同一 `DashboardFilters` 入口、使用同一组样式与 token；不能按页面、弹窗或具体筛选字段复制独立的 CSS 和事件实现。
- 四份基础模板的右上角各包含至少一组平铺和一个 Selector。平铺整组与 Selector 触发器实测外部高度均为 36px，桌面、390px 窄屏及 Modal 内保持一致；主页、Modal 工具栏及其选项菜单的搜索框与选项行高同为 36px。表格列菜单使用独立的紧凑规格：宽 264px、桌面控件高 28px、触屏高 36px，不能影响主页平铺与 Modal 工具栏。
- 完整选项少于 4 项时隐藏搜索框，4 项及以上显示；按完整列表（含“全部”）计数，不能随搜索匹配数减少而隐藏输入。核对匹配、无匹配、清空、动态列表跨越阈值及当前选中项。搜索及移动焦点不提交业务筛选，确认选项后才调用原有查询流程；清空搜索不清除已确认条件。
- 对照收起与展开状态，核对玻璃材质、选中面、字体、间距、hover、焦点和 loading。菜单内已选和未选项的 hover 均应明显，统一使用半透明白色背景，hover 只使用柔和内阴影，菜单项内阴影无偏移、四周均匀，不添加描边或外部投影，菜单与平铺按下时均轻微压缩并回弹，内阴影强于 hover、不切换为深色底，各模板与 Modal 不跟随图表主题色变化；平铺按钮共用相同白色 hover 底色，默认选中面保持白色玻璃，菜单与平铺的选中态均无外阴影。检查克制的指针光泽、按压回弹和触屏反馈，不能改变业务选择或布局高度；固定向下 SVG 箭头开合时不旋转、跳位或改变控件高度。不得以原生系统 `<select>` 菜单替代定制面板；浮层在视口内，无裁切、背景误操作或横向溢出。
- 实际验证键盘进入、上下移动、Enter / Space、输入法组合、Escape 层级、外部关闭及焦点恢复。主图或恢复状态同步选项与触发器读数；关闭后重开、动态更新、快速切换和销毁不保留旧搜索、过期选择或监听。菜单开合可中断并从当前画面接续，旧退场不隐藏新菜单；选中标识清楚，切换到减少动态效果时结束在途动画，关闭 Modal 后无遗留浮层。

## 功能交互

- 筛选同步更新其声明范围内的指标、图形、明细与发现；“全部”只解除对应条件。临时 hover 按作用域更新并恢复，标题、单位和范围一致，不额外发起查询。
- 分析入口继承已确认条件，选择、换维度和返回均可核对范围；Modal 工具栏通过 Selector 显示当前分组，不另设重复选中摘要或“清除”按钮；图形与明细一致，继续探索增加证据，关闭恢复入口焦点与主页位置。
- 加载反馈仅跟随当前触发控件，Selector 的 loading 与箭头原位替换、不并排占位，开始和结束均不因图标切换改变控件宽度；平铺 loading 保持文字右侧伸缩。保留已有内容和布局；快速连续选择只提交最新结果。失败、重试和空结果可辨认，关闭后无旧请求回写或遗留转圈。
- 图表与表格实例原位更新，读数从当前值接续，页面与面板不反复闪烁或重播入场；用户折叠状态与必要表格状态保留。
- Modal 明细表使用 VSeed 默认表格动画，筛选及切换分组后同一表格实例呈现逐行过渡；核对动画中间帧、最终完整记录、快速连续选择、空结果恢复和减少动态效果，动画不改变列宽、范围或查询口径。
- 四份模板的主页与 Modal 表格均通过 VSeed `bodyCellStyle` 启用半透明数据条，通过 `totals` 生成固定底部的原生总计。核对实际数值与当前完整表格记录一致，求和仅限可加总金额与互斥分组计数，记录属性使用平均并跳过缺失；ID、年份、比例和分组均值不直接累加。条件格式随筛选结果更新，不覆盖玻璃材质；总计不增加记录数、不冒充来源记录下钻。验证零值、负值、空结果恢复、整列选择、虚拟滚动末行、Modal 筛选动画和 390px 布局，更新复用原实例与列宽。
- 主页与 Modal 表格点击列标题选中整列，选区覆盖表头和完整结果中的全部行；滚动至末行仍保持列选中，正文单元格点击为单格选择，筛选更新后清除过期选区。
- 四份模板的主页表格通过左键点击或触屏轻点列头漏斗打开玻璃筛选菜单，右键不触发，复用 `DashboardFilters`；文本支持包含、排除、等值、非等值、开头、结尾及空值条件，数值支持等值、非等值、大小比较、区间与区间外及空值条件；按原始精度过滤，多列条件取交集。单值条件并排呈现运算符和值，仅区间展示双输入，空值隐藏输入；菜单保留单层玻璃材质，清除入口按条件归属显示，不堆叠胶囊按钮。恢复排序图标独立于平铺选项组，hover 不移动选中面、不旋转或偏移图标，与清除按钮保持一致的柔和内阴影；核对悬停前后按钮与图标边界不变。排序支持升序、降序和恢复默认，已选方向可再次点击取消。使用公开 VBI Builder / VQuery 查询并原位更新同一 VTable，不在页面手写聚合与数据过滤，不额外引入筛选插件。逐项核对全部运算符、零值、空字符串与 `null`、单侧区间、无效边界、单列与全部清除、空结果恢复、关闭草稿及已确认条件恢复、主页范围改变后条件保留、快速连续提交、输入法组合、Alt+↓ / Escape 和 390px 菜单位置；表格局部条件不改变指标卡，筛选和排序后的单元格下钻仍命中当前业务记录，列标题选择与菜单入口互不混淆。
- 主页与 Modal 的所有表格均启用原生 Ctrl+C 复制（macOS 为 Command+C）。实际核对单元格、矩形选区、表头整列及虚拟滚动中未显示的行；复制当前展示格式，筛选或更新后复制新结果，不改变数据和筛选，也不拦截搜索框的文字复制。
- 主页分析表格的每个正文单元格均可打开分析 Modal，维度格进入该行的主要指标，指标格进入对应指标；按记录中的业务键固定该行范围，并继承主页已确认筛选。核对所有列、不同记录、零值与缺失值，以及滚动、筛选后的入口；表头不弹窗。切换 Modal 维度或分组始终保持入口范围，Enter / Space 可打开所选单元格，关闭后返回表格并保留主页位置。
- 四份模板均保留原有分析表，在内容最下方另增原始记录明细表。列概况位于表头后的第二行，不混入记录；数值分布、文本高频项、其他与缺失计数对应当前完整结果，常量、零值、全缺失和空结果可区分。数值图使用 VSeed，边界与频数由 VBI 查询。
- 底部明细表沿用上方分析表的无边框阅读面，保留表头、斑马纹、选区边界和键盘焦点；复用分析表的列筛选、排序、搜索及复制组件，按真实列类型选条件，覆盖首列数值和后续文本列。全局条件同步原始范围，局部条件只影响本表；筛选后概况更新，排序不重复取概况，主题和尺寸变化复用表格实例。核对完整记录数、末行、横向滚动及 390px 呈现。
- 四份模板的 Modal“关联明细”均复用同一套列搜索、筛选与排序，支持文本、数值、空值条件及清除；不增加第二行统计图。列条件仅改变当前明细及其原有底部合计或平均值，分析图和指标保持原范围。菜单挂在 dialog 内，能操作输入、子菜单与键盘；切换分组保留兼容条件，关闭与重开无遗留菜单、旧查询或旧条件。核对空结果恢复、汇总、复制、展开与 390px 位置。
- Modal 表格沿用主页的无外框阅读面，保留表头、斑马纹、选区边界与键盘焦点；默认、筛选后和展开状态均无额外外框。
- 弹窗在内容就绪后揭示；覆盖动画中关闭、重开和延迟加载。菜单键盘选择、Escape 层级、外部关闭、触屏及可见焦点正常。
- Modal 关闭按钮使用居中的 SVG 图标，图标与命中区域的中心重合，不受字体基线影响；桌面、窄屏、长标题与内容滚动后均可见、可点击，关闭后焦点返回入口。
- 减少动态效果时可结束播放中的动画并直接呈现最终值；减少透明或不支持模糊时仍可读。退出释放订阅、查询、图表、表格、计时器与观察器。

完整交互规则见[筛选器](filter.md)与[指标深入分析](../../../references/deep-analysis/interaction.md)。交付简述实际验证范围和未验证项，运行日志与验收材料放在业务页面之外。
