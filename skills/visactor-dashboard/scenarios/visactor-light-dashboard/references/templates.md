# 模板列表

共 4 份基础模板，可先打开[可视总览](../templates/index.html)查看效果。

开始制作前，查看所选模板的 HTML 和截图。模板可以重排、组合或重新设计，布局和主题色分别按业务选择。

模板文件在 `templates/` 目录。桌面截图与 HTML 同名，手机截图在文件名后加 `-mobile`。
