# 筛选器

本篇负责控件选型、呈现与筛选作用域。查询条件与刷新规则见[组合与联动](../../../references/visual-query/references/composition.md)，源码入口见[模板接入](template-integration.md)。

## 选型与用户动线

| 控件        | 适用情形                           | 动线                                             |
| ----------- | ---------------------------------- | ------------------------------------------------ |
| 胶囊平铺    | 少量、高频、短标签的互斥选项。     | 直接选择，当前范围清楚，通过“全部”解除本组条件。 |
| 定制 Select | 选项多、标签长或需要显示分组数值。 | 打开列表，选择整行，收起并显示当前选择。         |

四份基础模板的右上角筛选器各包含至少一组平铺和一个 Selector，最右侧为同高的外观设置三点按钮，复用 `DashboardFilters` 的 `.df-icon` 图标控件与交互；浮窗与持久化见[外观设置](design.md#外观设置)。选项多、标签长或空间不足的分组采用 Selector；桌面尽量保持一行，窄屏允许按控件换行，不通过缩字或压低控件高度硬挤。多选使用明确的多选语义。

## 视觉标准

主页与 deep analysis Modal 必须复用同一套 `DashboardFilters` 组件及 `dashboard-controls-style`，参考[经营概览](../templates/template-business-overview.html)。平铺整组和 Selector 触发器的外部高度均为 **36px**；平铺内部选中面扣除轨道边框和内边距，搜索框与菜单选项行高同为 36px。当前值、hover、选中态和焦点统一使用组件 token。菜单选项与平铺按钮共用半透明白色 hover 底色，悬停只使用柔和内阴影、不添加描边或外部投影，不跟随图表主题色变化；菜单与平铺共用轻微按压、内侧阴影和回弹，按下不切换为深色底，已选项悬停也有反馈，平铺的默认选中面保持白色玻璃，菜单与平铺的选中态均无外阴影；轨道与触发器使用局部反光、单层上沿高光和轻量背景模糊；Modal 内不再叠加模糊。菜单与 Modal 共用近白灰半透明浮层材质，触发器通过光泽与展开态亮度表达状态。箭头使用居中且方向固定的向下 SVG。Modal 的当前分组由右侧 Selector 显示，不另设重复的选中摘要与“清除”按钮。

桌面筛选集中于标题右侧。Selector 使用组件绘制的搜索与选项面板，不能只装饰原生 `<select>` 触发器而留下系统菜单。浮层在视口内定位并独立滚动，打开态与收起态都要验收；搜索不改变当前业务条件。

仅让触发当前请求的控件显示 loading，连续选择跟随最新控件。Selector 的 loading 复用右侧箭头的固定位置，加载时隐藏箭头、原位显示转圈，结束后恢复，不额外占宽；平铺按钮的 loading 仍在文字右侧平滑伸缩，平时不占位。菜单选择后将反馈留在可见触发器上，完成、失败和关闭均能清理。弹窗更新不重复显示“正在更新”文字。

## Liquid Glass 交互细节

参考 Apple 的[材质规范](https://developer.apple.com/design/human-interface-guidelines/materials)、[按钮规范](https://developer.apple.com/design/human-interface-guidelines/buttons)与 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。浏览器实现通过光照、按压及连续过渡表达交互层次。

- 平铺选中面随选择连续滑动，悬停使用统一半透明白底与克制的白色光泽；细指针可驱动局部高光，触屏以按压反馈为主，不添加主题色边框。
- 按下轻微压缩，内阴影比 hover 更强，保持白色底；松开平滑回到原位。控件布局高度为 36px，动效不改变布局、不提前提交查询。
- 菜单从触发器方向展开与收回，选中项以勾选标识和阅读面表达；hover 使用统一半透明白底与无偏移、四周均匀的内阴影，点击沿用平铺的按压反馈，不加深底色。箭头固定向下。
- 快速开关从当前画面接续，旧退场不能隐藏新展开的菜单。切换到减少动态效果时立即收束；透明度降级和控件清理沿用模板。

菜单展开为 180ms，收回为 110ms，按压幅度由 HTML 维护。默认玻璃强度下，内容卡片的 `--glass-surface` 为 60%；外观强度调整材质，交互高光作用于控件层。

## Select 实现与状态

组件接入、搜索、键盘与焦点规则见 [Selector 接入](filter-select.md)。平铺与 Selector 读取同一已确认条件；标签由真实值映射，选项来自完整查询范围，搜索、hover 和移动焦点不提交。动态选项失效时清理选择并同步查询，不能保留已不存在的值。

## 轻量筛选的作用范围

- 全局筛选同步相关汇总、图形、比较基准、明细和 Insight；本期与基期的业务条件一致，时间条件分别应用各自周期。
- 卡内筛选只修改其拥有的条件和查询；“全部”解除本组条件，保留其他条件及指标固有条件。
- 临时 hover 的作用域和恢复见[指标联动](metric-card.md#与图表联动)，分析选择与返回见[指标深入分析](../../../references/deep-analysis/interaction.md)。

可恢复条件通过 Builder 管理，UI 映射选择意图。`whereFilter` / `havingFilter`、条件 ID、事务和恢复遵循[筛选规则](../../../references/visual-query/references/composition.md#筛选规则先于事件回调)。

## 联动更新与双重动画

复用页面的 `applyFilters()`、`requestRender()` 与刷新队列。加载保留原内容与尺寸，旧请求不能覆盖最新选择或提前清除 loading；失败保留原条件重试入口，不能把旧内容标成新结果。就绪后同步提交数字、图表、明细和发现，保留用户折叠状态。

图表复用实例并启用 update 过渡，读数使用[指标动画](metric-card.md#指标文本更新动画)，筛选不重播首次入场。加载时仍可继续选择，减少动态效果时直接落位。状态及生命周期按[共享刷新流程](../../../references/visual-query/references/composition.md#刷新订阅与生命周期)，检查项集中在[验收标准](acceptance.md)。
