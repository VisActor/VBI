# 图表编辑器验收

按本次影响范围检查，对照功能矩阵选择合法配置，以真实操作和独立结果验证。自动检查验证具体约束，视觉与动画过程需截图及中间帧；源码、按钮存在或历史报告不计运行通过。

## 验收 Checklist（共 38 项）

每份编辑器包含 **22 项通用验收＋10 项渲染与动画专项验收＋6 项导出与交付专项验收**，共 **38 项**。局部修改先确定适用项，无关项注明不适用理由；一个检查项内的适用用例全部通过才能勾选，未验证保持未勾选。

本清单记录验收结论，具体运算符、31 种图型和用例边界按[功能矩阵](standard-parity.md)执行；同一用例不因同时涉及控件和渲染而重复计数。新增主动探索入口时，再按[深度分析交互](../../../references/deep-analysis/interaction.md#验收)验证完整链路，不假定编辑器必有分析弹窗。

交付时分别汇总通用项及两组专项的通过、未通过、未验证和不适用数量：**总应检数＝38－不适用数；应检数＝通过数＋未通过数＋未验证数**。多个编辑器分别记录后再合计。

### 通用验收（22 项）

**模板、数据与状态：4 项**

- [ ] **01. 模板适配流程**：复制完整模板、先运行默认图及编辑操作、再最小适配，复用 Standard 能力；用户约束优先，重写能力有原因及替代行为。
- [ ] **02. 完整数据与独立基线**：源字段、类型和完整记录保真；默认 supermarket 的 9,959 行、20 列及销售额 16,068,954.125、利润 2,147,538.925 与独立 CSV 计算一致，换源后建立新基线。
- [ ] **03. 查询与 Headless 能力**：业务操作走公开 Builder，查询与呈现消费同一 DSL；保存的 DSL 注册连接器后可在无 DOM 环境重建相同 Query / seed。
- [ ] **04. 保存与恢复**：serialize / applyDSL 保留字段 ID、编码、别名、聚合、排序、格式、条件、limit 及语言主题，非法恢复保留原有效配置。

**字段与配置：8 项**

- [ ] **05. 字段搜索与过滤**：全部字段可检索和展开，类型及角色条件可组合、重置，无匹配有空态，清空恢复且字段身份不变。
- [ ] **06. 字段点击**：按字段语义加入维度或度量，防重正确，新增或移除不影响其他字段。
- [ ] **07. 四槽与跨角色拖拽**：实际拖入 dimensions / measures / where / having，合法跨角色使用、默认聚合与条件正确，不以 schema 角色禁止合法操作。
- [ ] **08. 插入、重排与跨槽移动**：头、中、尾及任意合法方向移动正确，跨槽转换无旧节点残留，原位放回、取消和拖出不误删。
- [ ] **09. 日期粒度**：原始值及年、季、月、周、日、时、分、秒按支持范围执行，DSL、seed 和可见标签一致。
- [ ] **10. 字段属性与编码**：别名校验、取消、删除、全部支持编码及推荐标识正确，多字段独立排序，切图后推荐编码随 Builder 更新。
- [ ] **11. 度量聚合**：数值与非数值字段的合法聚合及分位参数实际查询正确，不支持的聚合不可选，多个度量彼此独立。
- [ ] **12. 数值格式**：自动或自定义数值、百分比、科学计数、倍率、符号、前后缀、小数位和千分位正确，清除及保存恢复不丢失。

**过滤与历史：5 项**

- [ ] **13. 字符串与数值 WHERE**：比较、集合、关键词、区间及开闭边界、空值按源值验证，先过滤再聚合，合法零不当空值。
- [ ] **14. 日期 WHERE**：范围、相对、当前偏移及期间条件与日期选择器和 DSL 一致，边界记录归属正确。
- [ ] **15. HAVING 与条件编辑**：独立字段及聚合在聚合后应用；两类过滤的编辑、取消、删除、清空、AND / OR 与跨槽转换保留正确语义。
- [ ] **16. 结果上限**：limit 的正整数解析、边界及默认值与 Query DSL 和结果行数一致，不以本地截断代替查询。
- [ ] **17. 撤销与重做**：字段、聚合、过滤、排序、图型和 limit 可经按钮及快捷键恢复，输入框保留原生撤销语义。

**界面与运行状态：5 项**

- [ ] **18. 布局、触控与全屏**：桌面及 390px 窄屏布局紧凑，字段、四槽与工具栏可达，长名称可读；全屏及 resize 正确测量且不改 DSL。
- [ ] **19. 语言与主题**：中英和十套主题同步控件、图表及表格，维度跟随主题、度量绿色、外框中性，柱条无描边接缝，切换不重置分析。
- [ ] **20. 设置与控件状态**：搜索、菜单、拖拽落点、hover、按压和键盘焦点稳定；设置关闭及焦点返回可用，语言、主题和动画偏好刷新恢复，存储失效不阻断操作。
- [ ] **21. 加载、空态与错误**：初始化加载层在首图或合法空态就绪后交接；更新保留旧图并标明忙态，空结果清旧图，无效配置及超时可修正重试，快速编辑只应用最新结果。
- [ ] **22. 生命周期**：切数据源、pagehide / BFCache、反复编辑及退出时，订阅、实例、监听、Observer、请求和文档释放正确，迟到结果不写回。

### 渲染与动画专项验收（10 项）

- [ ] **23. 全部图型可运行**：按功能矩阵逐一用合法维度和度量运行全部 31 种图型，查询、构建、Canvas 及错误状态正确，不能以少数简单图代替。
- [ ] **24. 表格与透视分支**：ListTable / PivotTable / PivotChart 分支、多行列、多指标和原生滚动正确，不以普通表格替代透视布局。
- [ ] **25. 原生图形交互**：Tooltip、图例、选择、透视图图例过滤及竞赛 player / 时间轴与对应图型行为一致，图型面板选择后保持展开且不误触绘图区。
- [ ] **26. 同实例更新**：VChart 通过 updateSpec 保持实例，图型和数据更新按最新请求串行应用，快速连续切换无旧图残留或整页入场。
- [ ] **27. 路径 Morph 过程**：柱条换向、普通／并列／百分比及双轴双向切换采集至少三个不同中间路径，坐标有限、图元连续，结束清理临时图元。
- [ ] **28. 动画边界与淡入**：正值饼环、含非正值饼环、热力、雷达及层级图按各自能力验证；淡入检查透明度变化与稳定几何，不把淡入宣称为路径变形。
- [ ] **29. 数据更新与动画开关**：不同类别的相对数值变化呈现连续补间，关闭再开启 morph 生效，快速打断从有效状态继续，不只用整体倍增验证。
- [ ] **30. 减少动态与透明效果**：减少动态后实际几何直接稳定，减少透明、强制色彩或不支持模糊时控件仍可读可用，不只核对配置字段。
- [ ] **31. 独立终态对照**：与独立新建的目标图比较几何和数据终态，截图等待过渡结束；正确终态或“无报错”不能代替过程验收。
- [ ] **32. 渲染器切换与清理**：图表、表格、透视图互切时解绑并释放旧实例及待执行回调，图例筛选后立即切换不访问已释放资源。

### 导出与交付专项验收（6 项）

- [ ] **33. CSV 与 Excel 文件**：读取真实下载结果，核对别名、筛选聚合值、排序、limit、中文、换行、引号、空值、负数和公式样式文本，Excel 保留数值类型。
- [ ] **34. 数据复制**：实际读取剪贴板内容，与当前已确认查询范围、列名、顺序和格式一致，不复制旧结果或仅可见的局部数据。
- [ ] **35. PNG 下载与复制**：普通图、表格和分面图均能输出，图片只包含当前绘图区，表格按当前视口，下载文件及剪贴板图像可读取。
- [ ] **36. 导出权限与忙态**：空结果及忙态禁用导出，剪贴板权限拒绝有明确提示且下载仍可用，重复操作和失败后控件状态可恢复。
- [ ] **37. 单文件离线运行**：完整 HTML 复制到空目录，在断网浏览器经 file:// 打开，数据、图表、表格、主题和导出可用，无仓库路径依赖、额外 HTTP 请求或未处理异常。
- [ ] **38. 交付证据与清理**：记录本次适用用例、独立核对、实际操作和必要中间帧，说明未验证项；停止自己启动的服务，临时日志、快照和测试工程不进入技能包。
