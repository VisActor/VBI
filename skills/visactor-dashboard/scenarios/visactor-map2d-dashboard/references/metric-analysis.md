# 地图看板指标深入分析

先按[通用指标分析](../../../references/metric-analysis/guide.md)确定指标口径、分析路径、分组控件、VTable 明细、查询生命周期与验收方式。本篇补充地图场景的地域范围、定位行为、入口和视觉规则；业务绑定按所选模板的实际实现调整。

## 地域证据与分析路径

- 区分地域汇总、实体快照与时空事件。地域汇总明确每行的行政层级与统计范围；实体与事件的去重、时间和比较规则沿用通用指南，不把地图上的点位数量直接当作业务实体总数。
- 地域下钻必须有真实父子关系：选择有下级的地域 → 查看下一层及路径 → 到末级后核对记录 → 通过路径返回指定上级。没有父子关系时使用分组筛选，不伪造层级。
- 地图缩放、相机定位和分析下钻分别处理；只有明确选择地域条件时才改变统计范围。标记点击按宿主既定行为定位或筛选，不隐式叠加分析条件。
- 地域身份与坐标按[地图接入](open-street-map.md)处理。比较两期时核对地域覆盖与边界口径，覆盖变化需注明；未定位记录是否计入总体由业务口径确定，不能因无法绘制而静默漏计。

## 入口与地图行为

- 可分析的指标 Card 整块可点击，名称右侧放常驻小型斜向箭头；可分析图表的标题也使用同样图标并打开分析。不依赖 hover 显示入口，不使用下划线。
- 悬停保持玻璃表面，只加深名称、提高箭头清晰度并轻移约 1px；不对所有点击区域统一添加投影、矩形底色或抬升，避免文字区和环图中心出现突兀色块。整卡反馈同步到名称，键盘保留焦点轮廓，减少动态效果时取消箭头位移。
- 图表标题进入分析，主页图例、图元及地图标记保留原有筛选或定位。重点实体或事件的指标卡进入分析，独立定位按钮保留地图定位并避免触发整卡分析。
- 名称、数值、卡片空白与环图中心的命中、键盘操作和对话框行为按[入口与容器接入](../../../references/metric-analysis/guide.md#入口与容器接入)实现。

## 范围与返回

打开分析时继承已确认的地域、类别、指标阈值与时间范围；卡片的 hover 临时读数不改变入口实际范围。层级返回恢复上一级地域条件与选择，只做相机导航不改分析范围。

弹窗内选择仅影响当前分析。关闭后保留主页筛选、地图视野和滚动位置，归还入口焦点；数据快照、自动刷新与请求取消沿用[范围、联动与返回](../../../references/metric-analysis/guide.md#范围联动与返回)，不得因分析关闭而销毁宿主地图。

## 地图宿主的布局与视觉

跟随页面深浅主题，复用宿主的文字、玻璃表面、浮层、焦点和图表 token，材质边界见 [L-Card](L-card.md)。分析弹窗采用足够清晰的表面，不让背景地图干扰阅读。 分组切换复用主页 `control-group`，操作按钮、选择器、菜单和关闭入口使用共享控件类，弹窗样式只负责布局。VTable 通过 VSeed 的公开主题注册接口映射宿主 token，统一表头、正文、悬停与选中；正文保持透明、行间细分隔、数字右对齐，宽表内部滚动。悬停与选中使用低透明度主题色，表头的单元格与同行联动色同时映射，选中遮罩不能遮住文本。列顺序、宽度与格式由宿主明细配置提供。

桌面默认读数与发现位于顶部、图表和 VTable 并排；窄屏纵向排列，标题与关闭按钮始终可达，宽表内部滚动。弹窗约 380ms 平滑上移淡入，标题、摘要、控件、图表、明细按约 55ms 间隔依次入场；分析内容就绪后入场，筛选与滚动不重播。内部更新约 220ms；VTable 整体过渡，不逐行累加延迟。主题同步、布局稳定与系统动效偏好沿用[交互与平滑更新](../../../references/metric-analysis/guide.md#交互与平滑更新)。

## 地图场景验收

完成[通用验收](../../../references/metric-analysis/guide.md#验收)后，再检查：

1. 选择地域、下钻与返回后，指标、图表和明细的地域范围一致；实体快照与事件明细保持各自粒度，未定位记录的统计口径明确。
2. 地图定位或缩放不意外改变分析范围；指标分析与独立定位入口各自有效，图例、标记和主页筛选保留原有行为。
3. 关闭分析后主页筛选、地图视野、滚动位置和入口焦点恢复，快速关闭重开不会回写过期范围或销毁地图。
4. 深浅主题下地图背景不干扰弹窗阅读；桌面与窄屏下地图控件、关闭按钮和分组浮层均可操作。
