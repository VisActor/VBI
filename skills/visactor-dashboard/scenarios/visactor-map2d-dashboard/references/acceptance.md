# 二维地图验收

新页面对照所用模板，修改对照原页面，按本次影响范围检查。自动检查验证具体约束，视觉与交互仍需实际操作和截图证据；源码存在或历史结果不证明本次体验成立。

## 验收 Checklist（共 34 项）

每份页面包含 **24 项通用验收＋10 项深度分析专项验收**，共 **34 项**。局部修改先确定适用项，无关项注明不适用理由；一个检查项内的适用场景全部通过才能勾选，未验证保持未勾选。

通用项核对数据、地图与共用组件，专项实际走通“点击指标名称 → 比较或检验 → 明细核对 → 返回”，不重复检查同一套样式，也不能只点击数字或调用打开函数代替入口验证。

交付时分别汇总通用项与专项的通过、未通过、未验证和不适用数量：**总应检数＝34－不适用数；应检数＝通过数＋未通过数＋未验证数**。多个页面分别记录后再合计。

### 通用验收（24 项）

**分析与数据：5 项**

- [ ] **01. 问题与发现**：主要判断、比较或反证、记录依据和下一步明确；事实、解释与未知分开，证据不足时说明缺口。
- [ ] **02. 完整记录与身份**：完整源记录、稳定 ID、字段类型、合法零与空值贯穿查询、列表、地图和详情，不因漏投影显示为未知。
- [ ] **03. 独立数值核对**：从源数据复算总体及有意义的筛选范围，单位、去重、权重、分母、时间、比率和分位一致，不由可见行或 Top N 估算。
- [ ] **04. 空间比较口径**：位置精度、地域覆盖与聚合尺度支持当前判断，未定位记录及其分母明确，不从收录密度直接推断业务强弱。
- [ ] **05. 查询与可恢复定义**：VBI 统一取数并复用连接和同范围结果，可保存业务条件由 DSL / Builder 管理，恢复后可重建。

**模板与地图操作：7 项**

- [ ] **06. 模板适配流程**：复制完整模板、先运行、再做最小业务适配；用户约束优先，重写能力有原因、替代行为与退化核对。
- [ ] **07. 单文件与依赖**：独立 HTML 在声明的打开方式下可运行，完整业务数据及依赖可获取，联网或离线要求及底图署名明确。
- [ ] **08. 真实位置与地域**：核对实际业务图层的 ID、有效坐标及地域匹配，坐标系和边界来源可追溯，不以代表点或猜测位置冒充真实事件。
- [ ] **09. 全球取景**：跨日期线、世界副本、少量点与当前关注对象取景可读，定位不绕远路，不被卡片和工具遮挡。
- [ ] **10. 密集点与选中**：聚类、单点和确认选择可辨，重要极端记录可达，高亮不因缩放或地图投影脱离位置。
- [ ] **11. 导航与业务范围**：hover 只预览，拖动、缩放、定位和复位不擅改筛选；离开预览恢复已确认状态。
- [ ] **12. 跨入口确认**：从地图、列表和地域控件确认同一对象，范围、读数、图形、选择与记录一致，空结果清除失效对象。

**呈现与共用控件：6 项**

- [ ] **13. 响应式与安全区**：实际桌面、低矮屏和 390px 窄屏保留连续地图区域；resize 后地图、图表、定位及浮层避让正确。
- [ ] **14. 内容可读性**：标题、长标签、图表轴和列表末行完整，页面无横向溢出，宽表内部滚动，完整名称有读取路径。
- [ ] **15. 主题与玻璃层次**：四主题的深浅材质、图表、表格、标记和图例同步，内外玻璃层次与文字对比清楚，外观变化不触发业务查询。
- [ ] **16. 设置与偏好**：主题、玻璃强度、恢复默认和刷新保存正确；设置关闭及焦点返回可用，存储失效不阻断页面或重置视野。
- [ ] **17. 筛选与键盘**：复用分段、Selector 和 loading 控件，搜索、确认、清空、按压与键盘状态正确，浮层优先处理 Escape，触屏操作可达。
- [ ] **18. Tooltip 与说明**：指标、图元和图标说明对应真实对象及当前范围，鼠标与键盘可读取，定位和提示不被卡片遮挡。

**加载、动效与生命周期：6 项**

- [ ] **19. 首屏交接与降级**：加载期保留尺寸并禁用未就绪交互，数据与地图可用帧或明确降级后交接，失败有恢复入口。
- [ ] **20. 入场与原位更新**：地图、容器、标题和控件顺序正确，筛选不重播入场；观察中间态，数字及截图等待有限过渡完成，不只依赖 ready，减少动态直接最终态。
- [ ] **21. 查询竞争与恢复**：实际触发控件有反馈，旧内容保留，快速筛选只提交最新结果；慢请求、失败重试和空结果不冒充新范围。
- [ ] **22. 快照刷新语义**：刷新按 ID 更新并保留用户导航，发生、修订与截止时间清楚，静态快照和既有记录不暗示新增事件。
- [ ] **23. 底图切换与回退**：切换或失败恢复后业务层、相机和筛选保留，资源失败有明确状态，地图回退不阻断可用分析。
- [ ] **24. 暂停与释放**：后台停止无效绘制，退出取消请求、等待和动画并释放地图、图表及数据资源，延迟初始化或迟到任务不写回。

### 深度分析专项验收（10 项）

- [ ] **25. 指标名称点击**：逐一点击可分析指标的名称，只打开一个对应弹窗，标题、数值和单位正确；Enter / Space 有效，无 hover 自动打开或冒泡重复。
- [ ] **26. 入口上下文**：捕获已确认的地域、时间、震级或业务条件及打开时快照，不携带临时 hover；切换指标不残留上一次局部选择。
- [ ] **27. 维度与完整分组**：切换各可用维度、搜索和确认分组再清除，范围正确，Top N 外分组可达，清除回到进入时范围。
- [ ] **28. 比较与新增证据**：默认问题及继续探索提供可核对的比较、解释检验或记录证据，发现随条件重算，不只重复概览极值或放大数字。
- [ ] **29. 图形与局部联动**：图元确认与控件选择一致，读数、发现、图形和明细同轮同范围；局部选择不改变主页条件。
- [ ] **30. 完整明细与导出**：VTable 保留适用的全部记录和原始字段，选择依赖稳定业务键；有导出时读取真实文件核对 ID、行数、空值和范围。
- [ ] **31. 记录定位与复核**：分析和独立定位分别触发，无冒泡重复；保留地震示例时走通审核结构比较、完整待审核队列及快照详情，无候选时禁用定位。
- [ ] **32. 展开与返回布局**：展开明细再返回，图表和表格尺寸及局部状态正确；窄屏可滚动，长内容和关闭入口可达。
- [ ] **33. 异常与重入**：弹窗内慢请求、快速切换、空结果、失败重试及加载中关闭重开均正确，旧响应不覆盖新指标，不遗留转圈或菜单。
- [ ] **34. 关闭与源页面恢复**：关闭按钮、Escape 及声明的外部关闭方式有效，内部浮层不误关分析；键盘和触屏可完成全链路，返回保留主页条件与视野并归还焦点。
