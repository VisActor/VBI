# 验收标准

新建时对照所选模板，修改时对照修改前页面，只验证受影响的路径。用实际浏览器操作，入口存在、静态截图或源码检查不能代替行为结果。

## 筛选更新反馈

用慢请求检查主页、地图指标和弹窗控件：空闲时 spinner 不占宽度，只有实际触发查询的控件在文字右侧展开；图标按钮保持居中，选中、hover、focus、disabled 与四主题一致。局部纯呈现切换不伪造取数 loading。更新期间保留旧内容，成功原位过渡，失败可重试；连续切换、关闭重开和后台切换不遗留 loading 或迟到覆盖。检查数字、图形与完整明细最终对应同一条件，表格不重播入场，重试成功后入口收起。

## 首次体验与对照证据

- 模板与产物采用相同视口、浏览器缩放、主题和动效偏好；地图取景按各自数据范围确定，只有比较底图还原度时固定地图中心、缩放和倾斜角。
- 查看首次加载、稳定首屏、选中对象、分析返回四个状态。保存稳定首屏及相关交互状态截图，记录操作与结果；正常动效另行观察并记录入场顺序与更新表现，不能只用禁用动画的截图验收，也不能把截图设置写死到交付页面。
- 稳定首屏要等有限的入场动画结束，再确认标题、筛选、地图控件和页脚已经可见、可操作。模板的 `state=ready`、`sceneReady=true` 和 `dashboard-ready` 表示开始入场，不表示整套入场完成；不要在这些信号后只固定等待 2 秒便截图。可通过 `document.getAnimations()` 等待非循环入场动画的 `finished`，持续点位动效不阻塞截图；首次体验仍需另看正常入场过程。
- 检查用户实际窗口；未知时记录使用的尺寸，并补看宽屏、低矮屏与手机宽度。确认图表不压扁、页面不横向溢出，控件、浮层、关闭与返回始终可达。
- 分别检查正常默认态、空结果及相关失败路径：首屏不闪空卡片，就绪条件与[布局](layout.md)一致；空指标的显示值、`title` 和可访问名称均按缺失值格式化，不能泄露 `NaN` 或 `undefined`。失败有原因和恢复入口，迟到响应不覆盖重试。不能用简化回退态冒充正常默认态；有意离线交付除外。

## 视觉与信息

| 检查对象   | 通过条件                                                                                                                                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 整体构图   | 地图有连续可读、可操作区域；L 形布局的留白、双容器、筛选与标题位置按 [L-Card](L-card.md)。移除模板残留，概览突出指标和简短发现，不堆重复说明。                                                                                                             |
| 业务名称   | 按选择器与期望名称逐项核对文档标题、地图、指标区、图表、弹窗及导出入口的实际可见或可访问名称；包括主容器外的节点与启动文案。不能仅因 h1 已换便判定模板业务文案已清除。                                                                                     |
| 底图与材质 | 底图能支持当前地域辨识；与叠色、玻璃及排印一起对照，透明、反光和阴影仍有层次，内卡不重复叠毛玻璃，明暗处文字都可读。换成非地貌底图不自动判为退化。                                                                                                         |
| 点位与视野 | 默认范围清楚，重复世界不占主要阅读区；单点、聚类和选中对象可区分，编码与图例一致，聚类不掩盖关注对象。合并定位结果后核对实际业务图层中的实体 ID 与有效坐标集合；不能只凭“已定位”统计通过验收，避免查询漏坐标时全图无点。定位和提示框落在卡片外的可见区域。 |
| 图表与列表 | 标题、单位、标签和数值有足够空间；同类数字格式一致，长标签完整或可通过悬停、焦点、详情读取，列表完整行可读且长内容能滚动。样本均值排行可见有效样本量，少量样本不包装为总体结论。                                                                           |
| 主题与动效 | 逐一验证冰蓝、暖玉、深蓝、黑金完整主题及恢复默认，底图匹配主题明暗，主面板与详情共用材质；地图、控件、图表、表格、弹窗同步主题，浅色内层卡片边界清楚；正常入场按 L-Card 编排，筛选刷新不重播，更新不跳位。减少动态效果直接呈现最终状态。                   |

## 行为等价

按业务语义核对下列动作；模板中不适用的行为注明原因和替代路径，不以按钮数量或模块同名判定继承完成。

筛选后的数字需要等过渡结束再核对。模板 `MapDashboard.createMetrics` 在对应元素上提供 `data-metric-value`（格式化目标值）和 `data-animating`（是否仍在过渡）；等 `data-animating="false"` 后比较显示值与查询结果。`state=ready`、范围标题已更新都不保证数字已到终值，不能取过渡帧判断统计对错，也不要为通过断言而关闭交付页面的正常动画。

| 实际操作                                 | 应观察到的结果                                                                                                                                                                                                                                                           |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 从地域排行或选择器选择同一地域           | 筛选一致，地图定位到可见区，指标、图表和明细同步；覆盖率、缺失值计数也属于相应范围。若另展示原文件全量事实，明确标注全量口径，避免与当前范围混读。清除后恢复对应范围。                                                                                                   |
| 点击构成图图元或图例                     | 适用的类别筛选联动地图、指标和明细，选中态及清除方式明确；标题仍独立进入分析。                                                                                                                                                                                           |
| 从列表和地图选择同一实体                 | 选中与详情一致，有空间反馈；将实际 ID、地域、主值、子指标及类别与源记录逐项核对，不能仅断言详情已打开。已知字段不能显示为“未填写”、`undefined` 或 `NaN`。未定位记录能查看详情，不伪造位置。关闭详情保留确认范围并恢复入口焦点。                                          |
| 选中已定位对象，拖动缩放并暂停／恢复动效 | 正常动效偏好下选中项有涟漪，随相机保持定位；切换对象后旧的选中反馈清除。验证暂停、页面隐藏与减少动态效果的控制，停止动画后仍保留选中态且不妨碍地图操作。仅保留 CSS、静态高亮或相机过渡不算地图动效验收通过。                                                             |
| 导出当前结果并读取下载文件               | 行数与当前导出范围一致；按稳定 ID 将原始业务列与独立读取的源记录逐值核对，至少包含完整、空值、合法零和未定位样本。字段改名与类型转换应明确，空值仍为空值，展示兜底与筛选占位符不能成为原始导出值。仅检查按钮或生成下载链接不算通过。                                     |
| 打开分析、选择分组、返回与关闭           | 每种指标入口均核对主卡与分析总值、单位及缺失值口径；分组显示真实名称，不能被聚合值覆盖成 0、1。分析继承打开时范围，选择分组后的明细与该组一致，内部选择不擅改主页；关闭后恢复主页视野、筛选、滚动和入口焦点。详细检查见[地图场景验收](metric-analysis.md#地图场景验收)。 |
| 切换底图、主题，再刷新                   | 保留相机、筛选和业务图层；统计仍属同一范围，快照刷新不暗示获取新数据。                                                                                                                                                                                                   |
| 连续切换筛选或关闭重开                   | 最新选择生效，旧请求不回写；对象离开结果集时清除失效选择，空结果与查询失败可区分。                                                                                                                                                                                       |

交付简述有意改变的能力、实际验证的尺寸与操作、截图位置和未验证项。无法运行浏览器时明确限制，不把源码检查写成体验验收通过。

重点事件需分别点击标题与卡片内容：标题打开对应指标分析且不定位，内容定位并打开详情且不打开分析；两条路径都验证 Enter / Space、关闭返回和筛选后记录更新。

主题持久化只保存有效主题 ID。选择主题后刷新应恢复主题并采用对应默认底图；手动底图选择不保存。验证无效存储值和浏览器禁用存储时页面正常启动。浅色与深色底图在同一区域均使用单行轻量英文地名，不出现供应商重复标注。
