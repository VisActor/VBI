# L-Card

采用左侧概览、底部分析的 L 形布局时，两区各用一个完整玻璃容器，Card 放在容器里面。

- 页面顶部、左右各留 `20px`，底部留 `28px`。底部空间只放一行居中的 footer，避免额外间距；文案保留数据来源、必要状态和署名，窄屏可横向滚动。
- 不放左上角 LOGO 和名称占位。左侧容器贴齐顶部留白，所有全局筛选集中在地图区右上角并贴齐右侧留白，刷新和设置图标紧随其后；放不下就靠右换行，不散落到标题旁或地图各处。
- 主页与弹窗控件共用一套玻璃样式、底色和模糊处理，以稳定的半透明底色减少背景差异，并跟随深浅主题，高约 `32px`、字约 `11px`，不加边框和投影；少量选项平铺成组，多选项才用下拉，选中态用柔和底色区分。刷新只显示图标，保留提示和键盘焦点。地图标题在控件组下方，缩放和复位可留在地图边缘。
- 先让左侧容器、底部容器依次平稳翻开，无回弹；两者完成后，标题、控件和 footer 再一起淡入。等待期间控件不可点击或聚焦，刷新和筛选不重播；开启减少动态效果时直接显示。

## 玻璃与内容

外层采用透明玻璃、约 `14px` 的背景模糊、柔和阴影和淡淡反光，用同一主题的细边缘收口；默认圆角 `20px`；侧栏由外层统一设置约 `12–18px` 内边距，分组容器内边距为零。以数据点详情卡为材质基准，主面板、详情、设置与分析弹窗共用玻璃底色、边缘、模糊和阴影；内层使用轻量表面。浅色保持白色透光，用轻微底色差、内缘高光和柔和阴影区分容器与卡片；深色避免多层强反光。材质和文字颜色统一使用主题 token，布局组件不各自硬编码 UI 颜色。

侧栏使用两层表面：外层玻璃容器与内部指标／事件卡片。观测概况、震源与目录、重点事件用标题和留白分组，分组容器透明且无边框、阴影。内层 Card 用低透明度渐变增加层次，默认圆角 `13px`、间距 `8px`，不重复叠加毛玻璃；卡片数量由分析内容决定。底部分析 Card 放在同一个容器里，长内容在内层滚动。

主题按完整方案选择：冰蓝、暖玉、深蓝、黑金；材质、配色与渲染明暗由主题定义统一管理。控件选中与悬停文字、图表与图例、分析图表与表格、地图点标和飞线统一消费语义 token。底图只展示适合主题明暗的选项；冰蓝默认使用冰川蓝底图，暖玉默认使用暖纸米白底图，深蓝默认使用午夜蓝，选择黑金时默认使用炭灰；暗色底图首行固定为炭灰、午夜蓝。用户可在当前主题内手动切换其他兼容底图。入口统一放在右上角设置图标内，复用宿主主题和底图管理能力，保留业务图层。主题选择保存在 localStorage，首屏读取有效主题；底图仅保存在当前页面，刷新使用主题默认底图；存储不可用时正常使用默认主题；恢复外观默认值不清空筛选或地图视野。地形明暗反差较大时，仅增强玻璃底色遮罩，保留模糊、反光和柔和阴影。不支持透明效果时使用实色背景。标题、指标和图表随所属容器一起翻开，不给每个小块另做翻转。入场结束后清理临时动画资源。

左栏展示真实指标、单位和当前范围，底栏按需要放构成、排行、趋势或明细，不补造数据。每个指标 Card 与图表名称右侧提供常驻小图标，点击进入[地图指标深入分析](metric-analysis.md)对话框，初始化与窄屏布局见[布局](layout.md)。验收时检查边距、筛选聚合、入场顺序、键盘操作和窄屏溢出。

重点事件卡保留两个独立入口：点击标题进入指标分析，点击卡片内容定位事件并查看详情；两者均支持键盘，标题操作不触发定位。不得用整卡定位替代标题分析或反向覆盖。

弹窗、设置面板与数据点详情共用平滑的整体入场，再按标题、摘要、控件、图表和明细依次延迟出现；分析内容就绪后入场，筛选与滚动不重播。开启减少动态效果时直接呈现最终状态，关闭和键盘操作不等待动画。

VTable 通过[统一表格 token 与适配器](../../../references/visual-query/references/table-theme.md)跟随四套主题，深色表面从文字与强调色派生，避免固定浅色表头。当前范围的完整结果使用虚拟滚动，不显示手工翻页器；切换主题更新已有表格主题，保留数据与列宽。
