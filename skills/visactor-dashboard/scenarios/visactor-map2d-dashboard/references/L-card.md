# L-Card

采用左侧概览、底部分析的 L 形布局时，两区各用一个完整玻璃容器，Card 放在容器里面。

- 页面顶部、左右各留 `20px`，底部留 `28px`。底部空间只放一行居中的 footer，避免额外间距；文案保留数据来源、必要状态和署名，窄屏可横向滚动。
- 不放左上角 LOGO 和名称占位。左侧容器贴齐顶部留白，所有全局筛选集中在地图区右上角并贴齐右侧留白，刷新和设置图标紧随其后；放不下就靠右换行，不散落到标题旁或地图各处。
- 主页与弹窗控件共用一套玻璃样式、底色和模糊处理，以稳定的半透明底色减少背景差异，并跟随深浅主题，高约 `32px`、字约 `11px`，不加明显描边，以方向性高光和轻阴影表达厚度；少量选项平铺成组，多选项才用下拉，选中态用柔和底色区分。刷新只显示图标，保留提示和键盘焦点。地图标题在控件组下方，缩放和复位可留在地图边缘。
- 首屏参考3D的分段节奏，按下述时序依次呈现地图、左侧容器、底部容器与控件。内部 Card 跟随容器，筛选和刷新不重播；开启减少动态效果时直接显示。

## 入场节奏

地图就绪后的整段入场共4450ms，保持最终取景、布局与数据口径。

| 阶段                               | 时间范围    | Token                                                                |
| ---------------------------------- | ----------- | -------------------------------------------------------------------- |
| 从较宽世界视野平滑推近             | 0–2000ms    | `--motion-map-zoom-duration:2000ms`、`--motion-map-zoom-offset:0.65` |
| 左侧容器整体翻入                   | 2100–2950ms | `--motion-card-duration:850ms`                                       |
| 底部容器整体翻入                   | 3050–3900ms | `--motion-card-duration:850ms`                                       |
| 标题、控件、重点事件标注与页脚淡入 | 4000–4450ms | `--motion-controls-duration:450ms`                                   |

三个界面区域进场前各留 `--motion-stage-gap:100ms`，延迟由 CSS 按前序阶段累加。地图渐显 `--motion-map-duration:600ms` 与镜头推近同时开始。相机使用原 MapLibre `easeTo`，从不低于最小缩放的较宽视野推近至原中心、缩放和留白；地图、经纬网、点标、涟漪和飞线共用真实投影，不重建地图或查询数据。准备较宽视野后再等待底图就绪，避免推近一开始露出尚未加载的瓦片。

容器等待时保持 inert，标题和控件等待时隐藏，入场结束恢复普通 CSS 状态，清理临时 will-change。重点事件标注只改变透明度，保留 MapLibre 的定位 transform。用户拖动可接管相机；减少动态直接恢复最终取景。时长和推近幅度直接维护在单 HTML 的动画 token 中。

## 玻璃与内容

容器、Card、详情、设置和控件在[完整模板](../templates/template.html)内复用同一套 CSS。外层承担一次背景散射、局部轮廓光和柔和外阴影，容器与 Card 不画整圈边框，默认圆角28px；内部圆角由外层圆角减去内边距推导，Card 使用独立的透光填充、局部反光与短距离接触阴影，让内外两层在深浅主题下均可区分。深浅模式分别维护光学 token，主题只提供底色、文本和强调色；布局组件不各自硬编码材质。分析弹窗使用稳定的阅读面，图表和文字不被主页透印干扰。浮动控件使用较薄的散射，按压时短暂提亮；材质强度同时协调透色、散射和轮廓光，避免仅增加白色或深色遮罩。光感通过本页 CSS 渐变、阴影与状态过渡实现。

侧栏使用两层表面：外层玻璃容器与内部指标／事件卡片。观测概况、震源与目录、重点事件用标题和留白分组，分组容器透明且无边框、阴影。内层 Card 比外容器更明亮，浅色使用更清晰的白色透光面、深色保留克制亮度差，配合轻阴影增加层次、间距 `8px`，不重复叠加毛玻璃；卡片数量由分析内容决定。底部分析 Card 放在同一个容器里，长内容在内层滚动。

主题按完整方案选择：冰蓝、银雾、深蓝、石墨；材质、配色与渲染明暗由主题定义统一管理。控件选中与悬停文字、图表与图例、分析图表与表格、地图点标和飞线统一消费语义 token。底图只展示适合主题明暗的选项；冰蓝默认使用冰川蓝底图，银雾默认使用银雾灰白底图，深蓝默认使用午夜蓝，选择石墨时默认使用炭灰；暗色底图首行固定为炭灰、午夜蓝。用户可在当前主题内手动切换其他兼容底图。入口统一放在右上角设置图标内，复用宿主主题和底图管理能力，保留业务图层。主题选择保存在 localStorage，首屏读取有效主题；底图仅保存在当前页面，刷新使用主题默认底图；存储不可用时正常使用默认主题；恢复外观默认值不清空筛选或地图视野。地形明暗反差较大时，仅增强玻璃底色遮罩，保留模糊、反光和柔和阴影。不支持透明效果时使用实色背景。标题、指标和图表随所属容器一起翻开，不给每个小块另做翻转。入场结束后清理临时动画资源。

左栏展示真实指标、单位和当前范围，底栏按需要放构成、排行、趋势或明细，不补造数据。每个指标 Card 与图表名称右侧提供常驻小图标，点击进入[地图指标深入分析](metric-analysis.md)对话框，初始化与窄屏布局见[布局](layout.md)。验收时检查边距、筛选聚合、入场顺序、键盘操作和窄屏溢出。

重点事件卡保留两个独立入口：点击标题进入指标分析，点击卡片内容定位事件并查看详情；两者均支持键盘，标题操作不触发定位。不得用整卡定位替代标题分析或反向覆盖。

设置面板与菜单复用220ms整体展开，内容即时可用；分析弹窗与数据点详情保持整体入场和内容分层。分析内容就绪后入场，筛选与滚动不重播。开启减少动态效果时直接呈现最终状态，关闭和键盘操作不等待动画。

VTable 通过[统一表格 token 与适配器](../../../references/visual-query/references/table-theme.md)跟随四套主题，深色表面从文字与强调色派生，避免固定浅色表头。当前范围的完整结果使用虚拟滚动，不显示手工翻页器；切换主题更新已有表格主题，保留数据与列宽。
