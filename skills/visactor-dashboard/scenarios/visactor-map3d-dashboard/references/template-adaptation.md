# 模板适配与维护入口

复制[完整模板](../templates/template.html)并运行，先验默认态、一个国家、四主题、分析及返回，再做最小业务适配。模板使用固定 Three.js 0.170.0、VBI / VQuery / VSeed 0.6.4、VChart 2.1.7、VTable 1.23.1；没有 React 工程或外置业务文件依赖，但不是离线依赖包。

## 单文件代码组织

HTML 内保留数据、样式、资源加载器与应用模块，复制后直接运行，不需要额外构建业务文件。应用模块按数据适配、查询、主屏呈现、主题与动画、指标分析、事件绑定、释放、选择器、地球、启动的顺序阅读。

- `mainText` 维护指标数字、等级图例和说明；`drawOverviewCharts` 将 VBI 结果映射为 VSeed 数据，`overviewSpec` 统一首屏柱图、条图、排行和环图的呈现。`overviewCharts` 按容器 ID 复用 VChart 实例，主题/数据用 `updateSpecSync`、尺寸用 `resize`；释放集中在 `dispose`。子指数顺序与名称只在 `pollutantProfiles` 维护。
- `renderModal` 管理查询、让步与过期请求保护，`renderAnalysisSummary` 负责同步呈现。不要把同步 DOM 提取改成额外异步阶段，或移走原有版本校验。
- `bindUI` 按概览、弹窗、外观、分析和动态偏好绑定事件；`createSelectControl` 管理一个原生 select 对应的自定义控件、观察器和清理。
- `DashboardResources` 内的 `versions` / `resourceSources` 集中 CDN 配置，`loadCandidates` 负责顺序回退；仍分别校验 UMD、完整 ESM 依赖图和同实例 Three 模块。
- 地球 Shader 使用独立多行常量；真实高程、地表着色、纹理和线段构建使用具名函数。`GLOBE_APPEARANCE` 在使用时读取当前主题，避免首次与切换后的视觉参数分叉。`createGlobe` 继续拥有 GPU 实例与释放顺序。
- 启动入口依次初始化分析库、数据集、视图和公开运行接口，再非阻塞初始化地球；`ready` 与 `presented` 仍是不同的生命周期节点。

纯代码整理不改变 DOM、主题 token、动画参数或查询口径。清理 CSS 时按相同媒体条件与选择器确认覆盖关系，不能为归类而移动改变优先级的规则。用同一视口与静止状态比较截图及计算样式，并回归真实控件、完整明细、动效和销毁。

## 控件与增量更新

本模板的内联 `dashboard-material` 维护中性主题配色 token，`dashboard-neutral-themes` 保留场景消费适配：银雾为中性灰白与灰蓝强调，石墨为炭灰与灰绿强调。场景只适配底图、连续数据色阶和风险语义色，不在控件内另写色板。2D 默认深蓝、3D 默认冰蓝；原 `jade` / `gold` 存储值迁移为 `silver` / `graphite`，无效值或存储不可用仍使用原默认主题。

玻璃强度、深浅光学和组件表面直接维护在本模板的内联 CSS。滑块标记放在设置面板内，由`bindAppearanceControls()`管理；连续输入合并到一帧，提交保存到 `vbi-map-glass-strength`，同源页面同步，恢复外观回到60，销毁时清理帧和事件。材质调整不触发查询或地图更新；保持单 HTML，不增加外置材质资源、通用运行时或同步脚本。

`dashboard-query-controls` 与内联 `DashboardUI` 统一主页和分析的控件、加载、数字与尺寸更新，模板复制后仍为单文件。分段选择复用 `.control-group`，图标操作复用 `.control-icon`，不能只给部分业务控件追加外观覆盖。筛选将可见触发控件传给刷新入口；只在该控件文字右侧显示 spinner，闲置宽度为零，出现/收起平滑展开。先让 loading 绘制，再开始查询；保留旧结果，失败显示原因和重试，完成、取消、关闭与后台切换均结束等待。首次分析可用独立 spinner，不重复显示“正在更新”文案。

控件材质按操作层组织：分段轨道和独立按钮使用中性透光底色、细边缘高光与轻阴影；已在玻璃外壳或弹窗内的控件只叠加填色，避免重复 blur。内容卡片压低高光，分析正文使用稳定表面。胶囊与图标按钮保持同心圆角和居中，主题强调色继续用于焦点与业务编码。

`DashboardUI.createControls(root)` 为每组维护一个滑动选中底座，并跟随触发按钮 loading 的宽度变化；不复制选中背景到每个按钮。只观察该组的选中、加载、子节点和尺寸变化，单帧先读布局再写样式，空闲不轮询；动态弹窗创建后挂载，销毁时解除观察。菜单从触发侧轻量展开，按压只做小幅缩放，保留减少动态、减少透明与增强对比度的退化路径。这是 CSS 呈现，不模拟实时光学折射。

数字共用一个 RAF，保留文本和单位节点、跳过相同显示值，并从中途当前值继续；数值格式器按精度缓存。图表原位更新并缓存未变化的基础 spec，VTable 仅替换完整记录、关闭重复入场；尺寸先批量读取，再仅调整变化且可见的实例。减少动态效果与销毁路径继续生效。

`requestMain` / `requestModal` 串行消费最后一次操作；过期失败不能中断新请求。`createSelectControl` 缓存搜索文本并委托列表事件，悬停只改变前后两个选项；快捷国家按稳定键复用按钮。保留原生 select 的值同步、键盘、popover 和焦点归还；这些优化不改变 Three.js 地形、纹理、拾取与绘图策略。

## 数据与分析边界

主屏均值、计数、去重、分组和阈值通过 Builder 表达，查询结果复用于 HTML / Three.js / VSeed。完整记录查询带稳定行 ID，所有结果交给 VTable，不以可见行估算总体。中位数和 P90 使用公开 Builder 的 median / quantile({quantile:.9})，分组排行使用 having / sort / limit。复用 VQuery 已连接数据集，按查询配置缓存结果；稳定 ID 回查只负责还原源字段，不在呈现层自行聚合。

每个分析捕获主页已确认国家；风险分析另叠加 AQI>100 固有条件。切换分析视角清除该视角的局部选择，国家分组包含未标注项及 Top N 外国家，最低样本数只影响国家比较图，不截断分组菜单和明细。来源等级图按原分类，数值分布单独分箱；子指数不解释浓度或贡献。

所有临时 Builder 在 finally 中释放；旧请求不能写回新弹窗。VChart 用 updateSpec；表结构不变时 VTable setRecords 保留列宽，改主题用 updateTheme。关闭时释放当前分析的图、表和动画，保留主屏实例。

## 外观和生命周期

设置中修改主题并持久化有效名称；localStorage 不可用时仍正常运行。恢复外观不清理国家或相机。纯主题变更消费缓存，不重新请求。

对话框每次打开 / 关闭递增独立版本并取消旧对话框动画，退场回调只作用于相同版本，防止快速 Escape 后重开被旧回调关闭。加载完成停止隐藏 loader 动画；销毁关闭对话框并停止全部页面动画。分析视角使用 roving tabindex 与左右 / Home / End 键。

RAF 的绘制中保护避免 OrbitControls change 再调度一帧；每帧和媒体事件均核对 reduced-motion。隐藏页取消活动帧，恢复重置时间基准。销毁依次标记过期、取消监听 / 观察 / 动画 / RAF、释放 controls、几何 / 材质 / 纹理 / renderer、VChart / VTable、Builder、连接器和数据集。异步资源每次返回后检查 disposed，不复活已关闭页面。

初始化更新已存在数据集，避免上次关闭的异步清理未完成而重复创建失败。WebGL 失败或 contextlost 显示真实原因，国家选择、指标分析与明细仍可用；不以静态截图伪装正常三维。

内嵌 `source-csv` 使用 `application/json` 保存完整 CSV 字符串，先 `JSON.parse` 再解析 CSV；格式化工具不能通过添加缩进改变国家字段或生成空白记录。替换后将格式化过的 HTML 内嵌源与原 CSV 逐字段核对。

公共表格 style / script 复用 visual-query 的[共享资源](../../../references/visual-query/references/table-theme.md)。业务源数据与地理 JSON 比代码大，不为“缩短 HTML”删记录；通过全局 token、共享组件样式、SVG symbol、通用分析配置和生命周期减少代码重复。

本轮替代：合成月度物流例子改为真实城市 AQI 快照；移除没有时间 / 关系依据的趋势、运输飞线和主屏大明细表，分别用分布比较、国家代表点、按需分析里的完整 VTable 替代。排版、主题、动效、筛选和释放仍独立验收。

本轮视觉替代：为响应真实地形与科技感要求，平面海陆填色改为 NASA 地表影像 + GEBCO 高程位移 + 自然地表材质、清洁海洋与独立受光云层；AQI 保留在国家代表点，避免整个陆地的热力色掩盖山脉。根据用户最新要求，侧栏改为双层材质，地图改全屏底层，左右外容器以86°侧轴整体翻入，三张内卡随各自容器一起出现；没有数据依据的飞线不添加。

本轮交互替代：系统原生选项面板改为统一 `initSelectControls` / `syncSelectControls` 搜索浮层；`selectControls` 观察 options、disabled、hidden 并同步程序赋值，dispose 关闭浮层和断开观察。模态大面积blur与重复入场改为450ms壳+逐项1500ms的单一编排；`setPresentationPaused` 暂停幕后地球，`afterModalPaint` / 主线程让步为查询与 VTable 争取响应帧。分片不截断数据，原生 dialog 的焦点和退出版本保护继续保留。新增资源与排队任务均需纳入释放。

原始记录查询由 Builder 返回全部匹配稳定 ID，再从 `sourceById` 回查内嵌源记录；所有筛选条件仍由 Builder 执行，完整 12 列与空值逐 ID 保留。缺失 ID 显式失败，不静默跳行。这样避免 23,463×13 字段重复投影和复制。

渲染自适应：正常 GPU 使用384×192高程网格，软件 WebGL 从192×96开始；持续帧耗时超预算才逐级降低网格和像素比，仍保留4K bump与同源高程阴影。旧几何即时释放，不反复升降。静止、后台与弹窗遮挡时停止连续绘制，不能用持续空转换取“有动效”。

175个国家点用一个批次绘制，边界与经纬线分别合并。国家选择只更新 uniform、复用选中圈与标签，不重建地表或重传纹理。hover先屏幕邻近粗筛，再对候选执行真实地形遮挡；拖动期间不做拾取。

数据查询可以先完成，但首次GPU编译与纹理上传必须在加载层退场前完成，再启动慢速翻页。高程与像素预处理分批让出主线程，完成后的首帧与入口动画协调。初始化中途退出也要释放临时renderer及纹理，不只清理已经赋值给globe的实例。

查询缓存只适用于当前不可变数据快照。更新源、schema或连接器必须清空缓存；不能让新数据复用旧汇总。CSV适配只做逐行解析与字段派生，跨行聚合、分位和排行全部交给VBI。

## 参考图地球质感适配 · 2026-10-21

保留 Card、布局、四主题、查询和交互，只调整地球的默认经纬度（25°E / 23°N）、自然地表、分层云影、历史城市夜光、方向性大气和光照。光照随视图构图，不模拟观测时刻的太阳；真实地形仍使用同一高程与35倍视觉夸张。国家控件背景改用已有 `glass-solid` token，防止新大气亮边透过文字影响辨识。

地球光学 token 集中在设计 token 块；材质和切换共用读取路径。深浅两张缓存保留自然地表，四主题通过光源、光晕、夜光、线条和标签 token 变化。不要为切主题重复生成或上传地表。

性能实现：云影在初始化按64行分片烘焙；历史夜光先柔化并按线性亮度打包进地表 alpha，最低128避免Canvas预乘导致RGB失真。地表必须保持不透明，并在采样后恢复 `diffuseColor.a = opacity`。同一次地表采样同时提供颜色和夜光；海洋反射用颜色判别，云层只采样一次、光照在顶点插值。无全屏 bloom。基础路径共4张GPU纹理，两种底图未选中均7次绘制；选中缓存路径的资源与绘制开销见下方“绘图性能”。修改 shader 后需要实测同DPR、同LOD、同相机的基线与产物，不能只凭draw call数量判断流畅度。

可选夜光超时仅取消夜光；不是取消整个地球。纹理归 `ownedTextures` 管理，初始化中途退出和正常退出共用 `releaseGraphics`；每次异步让步后检查状态，不能遗留暂未赋给公开globe的renderer。参考素材出处与历史背景性质须随模板保留。

## 浅色与地图实用性适配 · 2026-10-21

保持六张Card、双层外壳、布局、四主题和原分析链路。浅色原自然影像改为保留影像差异的粉彩浮雕着色，并提高暗部照明，解决浑浊海洋与底部过暗；深色纯地貌保留原材质。地图默认慢转替代静止，确认国家后相机停止但高亮继续；未选中悬停、拖动、弹窗、后台与减少动态时暂停，用户控制仍有效。

`countries` Builder新增 `avg(high)`，其余分组Builder不变。`setSurface`/`setMetric`只更新呈现状态；`updateDataLayer`统一颜色、固定尺度、GPU高度和图例，`syncMapSelection`维护已确认国家摘要。`visibleColor`被柱、点、标签与选中环共用，避免颜色口径分叉。未知国家不生成伪坐标。

175国家柱共享一个InstancedMesh；startHeight/endHeight只在数据或指标切换时写入，逐帧仅更新progress uniform。初次生长1400ms、指标850ms，变化中再次切换从当前插值继续。相机变化不重建柱/底图，近屏幕候选才进行实际地形遮挡测试；背面/轮廓按观察方向隐藏，不改变编码高度。清理包含实例缓冲与共享geometry/material。

两种底图未选中绘制调用均为7，共4张GPU纹理，无额外后处理。相机默认fit由满高改为约87%主体高度；仍保留缩放比例和朝向。性能判断使用实际RAF状态，不能将用户auto意图当成悬停期间持续绘制的理由。

首次柱生长使用growthPending等待地图首次显示，再按地球放大的时长延后启动；放大期间保持零高度，完成后完整生长1400ms。共用单RAF与暂停时钟，容器翻页不暂停地球，加载与GPU预热不能消耗生长时间；减少动态效果直接最终态。地图降级时新图层/指标控件与旋转控件一并禁用，国家筛选与分析仍可使用。

国家边界加强沿用同一真实几何与一个批次；默认/悬停/选中的透明度来自token。hover只设置行政边界uniform，离开、拖动开始和图层切换清除悬停，不触发查询。柱半径统一0.018；点径0.08；这是可读性参数，不改变柱高或数据口径。

## 初始化占位与首屏交接

`dashboard-loading-runtime` 在外部库前执行，`.loading-card` 复用玻璃、前景、强调色 token，不另建主题色板。`stage` 只在 loading 阶段更新真实工作提示，不模拟百分比。场景通过 visibility 隐藏并设置 inert / aria-busy，保持 VChart 和 WebGL 所需尺寸；页面刷新读取保存主题后再绘制加载卡片。

数据 ready 与地图首帧（或可用的地图降级状态）共同触发 `completeInitialPresentation`。`reveal` 合并重复请求，至少显示 800ms 后一次性取消 inert、隐藏加载层；地球先渐显、自转并从小到大平滑放大，完成后再启动柱子生长；容器与控件沿用[运动 Token](design-tokens.md#运动-token)的先后节奏，内部 Card 不单独翻转。首次查询失败不能留下无限加载，统一走 `reportInitializationFailure`。

45秒总期限或最终初始化失败进入错误态，停止旋转/扫光并保留“重新加载”按钮。不要监听每次 script 资源错误就报错：`DashboardResources` 负责候选 CDN 回退，只有最终失败才交给加载层。错误会触发资源清理，但重试按钮归独立加载运行时，不被应用 AbortController 移除。后台暂停装饰动画；减少动态效果显示静态状态。销毁取消期限、帧等待、最短展示定时器及事件订阅，禁止迟到结果揭开已停止的场景。

替代原因：原来的整屏细线和单句大字缺少层次、阶段说明及重试入口；改为主题化加载卡片和明确生命周期。业务查询、地图材质和原有入场时序保持各自职责。

## 蜂窝底纹与循环晶体光效

`createGlobeDetailAtlas` 复用4K高程纹理：R保持原高程，G为地表影像推得的陆海遮罩，B为静态六边形微倒角。每64行让出主线程并检查disposed。地表shader复用此纹理读取底纹，读取的R同时供Three bump中心高度使用，避免额外采样；不创建每个蜂窝网格、不增加纹理或后处理；该陆海遮罩用于装饰，不是行政数据或统计网格。

同一175实例柱批次使用透明侧面、细棱、顶面与上行光带。柱半径0.018，满量程高度0.96（原0.48的两倍）；AQI以500、占比以1为固定分母，不按可见最大值重新归一化。调整满量程视觉高度用于提高比较可读性，不改变值间比例。

`effectTime` 是柱shader和点shader共享的活动时钟，周期6秒，各国家按ID错相。`canAnimateEffects` 统一动效开关、是否已选国家、hover、拖动、聚焦、首次生长、弹窗、后台、减少动态与销毁状态；只有实际允许绘制时累计受限delta。暂停不积累墙钟时间，恢复不跳相。柱高仍仅由startHeight/endHeight和progress插值，光效不写高度或instanceMatrix。

本轮主动替换原分类色实体柱和无循环材质，以满足蜂窝底纹与有生机的光柱要求；卡片的原分类色、查询、布局、筛选、分析与四主题保留。自然地貌改为设置中的背景开关，两种底图均保留数据柱。按用户要求移除样本覆盖模式及首屏图层切换；样本量在Card、摘要与完整分析中继续可用。

选中国家将相机auto设为false，但不隐式关闭光效；`effectsPaused` 只由用户动效开关控制。定位环以三重波纹向外扩散并渐隐、国界轻微呼吸，周期3.6秒，非选中柱收敛透明度；地球悬停允许已选国家循环，未选中悬停则停帧。清除选择且相机停转后停止连续RAF。`setSurface`只更新材质uniform、设置说明和底图偏好，不更新高度buffer或查询；保存失败也可以继续切换。恢复默认外观同时恢复冰蓝和蜂窝。

选中涟漪使用一个CircleGeometry与ShaderMaterial。片元根据半径绘制固定内环及三条错相外扩波纹，波纹在重置前消隐；不逐帧缩放网格、不新建多个环或额外RAF。减少动态只显示固定内环；手动暂停保持当前相位。沿用深度测试，背面不会穿透地球。

## 绘图性能 · 按需计算与静态地球缓存

保持原来的材质、纹理、地形LOD策略、四主题、柱高和动画。VBI查询与分析链路不变，优化范围只在呈现层。

- `columnPalette` 只在主题改变时读取CSS token；国家颜色保存在记录内供柱、点、标签复用。高度attribute仅在值改变时标记上传，不因主题变化重新上传高度。
- `projectionDirty` / `labelsDirty` 分开控制投影与标签布局；标签安全区尺寸在ResizeObserver中测量。相机停稳后的涟漪帧不重新读布局、投影国家或摆放标签。光照只在相机位置、目标或up变化时更新。
- pointermove只保存最新坐标，由既有RAF每帧处理一次；点击仍立即精确拾取。离开画布、后台与暂停清除待处理悬停，避免迟到tooltip。拾取与提示使用同一个canvas rect，保留CSS缩放坐标转换。
- IntersectionObserver在地图离开视口80px范围后暂停RAF与活动时钟，重入时继续。页面隐藏、弹窗、手动暂停、减少动态和销毁沿用原控制；暂停期间不累积动画时间。

`createStaticGlobeCache` 只负责选中国家且相机停稳后的底图复用。捕获默认framebuffer中已经完成色调映射、透明混合与MSAA的RGBA颜色；后续用无颜色转换的全屏三角形回放，再以原地形geometry执行仅写深度的绘制。原国家边界、实例柱、点、涟漪和定位线继续绘制，背面遮挡沿用原地形深度。它不是通用场景缓存：新增移动云层、静态对象或材质uniform时，必须更新静态/动态图层列表与失效规则。

视角、投影、地形geometry、球体变换、drawing buffer尺寸、色彩空间、色调映射和曝光变化自动失效；主题/背景通过`updateSurface`显式失效。旋转、拖动、聚焦和柱生长期间使用原单次场景渲染。视口裁切、XR、外部RenderTarget、对数深度或超过400万drawing pixels时同样走原路径。

缓存延迟分配一张RGBA8颜色纹理，最多16MB；超过尺寸上限即释放，不保留多主题或多尺寸副本。基础4纹理，启用缓存后最多5纹理；基础未选中7draw，选中首次捕获9draw，稳定回放合计7draw。`diagnostics.renders`统计真实绘制帧；`renderer.info.render.frame`因多pass不再代表动画帧率，不能用于性能对比。诊断的`drawCalls`汇总所有pass，`backdropCache`暴露命中、失效、尺寸及内存估算。

缓存shader随初始化预热，预热或捕获失败仅关闭缓存并回退直接渲染。共享球体geometry由原拥有者负责，缓存独有geometry/material/texture在`releaseGraphics`统一释放；context和viewport监听同步清理。使用同DPR、同LOD、同相机的交错对照验证优化，另以四主题截图检查保真；不能用降低画质或只数draw calls代替实测。
