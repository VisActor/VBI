# 三维地图验收

按本次影响范围检查，默认外观对照模板，示例数字对照数据基线。自动检查验证具体约束，视觉、拾取和动效仍需本次操作及截图证据，不沿用历史评分或性能结果。

## 验收 Checklist（共 38 项）

每份页面包含 **28 项通用验收＋10 项深度分析专项验收**，共 **38 项**。局部修改先确定适用项，无关项注明不适用理由；一个检查项内的适用场景全部通过才能勾选，未验证保持未勾选。

通用项覆盖数据、地球与共用组件，专项实际走通“点击指标名称 → 比较或检验 → 原始记录 → 返回”，不重复检查同一套样式，也不能以程序调用或仅点击数字代替入口验证。

交付时分别汇总通用项与专项的通过、未通过、未验证和不适用数量：**总应检数＝38－不适用数；应检数＝通过数＋未通过数＋未验证数**。多个页面分别记录后再合计。

### 通用验收（28 项）

**分析与数据：6 项**

- [ ] **01. 问题与发现**：主要判断、比较或反证、记录依据与下一步明确，核对影响判断的覆盖或样本量，数据不足时说明限制。
- [ ] **02. 源记录保真**：完整源字段、稳定 ID、类型、空值和合法零保留，分批呈现不截断证据，原始记录与聚合表粒度明确。
- [ ] **03. 独立数值核对**：从源数据复算总体及有效筛选范围，公式、单位、权重、分母和分位正确；保留 AQI 示例时对照可复算基线。
- [ ] **04. 样本与指标语义**：来源等级、数值分箱及子指数区别正确，均值和样本量口径清楚，不从样本排名推断人口暴露、因果或治理效果。
- [ ] **05. 查询与可恢复定义**：跨行统计由公开 DSL / Builder 表达，连接及结果复用正确，可保存条件可重建，数据更新使相关缓存失效。
- [ ] **06. 完整范围与覆盖**：未标注及未定位记录保留在适用总体中，Top N、最低 n 和地图裁剪不截断总体或完整分组。

**模板与空间操作：7 项**

- [ ] **07. 模板与单文件**：复制完整模板、先运行、再最小适配，继承适用能力；HTML 保留业务数据和轻量地理索引，网络要求明确。
- [ ] **08. 真实地理身份**：国家边界、别名及代表位置可追溯，微型国家和少量样本可访问，无坐标记录不绘制伪位置。
- [ ] **09. 共同尺度与编码**：数值、柱高、零值、颜色和图例一致，固定尺度不随当前最大值变化；背景、蜂窝和光效不冒充业务统计。
- [ ] **10. 精确拾取与遮挡**：悬停和点击命中正确对象，背面不穿透拾取；CSS 缩放、resize 和不同地表下坐标换算仍正确。
- [ ] **11. 导航与确认范围**：hover 只预览，拖动、缩放和重置视角不擅改筛选；确认国家与清除按业务入口生效。
- [ ] **12. 多入口选择一致**：国家控件、快选、代表点和排行确认同一对象，读数、选择与真实位置一致，未标注记录仍可核对。
- [ ] **13. 指标与背景切换**：切换数值指标、地表或装饰保留相机和选择，业务图层及邻域比较背景仍可见，来源与年代限制清楚。

**呈现与共用控件：6 项**

- [ ] **14. 响应式与内容完整**：实际桌面、低矮屏和 390px 窄屏保留独立地图区，关键行、样本量及返回入口完整，宽表内部滚动。
- [ ] **15. 标签与地图安全区**：标签、选中摘要和 Tooltip 避开侧栏及工具；尺寸变化后重新测量，长名称可读且页面无横向溢出。
- [ ] **16. 主题与玻璃层次**：四主题、深浅材质、强度、地球、图表和表格同步，文字及图形对比清楚，外观不改变业务范围。
- [ ] **17. 设置与偏好**：外观保存、刷新与恢复默认正确，浮层关闭及焦点返回有效，存储不可用或偏好失效不阻断页面。
- [ ] **18. 筛选与键盘**：复用分段、Selector、搜索和 loading 控件，确认、清除与动态选项正确；图标说明可聚焦读取，浮层优先处理 Escape。
- [ ] **19. 图形与 Tooltip**：图表标签、图例、连续色阶和来源分类色正确，Tooltip 对应当前对象及范围，并与动效状态一致。

**加载、动效与生命周期：9 项**

- [ ] **20. 首屏就绪交接**：加载期保留尺寸并禁用未就绪交互，数据、图表、地球可用帧与预热或明确降级后一次性交接。
- [ ] **21. 入场与稳定读数**：地球、数据柱、容器和控件按模板顺序呈现，更新不重播；观察中间帧，截图及数字核对等待有限动画完成，不只依赖 ready。
- [ ] **22. 暂停与恢复状态**：空白画布、地球表面及标记 hover、手动暂停、拖动、确认选择、弹窗、后台、离屏和减少动态分别有效，恢复不跳变。
- [ ] **23. 查询竞争与恢复**：实际触发控件有反馈，保留旧内容；慢请求、快速切换、失败重试和空结果只应用最新结果，不误标范围。
- [ ] **24. 刷新与状态隔离**：刷新遵守声明的快照策略，保留有效选择和用户导航，失效对象同步清理，过期查询或退场回调不覆盖新状态。
- [ ] **25. 资源加载与候选回退**：实际验证首选和全部失败、模块导出、纹理解码与 CORS；换源不混用运行时实例，中途退出不会恢复已取消初始化。
- [ ] **26. 三维降级**：WebGL 不可用、contextlost、地表或纹理失败时明确降级，国家选择、可用分析和明细继续工作，不以静态图冒充交互场景。
- [ ] **27. 性能与缓存保真**：同画质、同视角比较实际帧和响应，静止时停止无效绘制；四主题及相关背景下缓存正确失效，失败回退直绘，不以绘制次数宣称流畅。
- [ ] **28. 资源释放**：反复操作无实例、监听或 GPU 资源无界增长，退出释放拥有的图形、数据及等待任务，临时资源和迟到结果不能复活场景。

### 深度分析专项验收（10 项）

- [ ] **29. 指标名称点击**：逐一点击可分析指标的名称，只打开一个对应弹窗，标题、数值和单位正确；Enter / Space 有效，无 hover 自动打开或冒泡重复。
- [ ] **30. 入口与固有条件**：捕获已确认国家和快照，风险分析保留固有子集，普通国家分析不误带风险条件；不同指标不残留旧选择。
- [ ] **31. 视角与完整分组**：切换国家、来源等级、数值分布和子指数等可用视角，完整分组可搜索选择；最低 n 只影响声明的展示，清除回到入口范围。
- [ ] **32. 比较与敏感性检验**：深入后增加有效证据；保留 AQI 诊断时核对均值、中位数、P90、排除量及并列值，尾部检验保留原基准，不改写源指标。
- [ ] **33. 搜索与质量记录**：原始国家或城市搜索、未标注及质量条件正确更新范围，类别差异与子指数差异保真，切换视角不残留失效条件。
- [ ] **34. 图形、明细与导出**：图元和菜单同一局部选择，发现、图形及完整 VTable 同轮；展开返回保留状态，有导出时读取实际文件核对 ID、字段、空值和行数。
- [ ] **35. 记录定位与显式应用**：选择真实记录后定位对应国家代表位置，无城市坐标不伪造城市点；只有显式应用操作提交主页国家，无可定位对象时入口禁用。
- [ ] **36. 异常与重入**：弹窗内快速筛选、慢请求、空结果、失败重试、加载中关闭和换指标正确，旧查询不覆盖新弹窗，不遗留菜单或转圈。
- [ ] **37. 关闭与操作可达**：关闭按钮、Escape 及声明的外部关闭方式有效，内部浮层优先处理；窄屏、触屏和键盘可完成选择、明细及返回，焦点不困住。
- [ ] **38. 返回源页面**：普通关闭保留主屏国家、视野、读数和已有实例并归还入口焦点；显式应用后按已确认的新国家返回，不重建主页。
