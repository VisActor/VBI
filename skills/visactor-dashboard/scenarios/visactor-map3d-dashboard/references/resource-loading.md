# CDN 资源与网络适配

单 HTML 是交付形态，不要求把数 MB 的第三方库和纹理编码进 HTML。保留业务数据、轻量国家几何与页面代码；大型公共资源可用固定版本 CDN。用户数据不得因为切换 CDN 而上传。

## 先探测，再加载

`DashboardResources.detectNetwork()` 并行探测阿里 npm 镜像与国际 CDN 的小资源，最长等待约 1.5 秒，按实际成功与时延决定 `mirror-first` 或 `international-first`。这是网络链路判断，不是 IP 定位；语言、时区和浏览器地区不能当作国内外网络证据。

- 国内链路优先：`registry.npmmirror.com` 的版本化 npm 文件。
- 国际链路优先：`cdn.jsdelivr.net`，失败回退到 `unpkg.com`。
- 每个资源独立验证导出、跨域和加载结果。镜像响应成功不代表其中每个包都可用；一次探测失败也不能证明用户地理位置。
- 记录 `profile` 中的探测时延、选中供应商和失败原因。所有请求都有时间上限，全部失败显示可理解的错误。

## 区分 UMD 与 ESM

VChart / VTable 使用固定版本 UMD，由 script 实际加载验证。已有正确运行时优先复用，共享表格模块不会重复加载。

Three.js 与 OrbitControls 必须使用同一版本、同一精确模块 URL。OrbitControls 唯一的 `three` import 显式映射；未知依赖不得按字符串前缀盲改。文件需要 CORS，镜像没有跨域响应头时应自动回退。

VBI / VQuery / VSeed 原 npm ESM 含裸依赖，不能把 jsDelivr `+esm` 直接改成阿里域名。使用可处理完整依赖图的固定版本 ESM 服务；VChart 映射到已加载 UMD，避免重复拉取整个图表运行时。国内镜像不能提供兼容模块图时，明确保留国际 ESM 回退，不宣称已经实现完全国内离线运行。

## 地理纹理

NASA 地表、真实高程、历史云图与2016夜光使用公开资源 CDN，保留原始来源与年代。图片设置 `crossOrigin = 'anonymous'` 后再设置 src，确保画布采样与 WebGL 纹理合法。地表、高程或云图解码失败或超时进入三维降级视图，国家选择和指标分析仍然可用。发布到企业环境时可替换为其获授权的国内对象存储/CDN，必须验证 CORS 与原始高程编码。

夜光是可选增强：`earth-night`使用经浏览器解码与Canvas跨域采样验证的NASA灰度图，最多等待6秒；失败只关闭夜光。不得将无CORS的旧NASA镜像或年代不明的其他夜图当作等价的2016备用源。

## 验收

实测两种链路优先顺序、单源失败、全部源失败、ESM 导出和依赖一致性、独立目录 file://、纹理 CORS 与延迟销毁。不得仅凭 URL 拼接正确或 HEAD 返回 200 宣称浏览器可用。

初始化总期限由 `DashboardLoading` 管理（45秒）；候选请求自身的超时和换源仍归 `DashboardResources`。加载卡片展示分析引擎、数据连接、指标与地形准备等阶段，只有最终失败或总期限到达才显示重试。地图正常降级仍可进入数据分析，重试使用页面重新加载，避免半初始化实例复用。
