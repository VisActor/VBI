# 验收清单

新页面验证全部适用项，局部修改只验受影响项；逐页面记录操作、结果与证据，每项全部适用检查通过才勾选。未验证不勾选，不适用注明原因。

## 通用验收（30 项）

- [ ] **01. 发现取证**：抽取主结论，按源记录或查询复算范围、基准和幅度；结果相符，假设单独标识。
- [ ] **02. 数据接入**：逐行对照原始与接入 / 解码数据；字段类型、顺序、精度、缺失和记录数相同。
- [ ] **03. 指标复算**：复算默认及一次筛选；读数、单位和比较结果相符，覆盖去重、零分母、缺失、负值与不可比基期。
- [ ] **04. 查询复用**：抽查加载、筛选、换色和数据替换；取数、基础筛选与聚合经 VBI / VQuery 公开 Builder，衍生值使用同范围未格式化结果；连接复用、原始来源不重复加载，换色零查询，替换使用新数据。
- [ ] **05. 保存恢复**：JSON 往返后用新实例恢复；条件、布局、资源及公式重算结果与保存前一致。
- [ ] **06. 基座对照**：运行模板并对照业务产物；请求改动可用，保留功能无回归。
- [ ] **07. 组件接入**：检查主页、Modal 与列菜单；平铺、Selector 及其他同类能力复用所属公开入口，无按业务字段复制的结构、样式或监听。
- [ ] **08. 独立交付**：仓库外运行单个 HTML；无本地 CSS / JS 依赖，内嵌块与维护源一致，依赖版本符合模板约定；宣称缩减时记录数据 / 实现代码的前后体积。
- [ ] **09. 阅读排印**：对照页头、首屏和展开态；Logo 与标题同行、来源说明位于末尾，中英混排的 DOM、图表和表格共用字体 token；标题、读数、单位可见，同角色排印一致，无重复摘要或操作说明。
- [ ] **10. 响应式**：对照桌面与 390px 完整页面；无裁切或页面横向溢出，宽表仅容器内滚动。
- [ ] **11. 图形提示**：逐图及密集点序列悬停、选择并换色；Tooltip 对应记录值和单位，色阶随值变化，折线点无白边，标签不遮挡。
- [ ] **12. 设置浮窗**：缩窄视口并开关设置；入口最右且无跳位，浮窗不越界，外部点击、Escape、关闭键有效并返回焦点。
- [ ] **13. 主题切换**：在主页及已打开的 Modal 中换色；页面、当前分析及随后打开的 Modal 的图表、表头同步，业务语义色不变。
- [ ] **14. 玻璃强度**：将强度切到 0 → 60 → 100 并遍历 Card、外观设置、Modal、菜单和控件的各状态；阅读面明亮中性、遮罩不造成灰蒙感，Modal 内外 Card 共用细白轮廓及上下内高光，外壳、内卡和控件层次分明、不过曝，输入和选中可辨；减少透明或禁用模糊后仍可读、可操作。
- [ ] **15. 偏好恢复**：修改偏好后刷新、重置，再用无效 / 禁用存储重开；偏好隔离，重置不改筛选，页面可用。
- [ ] **16. 问号提示**：hover、聚焦、触屏打开提示，再逐层 Escape 和重开；引导返回对话编辑，可读、不越界、无残留。
- [ ] **17. 数值动画**：核对默认关闭，开启后连续更新并中途关闭；读数接续，关闭立即达到目标，无额外查询或图表重建。
- [ ] **18. 迷你图**：核对 VSeed 配置、画面与 Tooltip；同页迷你图类型不重复，柱无描边且保留零基线，面积无普通点且不强制零起点，donut 构成可核对；零值 / 负值 / 缺失未改写，常量与单点不制造波动。
- [ ] **19. 临时查看**：hover / 方向键查看后移出或 Escape；仅指定范围变化，随后恢复汇总，无新增查询或筛选。
- [ ] **20. 控件反馈**：操作平铺、Selector、loading 并滚动吸附 / 恢复；全局及分析筛选高 36px，置顶仅显示右侧控件，空白区域不拦截下方点击；平铺选中面投影可见，菜单 hover 清晰、箭头固定向下，控件尺寸不变且无跳位或溢出，回弹可中断，减少动态效果时直接切换。
- [ ] **21. 搜索确认**：用 3 / 4 项列表搜索、清空、重开并换项；搜索框按阈值显隐，无匹配有反馈，确认前无业务查询。
- [ ] **22. 清除显隐**：对未选和可清除选择做 hover、移出、触发器焦点停留、Tab、loading 与禁用测试；仅可清除且 hover / 清除按钮键盘焦点时显示 ×，其余为箭头，loading 优先转圈；图标同位同尺寸，无跳位。
- [ ] **23. 清除范围**：在主页、Modal 清除全局条件，再清局部分组（含 0 / 0.0 值）；其他全局条件及入口业务键保留，局部清除恢复入口范围，各视图同步；不误开菜单或关闭 Modal，触屏可通过菜单清除。
- [ ] **24. 筛选联动**：逐维、组合及清除全局条件，比对实际查询和结果；指标、发现、主图、迷你图、汇总表与原始明细均继承条件，时点、区间及对比基期与标注相符；输入法组合输入不提交，键盘、触屏及 Escape 可操作。
- [ ] **25. 加载恢复**：模拟慢查询与长计算，连续筛选，再失败、重试、空集；主页、Modal 和表格的反馈先于长任务绘制，只提交最新结果，旧任务不清除新反馈。
- [ ] **26. 实例清理**：记录筛选、换色及动效切换的实例创建 / 释放；常规图表经 updateSpec 复用同图型实例，表格原位更新并沿用 VSeed 动效；状态保留、组件不重播入场，减少动态效果时无更新动画；退出后无遗留资源或请求回写。
- [ ] **27. 选区复制**：复制单格、矩形和表头整列并滚到末行；内容 / 格式与完整选区一致，不漏未显示行。
- [ ] **28. 格式总计**：筛选前后复算完整表格总计并滚末行；汇总相符、不增加记录数，数据条随结果更新，无额外外框。
- [ ] **29. 列操作**：左键测试各运算符、零 / 空值、单侧区间、多列交集、排序、草稿及清除；仅本表结果匹配独立查询，提交有反馈，失败可重试。
- [ ] **30. 表格粒度**：对照全局及列筛选、排序前后的汇总表、原始明细和概况；汇总表按声明维度一组一行，明细保留原始粒度，组数与源记录数分别核对，均值与权重有依据；分布、频数和缺失可复算，局部列条件仅影响所属表。

## 深度分析专项验收（10 项）

- [ ] **31. 名称入口**：逐一点击指标名并按 Enter / Space；只打开一个对应 Modal，标题、数值和单位匹配。
- [ ] **32. 全局范围**：筛选并 hover 后打开分析；Modal 上方的全局平铺、Selector 和菜单清晰可见，鼠标、键盘及触屏可实际操作；确认后主页与当前弹窗同步，入口业务键正确，无临时 hover 或上一入口选择。
- [ ] **33. 单元格入口**：点击正文各列，筛选排序后重做；命中对应指标和业务记录，换维度保留入口，表头 / 总计不下钻。
- [ ] **34. 维度分组**：遍历维度，搜索、选择及取消分组；读数、发现、图形与明细同步，Top N 外仍可检索、选择和定位；改变全局条件后保留当前分析维度及入口，局部分组按声明规则重置。
- [ ] **35. 图形联动**：逐一核对趋势、关系图、交叉分析及点选后的查询与结果；图形、读数、关联明细继承同一全局范围，时点指标与区间分析分别核对，关系图每点粒度明确；Tooltip、均值线可复算，单值或配对不足时不伪造关系。
- [ ] **36. 关联明细**：换组及年份等视角后，在 dialog 内筛选、排序、清除；记录与汇总更新，兼容列条件保留，指标图不变，无列概况行。
- [ ] **37. 展开返回**：展开明细再返回；尺寸恢复，分组、列宽及列条件不变，390px 无裁切。
- [ ] **38. 异常重入**：延迟首次、局部及全局查询，快速切换、空集和加载中关闭重开；全局更新失败可在 Modal 内重试并恢复，反馈先绘制，无旧回写、遗留菜单或转圈。
- [ ] **39. 关闭防误触**：以 X、Escape、遮罩关闭，并操作全局筛选、内部菜单、外观设置及从内部拖出；内层 Escape 先关闭当前浮层，内部操作不误关，合法关闭完成退场与取消。
- [ ] **40. 源页保留**：在桌面、390px、触屏、减少动态效果及加载 / 错误态下关闭；同一套全局控件原位恢复，无重复控件、ID、监听或占位残留；最新条件与读数保留，焦点回入口，滚动与实例不意外重置。
