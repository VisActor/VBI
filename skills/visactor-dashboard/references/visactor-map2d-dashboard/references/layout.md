# 布局

## 初始化与首屏切换

初始化复用宿主的加载组件，统一阶段提示、未知进度、超时重试与退场状态；标题、准备任务和就绪条件按当前页面配置。

- 全屏加载层独立于主屏布局，中央卡片沿用页面主题；依次放置圆环、看板名称、阶段提示和细进度轨道。提示预留高度，未知进度用循环扫光。
- 主屏用 `visibility: hidden` 保留布局尺寸，以 `inert` 禁用交互；数据、字体与布局就绪后，按实际尺寸更新地图和图表。
- 先确定地图是否阻塞首屏：任务必须依赖地图时等待完整就绪；指标和列表可独立阅读时，地图超时可先显示数据。恢复时沿用当前筛选；已进入失败状态的初始化，重试后再开始，避免迟到响应覆盖新一轮。
- 就绪后加载层约 360ms 淡出并退出交互，解除主屏禁用，衔接 [L-Card](L-card.md) 入场。后续刷新只更新局部；减少动态效果时直接切换。
- 启动超时或关键数据失败时，停止加载动效，保留原因与重试按钮；退出时清理计时器和监听。

## 布局骨架

1. 沿用所选模板的布局骨架；桌面优先采用左侧概览、底部分析的“L”形布局，先确定连续的地图展示区，再安排卡片数量与尺寸。
2. 桌面地图作为独立底层铺满展示区域，卡片与控件悬浮其上；地图容器尺寸不随卡片内容变化。
3. 全局筛选集中在地图区右上角并贴齐右侧留白，刷新和设置图标紧随其后，空间不足时靠右换行；标题排在控件组下方，避免互相遮挡。
4. 左栏集中概览与关键指标，宽度设上下限；底栏放构成、趋势、排行或明细，按内容分配宽度，明细优先获得更宽空间。
5. 左栏从顶部统一外边距延伸到页脚上方；右侧扣除控件、页脚与间距后分配地图区与底栏高度；底栏横跨整页时位于左栏下方，从左栏右侧展开时与左栏底边对齐，均须给地图保留可用高度。

## 尺寸与避让

6. 页面外边距与入场顺序统一按 [L-Card](L-card.md)，同排卡片等高；先为标题、操作和注释留位，再让图表与表格填满剩余空间，Grid / Flex 子项设 `min-width: 0`、`min-height: 0`。
7. 按顶部控件、左栏和底栏的实际占位计算地图可见区域，布局变化后同步更新；地图居中、范围适配与定位围绕该区域，标记和弹窗避免落在卡片背后。
   首次布局、主动定位和复位才调整视野，自动刷新保留用户视野；尺寸变化时 resize 并重算避让。全球点位按当前中心处理跨日期线和世界副本，避免定位绕远路。
8. 缩放与复位可沿地图边缘布置，全局筛选仍留在右上控件组；状态和来源署名收进底部单行 footer。

## 响应式与验收

9. 低矮屏可让长列表内部滚动；窄屏或高度不足以同时容纳地图与卡片时，切换纵向布局，保留独立地图区，顶部控件允许换行，卡片按最小可用宽度重排为两列或单列，明细可跨列，避免压扁图表。
10. 验收宽屏、低矮屏和窄屏：地图主体可见，标题与操作完整，长内容不撑破卡片，页面无横向溢出；纵向布局允许页面滚动。
