# 工作台视觉规范

[完整 HTML](../templates/template.html) 是视觉基线；[桌面](../templates/desktop.png)与[窄屏](../templates/mobile.png)展示可运行默认态。

- 桌面 236px 字段区配弹性主工作区；主区依次为工具栏、四槽和大幅图表。700px 以下纵向排列，字段列表独立滚动，工具栏局部横向滚动，页面本身不横向溢出。
- 淡灰紫背景与白色阅读面，1px 弱边界，强调色集中于主要操作和图形。品牌栏、字段和操作区有稳定层级，避免额外装饰挤占绘图区。
- 用户要求去掉外围宣传、数据源条、额外操作按钮、CSV 上传、色板、配置面板、图表标题 / 副标题、结果数量 / 悬停说明 / 成功状态和 Live Preview 标签；编辑区直接接在品牌栏下方。保留图表工具栏中的图型、上限、history 与全屏；中英语言及外观放在工具栏全屏按钮右侧的设置面板。绘图区填满余下空间；页脚仅保留右对齐 `Powered By VisActor`，高约 21px，不另外占用大块留白。提示用自然语言解释操作与结果，避免展示函数名、内部图型代号或框架名称。
- 完整字段可搜索、展开、筛选，四槽保持维度 / 指标 / 明细过滤 / 结果过滤的语义。拖入位置、选中、可编辑、删除、加载和无数据状态清楚，长字段仍有读取路径。
- 设置面板提供浅色经典 / 朝霞 / 花园 / 典藏 / 冰蓝 / 樱粉、深色经典 / 午夜 / 极光 / 石墨共 10 套主题，默认 VSeed 原生浅色。主题卡片仅用底色和四色色点预览，同步选择明暗模式和配色，不另设深浅色开关；提供选中状态、键盘焦点、Escape / 关闭按钮 / 点击面板外部关闭和焦点归还。窄屏面板限制在视口内，可独立滚动。
- 颜色通过 CSS `--accent` 与 VSeed `color.colorScheme` 驱动；图例、坐标、tooltip、格式和单位沿用原生图型。多系列色彩可区分，主题切换同步控件与 Canvas，不能只改页面背景。
- 配色只改变填色，不给堆叠柱 / 条增加描边；通过 VSeed `barStyle.barBorderWidth: 0` 保持接缝干净。界面边界使用随明暗适配的中性色，不按主题染色。
- 表格沿用 VSeed → ListTable / PivotTable / PivotChart，保持完整透视布局与原生滚动；不以普通 HTML 表格替代，也不把入场透明帧当作正常对比度。
- VChart 更新保持实例与 morph：普通更新使用 650ms cubicInOut，可配对图元使用引擎原生路径变形；不强制统一图元标识，VChart 2.1.7 跨图元 morph 的真实时长不受此 650ms 完整控制。页面首次入场采用约 2.5 秒的分层节奏：品牌先归位、细线展开，字段区从左侧进入，工具栏 / 四槽依次归位，绘图区带轻微缩放从下方展开，图形再由下向上揭示。用高阻尼感缓动收尾，不模糊文字、不旋转分析区域。首个指针、键盘或焦点操作立即结束入场，避免拖拽目标移动；动画仅首次挂载播放，完成后不保留 transform / clip-path；筛选、切换语言或主题不重播整页。reduced-motion 直接最终态；全屏和 resize 后重新测量。
- 查询错误与空结果覆盖旧图而保留配置；导入错误保留有效 Builder。错误、焦点、弹层和 tooltip 均不能被外壳遮挡。

以相同数据、视口、缩放核对默认态、环图、表格、深色、空态与窄屏。除动画结束截图外，保存 morph 中间帧，核对实例复用与真实变形。[验收矩阵](standard-parity.md)负责行为证明，截图负责人工阅读质量。

动效参考 Remotion [动画组合](https://www.remotion.dev/docs/animation-math)与 [TransitionSeries](https://www.remotion.dev/docs/transitions/transitionseries) 的错峰、重叠及高阻尼时序思路；在单文件中用 CSS keyframes 实现，不引入视频播放运行时。验收时保存确定性时间轴中间帧并验证中断、最终态、无重播与 reduced-motion。

Header 仅保留自绘四格几何占位标识和“自助式分析”（English 为 Self-service Analytics），不放外部品牌、工作空间路径或右侧标语。冰蓝 / 樱粉使用同色系浅至深色阶，朝霞使用灰紫至珊瑚粉的连续色盘；控件强调色单独保证可读性，不能将其覆盖到首个图表系列。预览从完整色盘等距抽取 4 色，图表使用完整色盘。

花园使用 `8F7289 / ED7B61 / 29A15C / 529AC9 / D5B2BD / F6B09C / 9CCBA7 / 99BADF`；典藏使用 `073F7F / 866AA3 / BE0E23 / F49600 / 83A0BE / C1B7CF / E18791 / F9CB80`，替代原浅色青瓷与杏茶，浅色与深色独立选择。

深色第一项“经典”使用 VSeed 原生深色主题：预览色通过公开 `darkTheme()` 读取，渲染不覆盖 `color`，保留原生分类 / 连续色阶。午夜采用蓝灰层次与蓝青金色，极光采用中性紫灰层次与紫青绿，石墨采用中性炭灰与橙青蓝；主题明暗 / 图表交互仍走 Builder。页面初始默认 VSeed 原生浅色，不因为深色区顺序而改为暗色。名称统一为“自助式分析” / “Self-service Analytics”，包含 Header 与浏览器标题。

浅色第一项“经典”与深色第一项对称：通过公开 `lightTheme()` 读取预览，使用原生浅色强调色 `#8D72F6`，渲染不覆盖分类 / 连续色阶。默认外观为 `classic-light`；切换到原生深色时选择 `classic-dark`。
