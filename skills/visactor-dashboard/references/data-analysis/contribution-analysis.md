# 变化贡献分析

回答同一口径下两期净变化由哪些部分组成。贡献是算术分解，不能直接当作变化原因。

## 数据契约

- 明确事实粒度、唯一键、可加指标、单位及前后两个可比期间。
- 分组必须互斥且覆盖分析总体；缺失分组使用明确的未分类项，不能静默丢弃。
- 两期使用一致的业务筛选、状态、币种与时间边界；部分期间需声明覆盖差异。
- 去重计数、均值和比例不能直接套用可加金额的分解规则。

## 计算规则

1. 每组变化 = 后期值 − 前期值。仅一期出现的组，须区分另一时期确为零与数据缺失。
2. 净变化 = 所有组变化之和 = 后期总计 − 前期总计。
3. 正向贡献为正变化之和，负向贡献为负变化之和；分别展示增减与抵消。
4. 切换分组后重新计算正负贡献。分组粒度会改变抵消程度，但不改变同一总体的净变化。
5. 净变化接近零或为负时，贡献率可能不稳定或反直觉；优先给出带符号绝对变化，并明确比率分母。

## 查询与可恢复状态

保存指标、聚合方式、两期边界、分组维度、筛选范围、缺失处理及方法版本。公开查询分别获得两期分组结果，按完整组键对齐；派生关系保留两期值、差额和来源覆盖。

在 VBI 集成中，方法规则属于 DSL / Builder；适配器负责字段映射，宿主消费可重算的查询结果。图形 Top N 不得截断总体计算与完整证据。

## 分析与证据

可用带符号条形或桥图展示贡献；只存在正变化时如实展示。结合国家、产品、状态等真实维度检查抵消。明细保留原事实记录与期间归属，派生差额不能伪装成原始交易。

## 继续分析的动线

- 从净变化进入，先展示基期、本期与完整分组差额，再用桥图或带符号条形解释各部分如何连接两期总计；从单期金额进入，则先回答该期金额集中在哪里。
- 每个分组同时保留基期、本期和差额，避免只显示变化大小而隐藏原有规模。切换维度后重新计算正向、负向与抵消，不复用上一个维度的结果。
- 若只展示主要贡献者，剩余贡献需汇入有符号的“其他”，并保持总差额可对账；不得分别裁掉小额正值和负值后声称完整解释。
- 选择某组后，读数、发现及两期原始证据一起变化；两期应用同一业务条件，不能只过滤某一期。

## 结果一致性与验收补充

可在记录级投影基期金额、当期金额与带符号贡献，但必须保留源记录键和期间，不将投影行称为跨期配对交易。贡献之和由各分组差额计算；桥图起点和终点分别表示两期总计。

深入分析按需查询已确认入口范围，分组菜单覆盖完整成员而不受图形 Top N 限制。快速切换只允许最新请求提交；结果未确认时不导出候选范围，重试应重放失败的两期条件。

最小复算例：两组变化分别为 +30 与 −20，净增为 +10；换成更粗分组后可能只见 +10，但总体变化不能改变。

## 解释边界与稳健性

- 两期差额可分解并不意味着基准可比：核对覆盖天数、季节位置、币种、状态口径及来源更新。组织或分类变化时提供共同映射，不能把重分类当作业务增减。
- 定位“主要贡献者”后核对其基期规模、样本覆盖和极端记录影响；必要时用另一个合理期间或分组验证结论是否稳定。金额口径未变时不能为得到更平滑的变化而删去异常订单。

## 验证

核对分组变化之和与总差额一致，正向与负向贡献之和等于净变化。覆盖负值、空期间、单期分组、零净变化、缺失维度及浮点误差；验证两期同条件、切换维度重算和状态恢复。
