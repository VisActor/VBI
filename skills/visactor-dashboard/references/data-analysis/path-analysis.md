# 路径分析

回答真实事件序列如何分流、重复与终止，并区分图形展示截断和记录结束。

## 数据契约

- 必须有会话或实体键、稳定事件键、可排序时间或序号，以及节点映射规则。
- 声明会话边界、排序平局处理、重复事件规则和观察覆盖；仅有日期时不能伪造精细时间。
- 没有用户 ID 时不能报告独立用户或复访；没有成交事件时不能推导购买转化。
- 选择会话总体后保留其完整序列；若有意按事件范围截断，须声明路径含义已改变。

## 计算规则

1. 验证事件唯一性与会话内顺序，构造完整路径，保留重复浏览及真实事件属性。
2. 按步骤分层构造节点与边，避免重复类别导致分层流图出现环。
3. 声明边的度量是事件次数、转移次数还是去重会话数；不同口径不能混用。
4. 展示深度之外标为“后续步骤”，已观测序列结束标为“记录终点”。没有退出证据时不能称真实退出或流失。
5. 图形可以限制深度或 Top N，但完整序列、总体计算及证据查询不得同步截断；省略分支需有明确归并。
6. 边数相加不能直接作为会话数；平均路径长度使用完整事件数与完整会话数计算。

## 查询与可恢复状态

保存会话键、事件排序、节点映射、入口规则、会话筛选、观察边界、深度和度量。可注册前缀边与终点关系供查询，同时保留可追溯的完整序列。

在 VBI 集成中，路径规则由所属 DSL / Builder 承担，公开查询支持节点、边、会话及事件明细；Sankey 等具体绘制由宿主完成。

## 分析与证据

检查入口分流、常见前缀、重复节点与展示截断率，可按真实来源及期间比较。会话明细应保留完整事件序列；点击量不能以会话明细行数替代。比较不同期间前先核对覆盖完整性。

## 继续分析的动线

- 从节点、边或前缀进入时，筛选包含相应路径条件的完整会话，再查看其完整序列；不能只取匹配事件而丢掉该会话前后步骤。
- 继续看“多少会话到达第 k 步”：到达率 = 长度至少为 k 的会话数 ÷ 当前完整会话数，曲线使用固定会话总体。它反映已记录浏览深度，不代表购买转化或真实存活率。
- 重复浏览指标须声明重复的是类别、商品还是精确事件，并按完整序列判定；只重复类别不能等同重复商品，也不能据此推断购买意图。
- 改变图示深度只影响截断数量；继续比较入口、来源与月份时，仍使用同一会话集合与完整路径。会话量、点击量、平均长度分别标明单位。

## 结果一致性与验收补充

前缀关系、步骤边和会话明细的粒度不同：选择边时通过会话键回到会话总体，先去重会话，再统计完整事件。展示截断率的分母是所选完整会话数，不是可见边数。

保存路径选择的字段语义及步骤，不保存图形节点的临时下标。异步下钻和导出捕获同一入口范围；清除仅释放局部路径条件，保留原业务筛选。

最小复算例：三条路径长度为 1、3、5，第 3 步到达率为 2/3；展示前 3 步时仅长度 5 的路径为“后续步骤”，总体事件数仍为 9。

## 解释边界与稳健性

- 序号断裂、事件重复、采集版本变化或某来源覆盖不足会改变路径，不应未经核对就解释为真实分流或退出。记录缺口与合法跳步分别标注，不凭空补事件。
- 对会话划分、类别映射和展示深度区分处理：前两者可能改变分析总体或路径，后者只应改变呈现。合理变动后检查主要分流是否稳定；仅在有精细时间与业务依据时试验会话超时阈值。

## 验证

核对完整路径长度之和等于事件总数，验证前缀节点与边的流量对账。覆盖单步、重复类别、排序平局、序号缺口、长路径、截断与记录终点；验证改变展示深度不改变完整总体，筛选与状态恢复保持一致。
