# 数据分析方法

从业务问题选择计算方法，形成可复算的证据与有边界的判断。适用于独立分析、分析页面和看板；已有页面局部修改只重审受影响的口径与证据。

本目录负责数据契约、计算、解释与验证；按需展开的入口、Modal 和返回规则见[深度分析交互](../deep-analysis/interaction.md)，查询与渲染见 [visual-query](../visual-query/guide.md)。不依赖特定模板、示例数据或界面运行时。

## 明确问题与数据条件

- 明确谁使用结果、要判断或核查什么，以及已知目标、可控因素与约束。缺少会改变结论的关键定义时澄清，其余可继续取证。
- 确认事实粒度、稳定业务键、单位、公式、时间覆盖、维度、来源版本及缺失项；区分实体快照、事件和汇总。没有历史不生成增长，没有真实层级不生成下钻。
- 为主要问题确定比较基准、候选解释，以及支持或推翻判断所需的证据。探索可以否定最初假设；数据不足时明确可回答的部分与缺口。

## 按问题选择方法

只读取当前问题需要的方法；九种方法不是页面必须凑齐的模块。普通趋势或两期比较可直接按下文的可比口径计算。

| 问题                                 | 方法与数据条件                                                             |
| ------------------------------------ | -------------------------------------------------------------------------- |
| 哪些维度组合存在差异，总计代表什么？ | [多维透视](pivot-explorer.md)：事实键、行列维度、合法聚合及可加性          |
| 哪一步流失，转化是否已成熟？         | [有序转化](conversion-funnel.md)：真实阶段顺序、实体键、转化窗口           |
| 哪些批次持续回来，观察期是否充分？   | [同期群留存](cohort-retention.md)：入群规则、后续事件、队列分母与成熟期    |
| 方案与对照差异有多大，证据是否充分？ | [实验比较](experiment-comparison.md)：分配单位、组内计数、指标与检验假设   |
| 距目标多远，缺口被哪些超额抵消？     | [目标完成度](target-attainment.md)：真实目标、共同粒度、期间与版本         |
| 增减来自哪些部分？                   | [变化贡献](contribution-analysis.md)：可比两期、互斥可加分组               |

## 数据形态与比较口径

- 实体按稳定键计数，事件区分发生、修订与截止时间；比较使用明确时区、可比覆盖和同类条件。不完整期间与未覆盖记录单独说明。
- 总体从完整有效范围重算，不平均分组均值，不累加重叠分组去重数。比率合并同范围分子分母，均值保留权重；必要时区分构成变化与组内变化。
- 保留合法零、负值与缺失语义。空范围计数为 0；无定义的均值、极值和零分母比例显示缺失。中间计算保留精度，仅展示时舍入。
- 变化说明基数，区分百分点与相对百分比；方向是否改善由业务定义。Top N、抽样和分批加载明确覆盖，不以可见行估算总体。

## 发现、解释与行动

重要发现应说明：**哪个范围、相对什么基准、差异多大、依据在哪里。** 必要的样本量、分母、权重、数据时间和限制就近呈现。

- **事实：** 来自实际计算，图表与记录能核对到相同范围和粒度。筛选变化后重算发现，旧文案不能描述新条件。
- **解释：** 区分关联、候选原因和已验证原因。检查可用的替代解释，例如样本构成、覆盖、缺失及极端值；合理口径变化使判断反转时予以说明。
- **行动：** 给出证据支持的下一步，可以是复核、补采、继续观察或业务动作。效果预测、优先评分、成本与阈值须有定义和依据。
- **停止：** 问题已被足够证据回答时停止扩图；没有可靠发现时说明限制及需要补充的字段、历史或覆盖。

模型总结只消费已计算的数值、公式、范围、比较结果及有效性，不猜测缺失指标。图表种类、统计量数量或最高／最低摘要不能单独证明分析深度。

## 查询与可恢复定义

在 VBI 集成中，通过公开查询执行聚合与筛选，按 [visual-query](../visual-query/guide.md)复用查询。单条记录映射与对齐后的标量公式可由调用方衔接，不用页面内重复聚合替代查询；可加透视总计的适用条件见[多维透视](pivot-explorer.md#查询与可恢复状态)。

可保存、重算或跨宿主复用的方法、指标、条件、参数和关系属于所属 DSL 与公开 Builder；适配器负责字段映射，UI 负责临时选择和绘制。本目录定义方法契约，不表示现行 Builder 已实现全部方法。能力缺失时说明计算边界，不虚构 API，也不把不可恢复的页面算法包装成已有领域能力。

保存稳定业务键、来源与必要版本，而非图形下标。恢复后校验兼容性并重算；仅保存结论文本不能替代可重算定义。具体接口按需查 [VBI](../api/vbi/guide.md)。

## 验收

1. 结果回答明确问题，比较基准和结论强度与数据能力相符；没有可靠发现时说明数据缺口。
2. 用独立源记录或查询证据复算总体及有意义的筛选范围，核对粒度、分母、权重、缺失、成熟期和来源覆盖。
3. 按对应方法检查守恒、对齐、去重或统计假设；关键解释核对可用反证，不能从关联直接写成因果。
4. 承诺保存恢复时验证定义、条件和结果的往返一致性；完整证据不因 Top N 或分批加载被静默截断。
5. 有交互交付时另按[深度分析验收](../deep-analysis/interaction.md#验收)及宿主呈现规范验证；无 UI 的查询和计算不要求创建 Modal。
