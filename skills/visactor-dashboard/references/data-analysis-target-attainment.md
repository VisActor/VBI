# 目标完成度

回答实际与同口径目标相差多少，同时揭示缺口与超额，避免净额掩盖结构差异。

## 数据契约

- 必须有真实目标来源、实际来源、可比期间、业务实体、单位与指标口径。
- 实际与目标需在共同粒度对齐；目标表的键与版本必须明确，禁止一对多连接重复分摊目标。
- 记录目标版本、适用范围和生效时间；没有版本证据时不能编造计划版本。
- 区分缺失目标、合法零目标和无实际记录。不能按实际值的任意比例生成目标。

## 计算规则

1. 在共同粒度对齐实际与目标，保留来源覆盖及未匹配状态；跨粒度分配需有明确业务规则。
2. 可比实际仅取目标已知且口径一致的记录；同时披露未覆盖实际与目标，避免只展示已匹配部分。
3. 总完成度 = 可比实际之和 ÷ 对应目标之和，不平均各行或各组完成百分比。
4. 目标合计为零时完成度无定义；保留差额和零目标状态，不用极小常数替代分母。
5. 每个可比单元差额 = 实际 − 目标；缺口 = max(目标 − 实际, 0)，超额 = max(实际 − 目标, 0)。
6. 净差额 = 超额合计 − 缺口合计。先确定核算单元再求缺口，改变粒度会改变抵消程度。
7. 负目标、反向指标与阶段进度需单独声明业务语义，不能套用普通销售目标的“越大越好”。

## 查询与可恢复状态

保存实际与目标引用、共同键、期间、版本、覆盖规则、核算粒度、差额方向和筛选范围。派生关系保留配对值、覆盖状态、零目标、缺口及超额。

在 VBI 集成中，目标配对与一致性规则由所属 DSL / Builder 表达；适配器负责源字段映射。完成度、明细与导出共享公开查询定义。

## 分析与证据

并排比较实际与目标，保持共同数值基线；按真实维度检查未达与超额分布。明细保留原始配对字段、目标版本及覆盖状态，不能将缺失目标改成零。

## 继续分析的动线

- 完成度入口先核对可比实际、已知目标及覆盖率；销售入口可以包含无目标记录，两者总体不同，应明确披露，不能将全销售总计直接作为可比完成度的分子。
- 净差额入口继续查看未达目标缺口集中在哪些实体或分组，同时单列超额，避免总完成度超过 100% 就认定没有短板。
- 分组缺口有两种问题：先在核算单元计算再汇总，回答“全部未达的规模”；先分组相抵再计算，回答“该组净缺口”。同时支持时分别命名，不暗中切换。
- 比较实际与目标采用并列或共同基线表达，不堆叠为相加总量。跨产品、地区或计划版本查看时，保持共同核算粒度。

## 结果一致性与验收补充

配对关系同时暴露目标已知、缺失和零目标数量，明细可追溯到两侧来源键；覆盖状态与绩效状态分别表达。图形只显示主要缺口时，完整缺口合计仍覆盖全部核算单元。

切换范围或版本后重算配对与分子分母；金额读数、覆盖说明、差额发现及导出使用同一已确认结果。保存数据及计划版本，恢复时检查兼容性，不把旧版本汇总继续当作当前计划结果。

最小复算例：两个单元目标均为 100，实际分别为 80 与 140，则总完成度 110%、净超额 20，但缺口仍为 20、超额为 40。

## 解释边界与稳健性

- 区分同期已生效计划、最新修订计划和事后调整计划；同一实际值对应不同版本时完成度含义不同。无历史版本时披露限制，不声称已还原当时目标。
- 检查目标缺失是否集中于某地区、产品或期间，并同时披露已覆盖实际占比与记录覆盖；不能仅凭高记录覆盖推断金额覆盖充分。进度比较使用同周期实际与目标，不能无依据将全年目标按天线性分摊。

## 验证

核对可比范围、目标版本唯一性、连接基数与分子分母；验证超额减缺口等于净差额。覆盖零目标、缺失目标、无实际、空范围、部分期间和跨粒度数据；筛选及恢复后重新汇总完成度，不能沿用旧比例。
