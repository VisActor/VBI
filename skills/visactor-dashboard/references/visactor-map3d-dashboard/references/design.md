# 空间与玻璃视觉系统

以[完整模板](../templates/template.html)和[主页面预览](../templates/desktop.png)为基线。四主题、移动布局与分析弹窗在模板中直接运行检查。视觉要服务真实分析，不用占位品牌、技术署名、重复教学文案填满首屏。

## |O| 满屏构图

桌面 `100dvh`，全屏地图为底层，左右两座双层玻璃容器浮在地图之上。标题与范围控件位于两侧容器之间，不能为全宽页头给侧栏留空。六张卡片分别回答均值、阈值、子指数、覆盖、国家比较和来源等级。所有卡片内容完整可读，页本身不滚动；不能以 overflow 隐藏末行来假装满屏。

地图 renderer 使用完整视口宽高；默认球体主体居中，缩放可放大至超出视口、延伸到两侧卡片背后。快捷筛选与地图操作轻量避让。低高度桌面收紧间距和字号，仍保留排行 n 和分析入口。移动 / 窄屏通过媒体查询允许页面滚动，地球单独一行，侧栏变为卡片网格，宽表只在内部横向滚动。

## 材质与全局 token

深蓝、黑金、冰蓝、暖玉是四套完整方案。所有颜色集中于根主题 token：`--bg/--bg-end`、`--ink/--strong/--muted/--faint`、`--accent/--accent-rgb`、`--glass/--inner/--glass-solid`、`--edge/--shine/--shadow/--glow`、`--map-*` 与六个来源等级语义色。渲染器读取这些 token，不在 CSS、Three.js、VChart 和 VTable 分别维护色板。

双层容器分工：外壳使用约18px blur、透明色面、圆弧透光边缘与整体柔光；内卡使用约54%表面、细高光与清晰读数，不再逐卡重复背景模糊。浅色背景采用清透蓝灰或青玉，深色采用墨蓝与暖黑；两层不能使用完全相同的底色和阴影。设置、分析弹窗、hover 与控件共用材质。减少透明或不支持 backdrop-filter 时使用实色 token。

每个标题文字右侧紧邻常驻细线右上箭头（↗），不使用独立方框或玻璃按钮底。图标使用muted/hover accent主题色，视觉18px、透明命中区28px；图标不截获按钮命中，按钮保留完整可访问名称、键盘焦点和原有分析行为。主数值使用轻字重和 tabular-nums，辅助内容 9–12px；长国家名有完整读取路径，比较始终带 n。

## 三维表现

真实高程驱动 SphereGeometry 顶点位移并重算几何法线，配合4K高程 bumpMap、同源高程梯度阴影和侧向光照形成山脉起伏；自然地表影像、细国家边界、参与受光的白云、城市夜光与方向性大气形成科技感。海洋与陆地用地表颜色判别反射强度，避免海洋出现大片白斑；视角边缘的大气与一次预烘焙夜光柔化替代逐帧全屏Bloom。真实高程不能从地表 RGB 亮度伪造；国家 AQI 由连续数值色阶的六边形晶体柱与点表达，选中区域只叠加轻量高亮。避免平面贴图感、过亮光晕和伪城市点。柱高和连续色阶承担数值含义，蜂窝只作装饰并明确说明。

按可用宽高计算相机 fit distance，resize 保留相对缩放与朝向；重置才恢复默认视角。国家确认可平滑转向，用户拖动立即接管。默认极慢旋转；未选中时鼠标悬停暂停以便拾取，确认国家后停止漂移并持续循环高亮，用户可手动开启/关闭动效。弹窗、后台和减少动态效果覆盖自动旋转意图。像素比有上限，换主题原位更新材质和纹理，不重建 renderer。

## 卡片和弹窗动效

首次入场按左1→右1→左2→右2→左3→右3逐张翻开，每张2400ms、间隔300ms，总计3900ms；以侧边为轴、86° rotateY 大角度翻页与透明度构成缓慢入场，地球1900ms同步渐显。不逐个数字翻转，也不动画化大面积blur。筛选和主题切换不重播首次入场。

分析弹窗450ms整体展开，标题、摘要、控件、图表、明细、口径各1500ms，按100ms起始/190ms间隔逐项出现，总计2550ms。使用transform/opacity，不使用动态blur或数据加载后的重复入场；查询前先给浏览器绘制壳，完整记录映射分片，图表和表格分阶段让出主线程。打开时暂停背后地球连续绘制，关闭最后一个弹窗才恢复；更新保持位置和列宽。关闭、Escape 和焦点归还不被长动画阻塞。减少动态效果时关闭翻转、自转、脉冲和图表更新动画；隐藏页停 RAF，恢复只一个循环且不大幅跳帧。

首屏六箱分布、污染物子指数、国家/城市排行与来源等级环统一由 VSeed 生成配置、VChart 绘制；风险占比进度指示器保持轻量 CSS。图表容器随卡片伸缩，预留轴标签、数值和 n 的空间，提示层约束在卡片内；排行保留真实图形点击和独立键盘入口。首屏翻页期间不叠加图表入场，数据更新才启用更新动画；减少动态效果时全部关闭。

图表沿用统一字体、透明背景、弱轴线和真实语义色；来源等级与数值分箱不同名不同口径。表格复用[公共 token](../../visual-query/references/table-theme.md)，深浅主题同步，完整原始记录使用 VTable 虚拟滚动，不做手工分页。

## 主题化选择控件

国家、分析分组、样本门槛和质量切片共用 `select-control`：玻璃触发器、当前项、勾选、搜索、中英国家名、空结果提示与滚动浮层。浮层使用原生 popover 顶层，避免被 dialog 或卡片裁切；视觉由全局 token 控制。方向键 / Home / End / Enter、Escape 只关闭当前浮层、点击外部收起与焦点返回都必须实测。底层隐藏 select 仅作值与 change 事件桥接，不把浏览器原生选项面板作为用户界面。

柱高精确按完整查询分箱数量比较，零值没有可见柱；每箱同时显示区间与数量。风险卡的 AQI>150 比例明确使用全样本分母。来源等级环中心是来源 Good+Moderate 占比，不能与数值≤100混用。

首屏逐卡入场与任一弹窗打开共同决定幕后地球暂停，首屏动画结束不能错误恢复仍被弹窗遮挡的地球。所有动画时长从统一 motion token 读取；数据在动画进行时异步准备，不人为等待时序结束。

默认底图采用协调主题色的陆地蜂窝和克制光晕；关闭蜂窝后，浅色恢复粉彩自然地貌，深色恢复自然陆地与冷蓝海洋。地图下方快捷国家按全量样本量取前三；选择其他国家时保留当前项。快选、搜索选择器、真实国家点和主屏指标共享同一筛选范围；国家内城市排行提供微观入口，不添加没有坐标依据的微型城市地图。

## 参考图地球的实现边界

默认视角面向约东经25°、北纬23°的北非—欧洲；重置恢复此视角，国家选择与缩放行为不变。光源随观察方向保持上右亮、下部暗的艺术化构图，不表示真实太阳位置、当前昼夜或天气。云层固定历史影像有轻量旋转偏置，投影阴影使用对应UV偏移，不为装饰持续空转。

未选中时，两种底图均7次绘制调用，不引入全屏后处理通道。自然地表两种模式缓存，云影预计算进RGB、夜光打包进alpha；海洋反射复用已采样的地表颜色；主题只更新缓存引用、颜色和uniform。浅色模式关闭夜光并收敛外晕；自然地貌背景将深色夜光收敛到原强度16%，蜂窝底纹关闭夜光，使真实业务标记更突出。夜光亮点不可解释为AQI观测站；可拾取AQI点使用与柱体一致的连续数值色阶及完整查询结果。

强大气经过顶部国家控件后方时会降低文字对比，因此该触发器复用`--glass-solid`作为稳定底色；Card容器、排版、尺寸、其他控件及动效保持。

## 浅色浮雕与实用数据层

浅色自然地貌采用雾蓝海洋、鼠尾草低地、沙金荒漠、柔白积雪，并保留原影像的植被/荒漠差异；真实高程梯度维持山脊，宽环境光和0.82暗部下限避免下半球发黑，云影浅化。未改变高程来源或夸张比例。球体默认占约87%可用高度，保持侧栏覆盖与缩放自由。

风险层使用一个 InstancedMesh 绘制全部国家的六边形柱，半径一致、柱高线性映射固定尺度；透明侧面、细亮棱与轻提亮顶面共同形成晶体材质；主题低/高端色连续插值，避免六级分类色与底纹竞争。背面与贴近轮廓的柱/点隐藏，避免球缘针刺；不按视角缩短柱高。少量标签避开侧栏、顶部控件与底部国家摘要。地貌与蜂窝均保留数据柱/点；设置开关只改变背景材质，图例和指标控件保持可用。

模式与指标控件使用稳定玻璃实色底，避免亮云透过文字。点选国家显示 AQI、样本数与超阈值占比，样本少于30条提醒；“国家分析”继承已确认范围进入现有完整分析，清除后返回全球。不要用悬停预览代替确认状态。

国家边界必须在沙漠、植被、云层和海岸背景上可读。浅色使用青灰轮廓、深色使用冷色/灰白轮廓；悬停国家标记时联动该国边界，确认后突出该国并保留邻国以支持比较。经纬网仍低对比，不能把经纬格子误称国家网格。密集区域通过统一缩小柱半径和点光圈减少叠压，不改变国家代表位置或指标高度。边界继续一个批次，状态只更新uniform，不新增发光后处理。
