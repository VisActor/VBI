# Three.js 3D 地图 Dashboard

用于明确的三维地图、地球或空间分析需求。交付一个 HTML。业务数据与轻量地理索引保留在文件中；大型纹理和运行时可从固定版本 CDN 加载，先探测网络可达性并提供超时回退，见[资源加载](references/resource-loading.md)。

新建默认复制完整模板，先运行，再做最小业务适配。继承适用的排版、图表样式、筛选联动、动效和生命周期。用户指定风格或宿主约束优先；移除或重写能力时，记录原因及替代行为，并验证其余体验没有退化。

## 1. 运行完整基座并理解数据

复制 [template.html](templates/template.html)，先核对默认态、四主题、国家筛选、地图拾取、指标分析和返回。主页面实图见[桌面预览](templates/desktop.png)。不要只复制静态外壳或凭截图另写简化版。

模板使用真实空气污染 CSV 的全部 23,463 行城市样本，175 个非空国家、427 行未标注国家。它没有日期或城市坐标，因此只做静态样本比较，不生成趋势、实时状态、城市点位或运输飞线。国家位置来自 Natural Earth，与城市定位明确区分。字段、空间口径、分类差异和基线见[地图与数据](references/map-and-data.md)。

## 2. 保留高质量空间构图与统一外观

桌面采用 `|O|`：地图画布铺满整个视口，左右双层玻璃容器覆盖在地图之上，每个外壳包含三张内卡。标题与控件移入中央安全区，侧栏从顶部铺到底部；地球放大可以延伸到卡片背后。页面铺满首屏且没有页面滚动；移动端用媒体查询变为可滚动卡片布局，地球单独一行。不要通过裁切关键信息或缩小到不可读来隐藏溢出。

按[视觉规范](references/design.md)维护统一材质、透明模糊玻璃、内缘高光、柔光、排印、图表和三维光照。设置中提供深蓝、黑金、冰蓝、暖玉四套完整主题，首次默认冰蓝、已保存偏好优先，[设计 token](references/design-tokens.md)分为基础、深浅材质和主题色三层，CSS token 是颜色唯一来源，Three.js、VChart、VTable、弹窗和控件一起切换；外观保存不改变分析范围或地图视角。

初始化先显示主题化玻璃加载卡片、旋转环与阶段提示；场景保持尺寸但隐藏并禁用交互。等查询、图表、地球首帧或明确降级就绪，再一次性移交首屏入场。依赖自动换源期间不误报失败；最终失败或超时提供重新加载，保留减少动态效果、后台暂停和销毁清理。

六张卡片缓慢逐张翻开，地球渐显；分析弹窗整体展开，内部标题、摘要、控件、图表、明细与口径按顺序出现；不逐个数字翻转，不在筛选时重播首次入场。减少动态效果、后台暂停、资源释放和图形降级不能因改造外观而丢失。

地球以真实高程网格、细节法线与侧光显示起伏，深色主题以自然地表、受光白云、暖色历史夜光和有方向的青色大气构成科技感，浅色主题采用雾蓝海洋、鼠尾草低地、沙金荒漠和柔白积雪，抬高暗部照明并关闭夜光；地形不是染色球面。地表影像和高程栅格可从经过验证的公开 CDN 加载，标明来源、年代、分辨率及视觉夸张。国家边界在深浅主题下均应清楚分区；悬停与确认高亮有层次，保留邻国比较背景。国家与分析筛选使用可搜索的主题化浮层控件，保留键盘与焦点行为，不暴露系统原生下拉外观。

地图始终展示国家六边形晶体汇总柱，柱高在统一固定尺度下放大到原基线两倍；可切换 AQI 均值 / AQI>100 样本占比。地图上方仅保留指标切换。设置中的“蜂窝底纹”开关默认开启，关闭后显示自然地貌；切底图保留同一数据柱、国家选择与相机。用户已要求移除样本覆盖模式，样本量仍通过Card、国家摘要和分析呈现。蜂窝仅装饰，缺少城市坐标时不能伪造城市或网格聚合。

四主题晶体柱、点和图例共用连续数值色阶，Card 的来源分类色保留原义。柱面光带与点环每6秒错相循环，选中国家另有3.6秒向外扩散的三重涟漪与国界呼吸；选中后相机停止，高亮仍继续。悬停未选中地球时暂停，选中态悬停仍可观察高亮。拖动、弹窗、后台和减少动态效果暂停光效；手动动效按钮可暂停全部。循环只改变材质与定位环，不改变柱高或统计值；不能把静态快照演成时间趋势。

性能优化优先减少重复工作，保留纹理、地形精度和数据编码。相机停稳后的选中循环复用有界地球颜色缓存，并用同一地形网格重建深度，数据柱、边界与涟漪继续实时绘制；移动相机恢复原渲染路径。主题、背景、视角、尺寸和地形变化必须使缓存失效。颜色、标签尺寸与光照按需更新，pointermove 每帧至多精确拾取一次；后台或地图离开可视区域暂停。缓存失败须自动回退，正常/中途退出都释放资源。细节见[模板适配](references/template-adaptation.md)。

## 3. 接入查询与主动深入分析

1. 优先复用宿主数据接入，其余按 [server-runtime](../server-runtime/SKILL.md)选择；静态源完整内嵌，不依赖同目录 CSV / GeoJSON。
2. 按 [visual-query](../visual-query/SKILL.md)使用 Builder → VQuery → VSeed → VChart / VTable。业务聚合和条件由 Builder 描述，地图只消费查询结果；不要在 Three.js 内另做筛选和统计。首屏分布、子指数、排行与来源等级环共用 VSeed / VChart 呈现，不重新手写 HTML 条图；复用实例并保留排行鼠标与键盘入口。
3. 每个指标或图表标题文字右侧紧邻常驻、无边框、键盘可达的细线右上箭头分析 icon（↗），按 [metric-analysis](../metric-analysis/SKILL.md)进入共享原生 `dialog`，不能以放大原数值替代深入分析。按指标选择国家比较、等级结构、数值分布、子指数画像或数据质量核对。
4. 分析继承打开时已确认范围；局部选择同步读数、图形和完整 VTable，关闭后保留主页范围和视野并归还焦点。Top N 不限制总体计算、分组可达性或完整明细。
5. 数据定义、聚合和可保存的业务条件归 DSL / Builder；相机、对话框、hover 与动效归呈现层。中位数和 P90 使用公开 Measure Builder 的 median / quantile 聚合，排序、门槛和 Top N 也进入 Builder，禁止页面自行分组、求和或排序求分位。复用已连接数据集及查询缓存，不能每次查询反复装载源数据。

## 4. 适配与验收

[模板适配](references/template-adaptation.md)列出业务、主题、查询、弹窗与生命周期入口。替换数据先修改 schema、字段映射和口径，再最小调整布局；没有依据的能力需移除并说明替代行为。

按[验收标准](references/acceptance.md)核对数字、真实鼠标和键盘操作、四主题、满屏 / 移动布局、动效与销毁。视觉判断需要阅读实际截图；独立评分必须来自评审实际结果，不能为越过门槛引导分数或用自动断言替代视觉评审。
