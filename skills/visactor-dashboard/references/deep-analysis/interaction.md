# 按需深度分析

为概览中的指标或数据设计主动探索入口，让用户继续比较、解释和核对证据。默认首屏保留概览、关键读数和必要范围，点击后在 Modal 展开；用户明确要求完整分析页或已有宿主使用其他容器时沿用其结构，不强制改成弹窗。

本篇负责入口、上下文、局部选择与返回；计算与证据按[数据分析方法](../data-analysis/guide.md)，查询、渲染和资源生命周期按 [visual-query](../visual-query/guide.md)。布局、材质和组件沿用调用方，不依赖特定场景、模板或运行时。

## 首屏与深入内容

首屏突出主要发现和必要证据，多维拆解、长篇解释和完整记录按用户动作展开。不自动弹出，不在悬停时进入；深度查询及相关视图按需加载，首屏查询独立完成。

详情先回答概览尚未回答的问题，再提供相关比较、检验和记录核查。每个入口明确指标、进入范围、默认问题和可核对证据，按[方法索引](../data-analysis/guide.md#按问题选择方法)选择分析；不要求所有指标使用同一套图表。放大数字、重复排行或静态说明不能代替新的证据。

## 入口与操作语义

- 有进一步分析价值时，指标名称、卡片名称与数字可作为同一分析入口，点击任一入口打开对应内容；只有定义说明时如实标注。
- 图元或单元格确认通过稳定业务键建立条件。表头选择整列与数据格分析分别定义，不能把表头误作普通数据格。汇总格按真实成员范围进入，不以可见行列下标代替业务身份。
- 入口可聚焦，支持 Enter / Space，具有描述目标的可访问名称。避免嵌套按钮和事件冒泡导致重复打开；卡片内筛选、下载、地图定位等操作保留各自语义。
- 悬停只临时预览，离开恢复已确认读数与范围。打开分析使用已确认范围，图元点击再叠加被确认对象的条件，不能意外携带上一处 hover。

## 内容与完整证据

围绕主要问题组织读数、图形、发现及关联明细。发现说明范围、基准、幅度和证据；局部选择变化后使用新结果重算，事实、候选解释与未知分别表达。具体公式、成熟规则、空间覆盖及统计假设按对应数据分析方法处理。

关系图的横纵指标必须对应当前问题并有可解释的变化；国家数、记录数等只因查询可得而存在的计数，不自动作为解释轴。横轴恒定、有效配对不足或缺少业务关系时不展示散点，改用适当比较或保留明细证据；样本量可作为 Tooltip、覆盖与稳定性说明，不代替解释指标。

明细使用 VTable，行粒度支持当前问题；只有聚合结果时说明不能穿透原始实体。Top N 只限制图形展示，完整分组仍可检索和选择；远程分批加载标明覆盖，不以可见行估算总体。无法绘制或定位的记录仍保留在适用统计与明细中。

导出在对应结果已加载并确认后启用，携带当前已确认范围、指标与必要字段；首次加载或条件尚未确认时不能导出一个看似完整的新结果。

## 范围、联动与返回

打开时捕获已确认的时间、地域、业务筛选和指标固有条件。来自不同入口的分析使用各自上下文，不沿用上一个指标的范围、发现或选择。

图表与分组控件读写同一局部选择，读数、发现、图形、明细与导出使用同一轮已确认结果。切换维度只清除失效条件；清除回到进入时范围，不能扩大到其他期间、地域或业务总体。选择、清除方式和当前范围持续可见。

局部选择默认只影响分析容器；用户明确执行应用操作才改变源页面。地图缩放、拖动和定位默认属于导航，确认业务范围才修改查询。后台刷新明确采用冻结快照或同步刷新策略，避免同轮证据来自不同截止点。

继续探索可返回上一级条件。关闭保留源页面筛选、视图、滚动位置与已有可视化，并将焦点交回入口；不因关闭分析重建主页。业务定义的保存恢复按[可恢复定义](../data-analysis/guide.md#查询与可恢复定义)，Modal 开关、临时请求和实例归界面层。

## 查询与平滑更新

- 打开与局部查询提供加载反馈。新范围计算期间保留已确认内容并标明更新中；失败保留原结果，重试原失败条件，不把旧结果标为新范围。
- 关闭、重开、切指标和快速筛选使旧请求失效；结果应用与渲染前核对请求版本。连接复用、取消与最终释放按[组合与联动](../visual-query/references/composition.md)处理，取消一个消费者不能使其他消费者失效。
- 通过 VSeed 配置图表，图表原位 `updateSpec`，表格按渲染器更新记录或配置；筛选不卸载重画、不重播页面或面板入场。表格记录更新可沿用 VSeed 默认动画，减少动态效果时直接落位，具体参数由宿主与渲染器确定。
- Modal 提供名称、可见关闭按钮、Escape 与焦点约束，打开期间背景不可误操作；内部浮层优先处理 Escape。支持键盘、触屏和窄屏滚动，关闭始终可达。

## 验收

1. 从指标名称、卡片名称、数字或已声明的数据入口进入对应分析，键盘入口有效，无自动打开、悬停误触或重复触发。
2. 继承已确认范围，默认内容增加有效证据；按需查询，计算结果通过[方法验收](../data-analysis/guide.md#验收)核对。
3. 实际完成“入口 → 比较或检验 → 明细核对 → 清除或返回 → 关闭”，各步范围一致，完整分组和证据可达；局部选择不擅自改变源页面。
4. 连续打开不同指标、快速筛选、空结果、失败重试及关闭后旧请求返回均正确，保留已确认结果，更新不闪烁或重复入场。
5. 核对表格更新过渡、键盘、触屏、减少动态效果、窄屏、焦点恢复及源页面状态；不将源码检查或历史结果当作本次运行证据。
