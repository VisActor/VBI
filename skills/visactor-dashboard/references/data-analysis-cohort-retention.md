# 同期群留存

回答不同批次进入的成员，在相同观察年龄有多少再次活跃。先定义入组事件与回访事件，再比较同期群，避免把观察时间不同的成员直接比较。

## 数据契约

- 必须有稳定成员 ID、事件日期、入组规则、回访规则和数据观察截点。
- 明确时间粒度、时区、自然周期或滚动窗口，以及首次归属的平局处理规则。
- 只有观察记录时，首次出现称为“首次观察”，不能等同真实注册或获客；历史覆盖不足时标明左删失。
- 国家、渠道等归属字段必须声明按首次事件固定，还是按回访事件变化。

## 计算规则

1. 按成员确定入组时间与同期群，同一成员在一个观察窗口最多计一次回访。
2. 由入组时间和目标窗口计算观察年龄；只有完整走过窗口的成员进入成熟分母。
3. 留存率 = 窗口内回访的唯一成熟成员数 ÷ 成熟成员数。汇总时合并分子分母，不平均各群比例。
4. M0 等入组窗口的基数按入组定义计算；未成熟用缺失状态，成熟未回访为零，空分母的比例无定义。
5. 区分指定窗口回访、连续留存与截至窗口累计回访，不混用定义。间隔后回来不等于连续留存。

## 查询与可恢复状态

保存成员键、入组及回访规则、时间粒度、观察截点、窗口、归属维度、筛选范围和方法版本。派生事实建议为“成员 × 观察年龄”，保留目标窗口、成熟状态及回访次数；筛选、分组与明细共享同一关系。

在 VBI 集成中，通过公开查询获取事实，方法定义与一致性规则由所属 DSL / Builder 承担；临时选择和图形渲染由宿主负责。

## 分析与证据

用同期群矩阵比较相同观察年龄，补充成熟人数与待观察人数。可按入组批次或真实归属维度下钻；明细保留成员、入组时间、目标窗口与回访证据。极值比较应声明最小样本要求，不把描述性差异解释为因果。

## 继续分析的动线

- 从某个同期群 × 观察年龄的交叉格进入时，带入该批次、年龄和原范围，先解释该格的分子、成熟分母与待观察人数。
- 继续回答“同一批成员之后如何变化”时，仅释放观察年龄条件，查询这些成员在各年龄的完整关系；保留批次、归属与原业务筛选。若入口选的是某年龄的成熟或待观察子集，先冻结成员集合，再查询其轨迹，不能简单删除状态条件而换了一批成员。
- 曲线按相对年龄对齐，未成熟点留空，不连成零值。多批次曲线过多时可限制显示数量并披露覆盖，完整批次仍能检索与选择。
- 批次比较同时给出比例与成熟样本量。最小样本门槛应可配置并展示；没有足够合格批次时退回当前范围的分子分母，不强行生成最高与最低结论。

## 结果一致性与验收补充

为购买事件、成员和成员年龄分别保留稳定键，明确从事件去重到成员窗口的转换。明细中的回访、未回访和待观察状态必须能直接支持汇总读数。

固定一个已确认范围，验证“选格 → 查看同批轨迹 → 切归属维度 → 清除”的集合变化；清除只回到入口范围。异步返回须核对请求版本；失败保留上次已确认结果，导出只使用当前已确认的成员年龄记录及其条件。

最小复算例：两个成熟批次分别回访 1/2 与 9/90，合并为 10/92，不能平均 50% 与 10%；另有 3 位待观察成员时，分母仍为 92，而不是 95。

## 解释边界与稳健性

- 先用必要历史确定首次归属，再裁剪报告期间；否则同一老成员可能被重新归入新批次。实体在历史表中被删除或只保留当前活跃者时，披露无法覆盖的退出成员。
- 对影响结论的观察截点、完整窗口或最小样本门槛做有依据的敏感性比较。数据迟到可能改变“未回访”状态，结果应标明数据截至时间；不以挑选最优年龄或批次替代预设比较。

## 验证

核对成熟回访与成熟未回访之和等于成熟人数；覆盖重复事件、零回访、未成熟、跨周期边界、历史不足和空范围。验证汇总加权、固定归属、筛选后重算，以及保存恢复后结果一致。
