# 多维透视

回答不同维度组合的指标构成与差异，明确事实粒度、合法聚合及总计语义。

## 数据契约

- 明确事实唯一键、行列维度、指标、单位、时间粒度与缺失处理。
- 区分商品行、订单、客户等实体粒度；连接维表前验证基数，避免重复放大事实。
- 每个指标声明可用聚合及跨维度可加性；负值、有效零与缺失分别保留。

## 计算规则

1. 按筛选范围构造完整事实集合，再按行列维度查询交叉结果。
2. 可加指标可汇总交叉格；去重计数、均值和比例的总计需从总体事实或充分统计量重算。
3. 去重订单等指标不可跨交叉格直接相加；比率合并分子分母，均值保留权重。
4. 行列交换只改变组织方式，不改变事实集合与总体口径。层级钻取须声明成员归属与小计规则。
5. 预聚合结果进入渲染层时避免重复聚合；Top N、分页和展示折叠不截断总体。

## 查询与可恢复状态

保存数据引用与版本、行列及层级、指标定义、聚合、筛选、排序、小计和缺失规则。领域操作通过所属 DSL / Builder 保持合法性，具体控件和临时高亮由宿主负责。

在 VBI / VSeed 集成中，通过公开查询获取透视数据，按实际 API 的维度与度量编码构建 Spec；不要让适配器承担指标规则。图表与明细复用同一范围及口径。

完整叶子结果互不重叠且指标可加时，可通过 VSeed 的 totals 配置让 VTable 计算小计与总计，无需另查同一金额的全部汇总层级。输入被 Top N 截断、指标跨组重叠或不可加时不能使用这一捷径；去重数、均值和比例仍按总体事实或充分统计量重算。

## 分析与证据

先看总体，再定位交叉差异；结合规模、利润或比例检查单一指标的局限。可以沿时间、品类、地区等真实维度下钻。明细保留事实键及指标源字段，明确当前展示的是事实行还是分组结果。

## 继续分析的动线

- 从交叉格进入时，将实际行列键转换为业务条件，再基于该条件查询完整事实；不能用可见行号或列号代替成员身份。
- 从规模继续比较表现，例如在同一分组上同时看销售规模与利润率。交叉分组要带样本量、明确的分子分母及完整成员入口，避免把小组的极端比例当作整体问题。
- 利润等带符号指标补充正值与负值的抵消；去重实体指标补充每个实体包含的事实行数，分别解释规模与粒度。
- 行列维度冲突时，领域操作应选择明确策略：互换、规范化或返回可理解的校验错误。该规则必须在 Builder 层保持一致，不能只靠控件禁用。

## 结果一致性与验收补充

透视表、分面图和指标共享交叉查询或相同查询定义；并排比较使用一致数值尺度与零基线。排序、折叠或分页后，仍按业务键保留选择，不能误指另一交叉格。

保存状态时校验维度、指标和聚合是否合法，并校验数据版本；不兼容状态须明确拒绝或迁移。候选状态查询成功后才替换已确认结果；失败保留原范围，精确重试失败条件。

最小复算例：同一订单同时含两个品类时，两格各计 1 单，总体仍为 1 单；利润 +20 与 −15 合计为 +5，负利润不得删除。

## 解释边界与稳健性

- 总体与分组趋势相反时，检查分组权重是否变化；同时给出组内指标与总体构成，不直接选择更符合预期的一层作结论。共同分组上的固定权重比较须另标口径，不能替代实际总体。
- 关联事实前后核对主键覆盖、未匹配项、金额和实体数；COUNT DISTINCT 只能修复部分计数语义，不能修复重复连接后的金额。稀疏交叉格展示覆盖与分母，不自动补零或合并成高置信排名。

## 验证

验证行列交换、层级小计、整体去重、比率加权及预聚合不重复求和。覆盖空范围、合法零、负值、缺失维度、重复连接和分页；核对不同视图与明细口径一致，保存恢复后查询结果一致。
