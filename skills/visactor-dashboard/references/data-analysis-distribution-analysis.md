# 分布分析

回答数值的典型水平、离散程度、长尾与群体差异，保留记录级证据，避免仅用均值代表整体。

## 数据契约

- 明确记录粒度、稳定记录键、数值字段、单位、时间范围与缺失处理。
- 记录 ID 不等于人员或业务实体 ID；不能因为属性相同就删除重复记录。
- 区分有效零、缺失、无效值和业务上合法的极端值。权重存在时声明权重含义及统计定义。

## 计算规则

1. 从当前完整有效记录计算样本量、均值、中位数、分位数及离散程度。
2. 明确分位数算法。例如 Type 7：排序后 h=(n−1)p，在 floor(h) 与 ceil(h) 对应值之间线性插值。
3. IQR = Q3 − Q1；采用 1.5 × IQR 标记时，区间外记录仅称规则标记值，不自动删除。
4. 直方图声明分箱宽度、端点归属与范围。不能用分箱近似值替代承诺精确的分位数。
5. 分组分位数必须从该组完整数值或精确频数重算，不能平均分组中位数或 P90。
6. 比较异常占比时声明使用共同总体界限还是各组独立界限。固定总体界限更便于按相同标准核对分组。

## 查询与可恢复状态

保存数值字段、单位、有效值规则、权重、分位算法、分箱、标记规则、参考范围及筛选条件。可查询原始数值或无损频数；若采用压缩计数，必须验证容量、溢出与整数精度，不绑定某个样本的基数。

在 VBI 集成中，统计规则与可恢复定义属于 DSL / Builder；图形、临时高亮和弹窗属于宿主。相同范围的统计关系可复用，查询取消不能使其他消费者失效。

## 分析与证据

结合直方图、分位数或箱线图观察主体与尾部，再按真实维度比较。明细保留原值、单位和源记录键。描述性构成差异不证明因果；插值 P90 不保证恰好 90% 的样本位于其下方。

## 继续分析的动线

- 从中位数或高分位数进入，不只重复一个数值；用经验累计分布比较差异来自主体位置还是少量尾部，并同时显示各组样本量。
- 经验累计分布 F(x) = 不大于 x 的有效记录数 ÷ 有效记录数，同值累计为同一阶跃；它与插值分位数的定义分别说明。
- 从区间外记录进入，固定入口参考范围的界限再核对各组。若允许改用组内界限，应显式切换规则并重新计算，不能无提示地改变“异常”的含义。
- 分箱选择应映射回明确的原值区间，含端点规则；图形缩放或只显示主体区间不得删除尾部统计及原始证据。

## 结果一致性与验收补充

原记录或精确频数是复算依据；宽表打包、进制编码等属于适配策略，不能成为方法必需条件。复用频数关系时，缓存键包含数据版本、范围、数值字段及有效值规则；构建失败可重试，各消费者独立取消，不能因关闭一个分析而使其他查询失效。

分位数、经验累计曲线、标记记录与导出共享当前已确认范围。隐藏内部频数编码，明细仍是一条真实源记录；需要全量统计时检查查询是否截断，分页只影响明细展示。

最小复算例：数值 [0, 0, 10, 100] 的经验 F(0)=50%，Type 7 中位数为 5；二者定义不能互相替代。

## 解释边界与稳健性

- 按关键分组或期间核对缺失率与有效样本构成；只分析非缺失记录时说明覆盖，不默认缺失随机，也不自动插补。
- 必要时并列均值与中位数、IQR，观察极端值对判断的影响。去尾、缩尾或对数变换只作为有说明的敏感性结果，保留原尺度基准及转换公式；规则标记率高不自动证明阈值过严或数据有误。

## 验证

覆盖空集、单值、重复值、全相同值、负数、极端值、缺失、分箱边界及小样本插值。独立复算频数、分位数与标记计数，验证筛选、分组及保存恢复保持一致。
