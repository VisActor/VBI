# 指标深入分析

**指标深入分析是对用户主动探索的奖励。** 主页先让用户看懂并产生兴趣；用户点击指标、选择分组、继续下钻时，逐步发现更有价值的结论、顺畅的联动和可核对的依据。精妙设计体现在每一步都回应了用户的问题。

本篇负责分析内容与动线，宿主负责视觉和容器，[visual-query](../visual-query/SKILL.md)负责查询、渲染与联动。

## 简约与逐步展开

- **主页保持简约。** 保留首屏的指标、图表与布局，不提前铺开分析内容。
- **入口容易发现。** 可分析指标在标题右侧放置轻量图标，不使用下划线；提供点击与聚焦反馈，触屏、键盘也能进入。奖励来自深入后的内容与体验，不靠仅 hover 可见的入口或额外操作门槛制造惊喜。没有后续分析时不制造可点击外观，只有口径说明时如实标注入口。
- **详情首屏先回答一个主要问题。** 默认展示指标与范围、一条有依据的发现、一张主要分析图和用于核对的 VTable。按数据条件精简；没有可用分析时提供有效的口径或聚合依据，不凑齐模块。只有可比基期存在时才显示变化。
- **后续能力随问题出现。** 为当前选择提供少量相关动作，如查看分组、比较或展开表格。复用同一详情视图与可返回的路径，避免连续叠加对话框或把全部分析方式排成工具栏。
- **容器服从阅读。** 默认复用宿主的对话框或分析面板；桌面空间适合时将 VTable 放在右下，允许展开或占据整行，窄屏纵向排列。持续探索需要更多空间时可扩展为全屏，保持分析范围和选择。
- **文案服务分析。** 保留指标、范围、结论、筛选状态和必要动作。去掉反复出现的“点击查看”“明细已同步”等教学提示；维度按钮直接使用维度名称。口径与分组列表按需展开。
- **选择控件复用宿主标准。** 平铺选项与 Select 沿用宿主的样式与交互，统一触发器、浮层、整行命中与键盘行为；只更新当前分析范围。

## 入口与容器接入

- 指标名称作为键盘可达入口，支持 Enter / Space，提供指标名称、焦点样式；打开对话框的入口设置 `aria-haspopup="dialog"`。原生 button 直接复用，不嵌套按钮，动态数值更新不覆盖标题和图标。
- 宿主采用整卡入口时，名称、数值与空白区域进入同一分析；卡片内的独立操作保留各自行为，避免冒泡重复打开。环图中心由装饰变为入口时，解除阻断交互的 `pointer-events: none`。
- 图表标题进入分析，图例与绘图区保留原有筛选和预览行为。入口不就绪时说明状态，不能打开与当前指标无关的旧结果。
- 多个指标复用一个分析容器。HTML 对话框优先用原生 `dialog`，支持关闭、Escape、焦点归还和内部滚动；后续分组与维度切换在当前容器完成。

## 先明确指标与问题

为需要深入分析的指标确定以下内容，再选择图表与交互；这些信息用于设计，不要求全部展示在主页。

1. **对象与口径：** 名称、单位、公式、事实粒度、去重键、时间与业务范围、有效的比较基准。
2. **可用证据：** 时间字段、可分析维度、真实层级、历史覆盖和可访问的明细；明确缺失项。
3. **默认问题与后续路径：** 先回答一个卡片尚未回答的问题，再选择能推进理解的分析方式。每条路径写清入口、首屏、下一步和返回；不要求每个指标具备全部方式。
4. **核对方式：** 表格一行代表什么、哪些列支持当前结论、如何与指标核对。成交客户通常一行一位客户，动销商品通常一行一个商品；订单明细使用不同粒度时应明确说明。

没有时间字段不生成趋势，没有可比历史不生成周期变化，缺少必要历史或业务定义不判断新老客户；只有聚合数据时提供聚合表，并说明无法穿透原始记录。

## 数据形态与比较口径

- **实体快照与事件分开。** 实体快照按稳定唯一键计数，明细保持实体粒度，没有历史快照不生成趋势或增长。事件按事件 ID 去重，区分发生时间、修订时间与查询截止时间，更新已有事件不能算作新事件。
- **时间范围一致。** 时间分组使用明确的报告时区，近期窗口以同一截止点计算，首尾不完整时段需注明，不把缺失记录自动当作零。比较前确认两期覆盖、单位、事实粒度与去重规则可比，业务条件保持一致，日期分别应用各自周期。
- **按完整范围重算。** 汇总、均值、极值与去重数按原始记录和当前范围计算，不平均分组均值、不累加重叠分组去重数。子集指标先叠加固有条件，再同步查询读数、图表和明细；比例明确分子分母，切换分组按定义重算。
- **有效性分别判断。** 合法的零值与负值按字段语义保留；空结果计数显示 0，无定义的均值、极值或零分母比率显示 —。中间计算保留精度，仅展示时舍入，不用极小常数绕过除零。
- **变化不等于好坏。** 正基数的相对变化通常为 `(本期 − 基期) / 基期 × 100%`；负基数按指标语义明确比较方式。当前值与变化分别判断有效性，基期不可比不隐藏有效当前值。箭头与文字表达真实增减，好坏取决于指标含义，不只依赖颜色。

## 分析方式与用户动线

按业务问题选择下表中的路径，并替换为真实字段与入口文案。每次深入应增加新的解释或证据，避免仅放大原数字或重复主页。

| 方式     | 启用条件                     | 用户动线                                                                                                                     |
| -------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 口径理解 | 已知指标定义与计算范围       | 点击口径说明 → 查看定义、计算方式与范围 → 按需核对分子分母或有效样本 → 收起说明，回到原阅读位置。                            |
| 趋势分析 | 有真实时间与合理粒度         | 点击指标进入趋势 → hover 用 crosshair 定位时间 → 点击该维度区域确认，联动局部读数、发现和表格 → 清除时间选择，恢复整个周期。 |
| 周期比较 | 本期与基期口径可比           | 进入比较 → 查看两期值、差异与比较范围 → 有相关维度时查看各组的两期表现，选择分组核对证据 → 清除分组或返回总体比较。          |
| 结构分析 | 有业务相关维度               | 进入结构 → 查看默认维度的分布或排行 → 点击分组，联动该组读数、发现与明细；需要时切换相关维度 → 清除分组，恢复总体结构。      |
| 层级下钻 | 有真实父子关系               | 点击有下级的分组 → 查看下一层及当前路径 → 继续选择有效下级，到末级后按需查看明细 → 通过路径导航返回指定上级。                |
| 明细核对 | 有可访问的实体记录或聚合依据 | 从指标或已选图元进入 VTable → 查看当前范围、粒度与记录 → 按需搜索、排序、滚动或展开表格 → 返回分析区，保留条件与阅读位置。   |

口径说明可直接展开；其他方式按默认问题进入详情，后续动作就近提供。搜索与排序按分析需要提供，VTable 默认以虚拟滚动浏览完整结果，不加手工翻页器，明细行只在确有下一步时开放继续分析。筛选或图表选中条件必须可见、可清除。

## 分组选择与完整结果

- 分类图按可读容量显示 Top N 并标注，分组菜单仍可选择完整范围内的所有分组；选中 Top N 外的分组时在图中保留该项。Top N 只限制展示，不限制总体计算或明细访问。
- 图表与菜单读写同一分析选择；保留总体图用于比较并高亮选中项。清除只移除对应条件，保留入口范围和指标固有条件；切换维度清除上一维度选择。选项数值来自完整有效范围，不由可见行估算。
- 少量短选项可平铺，选项多或较长时用选择浮层；多选显示语义与已选数量，不套用单选确认后关闭的规则。控件尺寸稳定，窄屏允许换行，触屏保留足够命中区域。
- 浮层放在对话框的可交互层内，不挤动图表与表格，限制在视口内；长列表内部滚动，必要时提供搜索。hover 或移动焦点不提交条件，点击、Enter 或 Space 确认后更新选择并归还触发器焦点。
- Escape 优先关闭当前浮层，不同时关闭分析对话框；点击外部关闭时不抢回焦点。加载保留控件和已有内容，失败不将旧结果标成新选择；动态标签使用文本写入，失效选项按当前范围清除并同步查询。
- 明细将当前范围的完整查询结果交给 VTable 虚拟滚动，允许展开表格，不增加手工翻页器或按固定行数切片。远程查询需要分批取数时，按服务端游标逐批加载并明确加载范围，不静默截断。

## 范围、联动与返回

- 点击指标入口继承已确认的时间、地域与业务筛选；点击图元时再叠加该点或分组条件。hover 只作临时预览，不隐式成为详情条件。卡片因 hover 显示局部值时，应标明临时范围与入口将打开的范围。
- 详情内的选择默认只更新其关联读数、图表、发现和表格；同时显示当前范围。只有明确的“应用到看板”动作才修改主页。周期比较保留各自日期，结构占比明确分母随选择变化还是固定总体。
- 自动刷新页面明确采用打开时的截止点或同步刷新策略，并显示数据时间；同一分析的读数与证据保持一致。关闭或快速切换后，旧请求不能回写新范围。查询与生命周期按[组合与联动](../visual-query/references/composition.md)处理。
- 采用冻结分析快照或暂停刷新策略时，关闭后恢复原刷新策略。请求携带取消信号并校验版本，提交渲染前再次校验；临时查询 Builder 在 `finally` 中注销并释放。
- 返回恢复上一级条件与选择；关闭保留主页筛选、滚动位置并归还入口焦点。对话框支持关闭按钮、Escape 和键盘操作；图表选择提供触屏及键盘可达的等价入口。空结果、失败和加载中有明确反馈与恢复路径。
- 关闭时取消请求、数值动画与待显示加载提示，释放本次分析创建的图表和表格；销毁分析组件时移除监听和 ResizeObserver。关闭分析不释放宿主仍在使用的实例。

## 交互与平滑更新

- **命中范围与 crosshair 一致。** 趋势图 hover 时用 crosshair 定位，点击该维度在绘图区内的整列区域即可确认，不要求点中圆点或线条。优先使用 VChart `dimensionClick` / `dimensionInfo`，与原生准星共用维度映射；触屏也可直接点按区域，键盘使用等价分组入口。保留点和线段上的点击，但同一次手势只处理一次，避免图元事件与维度事件重复切换。选择对应真实时间点或分组，不以插值生成明细条件。仅 hover 不提交表格筛选；若用户明确要求悬停即联动，再提供临时预览及移出后的恢复。
- **选择可核对。** 选中图形高亮，同一维度值同时驱动局部读数、发现与 VTable；显示简短的筛选标签与清除入口。切换维度或清除选择后恢复相应总体范围，避免图表指向一个年份、表格却保留另一个年份。
- **布局保持稳定。** 图表与表格的标题、内容区对齐；加载、选择和清除不改变弹窗位置及主要内容的位置。为读数和筛选状态预留空间，加载提示不挤占布局，不让整个内容区反复变暗或消失。内容滚动时标题和关闭按钮保持可达。
- **原位更新。** 复用图表与表格实例，图表使用 `updateSpec()`；表结构不变时，筛选通过 VTable `setRecords()` 更新完整数据，保留列宽，不反复 `updateOption()` 重建表头。表结构真正改变时才更新配置。
- **短促、同步的动效。** 图表、读数和表格都有轻量过渡。VTable 可采用约 220ms、无延迟的整体淡入（`animationAppear: { type: 'all', duration: 220, delay: 0 }`），避免逐行累积延迟。加载期间保留已呈现内容；过期请求不能回写。遵循系统“减少动态效果”设置，并在关闭时取消待执行任务和动画。

主题跟随宿主，[表格 token 与适配器](../visual-query/references/table-theme.md)统一维护默认、悬停、选中和滚动条样式；文本、表面、浮层、焦点和图表复用宿主 token；VChart 与 VTable 同步切换深浅主题，不单独硬编码浅色表头。浮层保持足够清晰，宽表在容器内部滚动；减少动态效果时直接呈现，并能停止播放中的动画，减少透明度时采用实色表面。

## 宿主提供的分析配置

宿主完成数据连接和 Builder 注册后，为分析入口提供以下信息；具体绑定函数、DOM 选择器和模块组织由宿主决定。

| 配置               | 职责                                                           |
| ------------------ | -------------------------------------------------------------- |
| 入口与就绪状态     | 绑定指标卡或图表标题，数据就绪后允许打开，保留其他交互。       |
| 数据连接与结果范围 | 复用宿主连接，覆盖完整可访问结果，明确完整范围与截止点。       |
| 当前范围与记录粒度 | 每次打开捕获已确认筛选，明确明细一行的语义。                   |
| 分析维度           | 提供真实字段、标签、类型与默认维度，仅使用当前数据支持的路径。 |
| 指标定义           | 提供聚合、附加条件、单位、格式化和分组口径。                   |
| 明细定义           | 配置唯一键、原始字段与展示格式，避免误聚合或将缺失值转为零。   |

## 证据与能力归属

- **数字能够核对。** 去重客户数不能累加每日或跨重叠分组的去重数；比率由同范围的分子分母汇总计算，不平均局部比率。零、缺失、不可比与加载失败分别表达。分批加载、Top N 或抽样表注明范围，总体指标不能由截断明细估算。
- **发现有依据。** 结论引用当前范围内真实计算的值，重要证据可在图表或表格中核对。描述变化、结构和关联，未经验证不写成原因；没有数据不补造目标、阈值或建议。相对变化明确基数定义，基期为零时说明不可比。比率从 10% 到 12% 是增加 2 个百分点，相对增幅为 20%，两者不能混用。
- **模型只总结证据。** 使用模型生成结论前，提供已计算的指标、公式、单位、范围、比较结果与有效性；模型不猜测缺失指标。保存发现文案不等于保存可重算的分析定义。
- **明细使用 VTable。** 普通记录与聚合结果选择适合的表类型；一行的语义由查询决定，表类型不自动保证原始明细。保留完整结果的访问方式，宽表允许展开。接入复用[HTML 图表与表格流程](../visual-query/references/html-integration.md)，不以普通 HTML 表冒充 VTable。
- **分析按需加载。** 打开详情后再查询所需分析，后续路径按需取数。只有口径、粒度与数据范围一致时复用已有结果，不为潜在点击预先加载全部明细。详情失败时仍能返回已可用的主页。
- **定义与呈现分层。** 需要保存、恢复、跨集成复用的指标公式、分析关系与条件归所属 DSL，由公开 Builder 操作；对话框、焦点和临时悬停归 UI。复用已有能力，缺少 DSL 支持时明确恢复边界，不以任意 HTML 回调或保存 Insight 文本代替可重算的分析定义。API 按需查阅 [VBI](../../api/vbi/SKILL.md)。

## 验收

1. 逐一检查指标与图表标题入口；采用整卡或环图中心入口时覆盖名称、数值与空白区域。检查图标常驻、没有重复打开，无后续内容时不制造可点击外观。
2. 核对总体和一个筛选范围的读数、分子分母、去重数与明细粒度；覆盖零基期、零分母、缺失、合法负值与不可比时段，发现能够由证据复算。
3. 在 crosshair 出现但远离线条和圆点的位置点击，核对 VTable 中记录的维度值；同时覆盖圆点、线段、分组菜单、清除、切换维度、Top N 外分组、滚动到最后一条与展开表格，不能只检查选中标签。
4. 验证 Enter / Space、触屏、Escape 的浮层优先关闭、焦点返回及快速关闭重开；Tab / Shift+Tab 能进入和离开 VTable 并到达关闭控件，不困在单元格中。旧结果不能覆盖新范围，详情内选择不意外修改主页。
5. 覆盖深浅主题、桌面与窄屏、正常及减少动态效果、空结果与失败重试；逐帧检查弹窗位置、表格列宽及滚动无跳动，无横向页面溢出。
