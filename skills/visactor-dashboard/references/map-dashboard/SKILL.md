# 地图 Dashboard

用地图、悬浮指标和流畅动效呈现地域关系与业务发现。

新建页面从模板出发，按以下 4 步执行。修改已有页面时，复用宿主结构，只处理相关步骤。

仅按当前任务读取所需参考，模板、公共查询与 API 资料见下方入口。

## 模板选择

按数据形态选起点，先运行模板，再替换业务数据、调整布局与视觉。

| 模板                                                                                                  | 适用场景           | 复用重点                                                                                     |
| ----------------------------------------------------------------------------------------------------- | ------------------ | -------------------------------------------------------------------------------------------- |
| [超市经营](templates/supermarket/README.md) · [HTML](templates/supermarket/template-supermarket.html) | 地域经营与层级分析 | 省市联动、趋势、排行、明细与刷新；按[超市指南](templates/supermarket/GUIDE.md)复制完整项目。 |
| [地震观测](templates/template-earthquakes.html)                                                       | 时空事件追踪       | 时间筛选、事件定位、近期动效与原始记录；取数按实际来源调整，刷新不等于新增事件。             |
| [电厂分布](templates/template-power-plants.html)                                                      | 实体分布与名录分析 | 大量点位、国家与类别筛选、实体详情及底图切换；快照不代表实时数据，底图仍需联网。             |

地震与电厂模板各自内嵌所需模块，可直接查看 HTML。模板是实现与质量基线，字段、地域资源、主题色和刷新节奏按真实业务适配。

## Step1：确定指标、范围与模板

1. 明确页面要回答的问题、展示终端和地域范围。选出核心指标，确认单位、公式、事实粒度、报告时区与比较基准。
2. 按上表选择模板，阅读 HTML 和启动说明，查看可运行页面的布局与交互。优先沿用模板的查询、筛选、刷新和清理机制。
3. 按[地图接入](references/open-street-map.md)核对地域身份、层级与坐标。发现敏感数据或地域口径问题时，按[数据源与地域口径确认](references/data-scope.md)处理。
4. 根据真实数据选择趋势、排行、构成与明细；没有历史不生成增长，没有父子关系不伪造下钻，没有依据不补造目标或事件。
5. 为有进一步分析价值的指标规划入口，按[通用指标分析](../metric-analysis/SKILL.md)确定默认问题与探索动线，按[地图分析补充](references/metric-analysis.md)处理地域范围与定位行为。

## Step2：接入数据与联动

1. 优先复用已有数据接入，其余按[数据接入判断](../server-runtime/SKILL.md#数据接入判断)选择。先验证页面加载与最小查询，再核对整体、一个地域及可用的时间范围。
2. 按 [visual-query](../visual-query/SKILL.md)完成 VBI Builder 查询 → VSeed 配置 → VChart / VTable 渲染；HTML 指标消费同一查询结果，地理底图交给地图引擎。
3. 先打通 **范围筛选 → 地图与指标联动 → 趋势或比较 → 明细下钻与返回 → 刷新及空错状态**，再扩展装饰和额外面板。
4. 按[控件与联动](references/open-street-map.md#控件与联动)区分定位、筛选和分析：相机移动不隐式修改统计范围，hover 不自动成为详情条件。
5. 指标分析继承已确认的范围，在同一容器中连接分组、VTable 与返回路径；关闭后保留主页筛选与地图视野。
6. 复用图表实例原位更新。状态恢复、请求取消与页面销毁按[组合指南](../visual-query/references/composition.md)处理。

## Step3：组织布局与视觉

1. 以地图为主体，概览指标与重点发现形成清晰主次。按[布局](references/layout.md)安排悬浮区域，主页保持简约，深入分析在用户主动进入后展开。
2. 按 [L-Card](references/L-card.md)统一留白、玻璃材质、筛选位置与入场顺序；指标卡与可分析图表标题提供常驻小图标。
3. 根据业务选择配色、底图与空间动效，用户指定或已有页面的风格优先。模板可以重排与组合，但保留已打通的分析路径与交互质量。
4. 同时适配桌面和移动端，避免悬浮卡片遮挡地图控件、关闭按钮与明细入口。深浅主题同步作用于地图、图表、表格与分析弹窗。
5. 用户开启减少动态效果时直接呈现最终状态。一次调整一个模块，并核对筛选、定位与分析仍然可用。

## Step4：验收与交付

首次生成 Dashboard 产物时，按[验收标准](references/acceptance.md)检查。
