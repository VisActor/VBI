# OpenStreetMap 地图接入

优先沿用模板里的地图、底图与导航模块；修改入口见[适配指南](template-adaptation.md)。本篇保留接入和空间语义约束，不另建一套地图组件。

## 位置数据

- 先确定点代表地域汇总、事件还是实体。实体和事件使用稳定 ID；地域键带父级，避免同名城市混在一起。
- 核对坐标来源、坐标系和精度，统一为 WGS84 `[经度, 纬度]`，校验空值和范围。行政代表点不能当作实体或事件的实际位置，城市代表点注明精度。
- 有效但未定位的记录保留在业务统计和明细中，说明未定位数量及地图覆盖率；不借用省会或随机位置补点。
- 优先使用数据源地域编码；只有坐标时，在接入层依据明确版本与精度的边界资源进行空间匹配，未匹配记录保留并注明口径，不能根据地点描述猜归属。
- 实时事件按 ID、发生时间和修订时间识别新增或更新；刷新不重播旧事件。快照不生成实时事件，无位置的近期事件跳过空间动效。

## 接入与底图

复用同版本 MapLibre JS / CSS 与模板底图目录，来源署名保持可见。需要增加底图时按数据形态选择：

| 来源                                                | 适用与接法                                                                                              |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [OpenFreeMap](https://openfreemap.org/quick_start/) | 矢量 style：Positron 用于指标阅读，Bright / Liberty 提供更多地域与街道细节，Dark / Fiord 用于深色主题。 |
| [NASA GIBS](https://www.earthdata.nasa.gov/)        | Blue Marble 地貌栅格适合全球概览，原始瓦片最高 8 级；需要边界地名时另叠矢量层。                         |
| [EOX](https://maps.eox.at/)                         | 地形栅格适合资源分布；WMTS 注意 `{z}/{y}/{x}` 顺序、最大层级与署名。                                    |

- 默认态与故障回退分开：正常网络下加载所选底图，实际失败或超时后明示回退并提供恢复入口；用户要求离线时，内置底图可以作为正式默认态。
- 切换底图保留相机、筛选和业务图层，同步叠色、署名和加载状态。使用 `setStyle` 时在 `style.load` 重新挂载业务层，失败的资源不能标记就绪。容器变化调用 `resize()` 并按[布局](layout.md#尺寸与避让)重算避让。
- 地貌影像、hillshade 与真实三维地形分开选择。仅在需要三维地形时接 `raster-dem`、调用 `setTerrain` 并配置倾斜视角；切换样式后恢复，未加载高程不能宣称地形就绪。接法见 [MapLibre 地形示例](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)。

## 叠色与视觉还原

- 成套核对瓦片、地图 paint、边界地名、色罩、渐变、暗角与玻璃 token；只复制瓦片 URL 或保留 blur 不能还原模板观感。底图可以不同，地理辨识度、表面层次和文字可读性应一起成立。
- 地貌调色先保留山脊与海陆明暗，再统一色调，最后压暗边缘；区域选中优先描边或低透明填充，避免遮住底图细节。
- 装饰层限定在地图区并设 `pointer-events: none`，明确点标、文字和卡片层级；切底图时清除旧叠色，不对整页加滤镜。
- 底图预览从同样式、同叠色的实际地图生成，不能用单张瓦片加滤镜代替；暗角随画幅缩放。仅检查底图还原度时统一中心、地图缩放和倾斜角，业务取景按实际范围确定。

## 标记点与飞线

- 大量点位使用 GeoJSON 图层，DOM / SVG 只突出重点项；先检查默认视野的分布密度和重点辨识度，再决定是否聚类。
- 聚类与单点用数量标签、形状或描边等方式直接区分，分别说明大小与颜色含义；检查聚类是否隐藏业务关注的极端值，必要时另标重点。空间聚类不代替行政层级汇总。
- 默认全球视野以一份主要世界为阅读中心，避免重复大陆和点位占据主要可读区域；结合可见区域、缩放下限和世界副本策略取景，不盲目固定开关。跨日期线范围取最短经度跨度，定位按当前中心展开经度，避免绕远路。
- 设置提供 2D / 3D 标记点选项，所有主题默认使用 2D；3D 点标采用左上反光、底部暗边、细描边与柔和投影形成玻璃球质感，配色跟随主题，大量点位共用纹理并由地图图层批量渲染。标记样式只作用于当前页面，刷新及恢复默认时使用 2D；切换样式保留筛选、视野与选中对象。保留光晕与选中反馈，按业务调整尺寸和颜色映射；动效仅用于近期事件或选中项，不必给每个点加光柱或涟漪。Marker 负责定位，动画作用于内层。
- 飞线须有真实关系来源；采用模板投影与动画机制，端点随相机更新、跨日期线先展开经度。没有关系数据就删除连线及对应说明。

地图右下角提供简约图例，展示真实颜色分组、边界与未知值；图例颜色与标记共用主题 token。2D / 3D 标记样式切换同步图例点形，窄屏换行，避让地图控件和分析面板。

## 控件与联动

- 地域选项多时复用可搜索选择器，支持方向键、Enter、Escape、焦点返回和外部关闭，浮层避开视口边缘。
- 明确每个入口是定位、筛选还是详情：地域排行通常联动筛选与定位；实体列表与点标共用选择入口；悬停只预览，拖动只导航。图表标题进入分析，不能吞掉图元与图例原有操作。
- 全局选择通过统一入口更新 Builder，地图、指标、构成、排行和明细消费同一范围。复位地图只恢复当前范围视野；清除筛选与关闭详情各自恢复对应状态。
- 保留适用的比例尺、缩放、指北、全屏、复位、底图与动效控制，并避让卡片。暂停、页面隐藏、减少动态效果统一控制动画，地图仍可交互。
- 选中对象离开结果集时清除高亮与详情；空结果移除失效点线，保留所选地域边界、视野与空态。刷新和主题切换不隐式重置范围或相机。
- 数据或展示层级变化才更新点集，选择变化只更新高亮，相机移动只更新投影。请求取消、过期结果与卸载清理沿用[组合指南](../../visual-query/references/composition.md)。

地名标注使用统一的轻量英文样式，国家名采用常规字重、小字号与适度字距，颜色随底图明暗保持可读；同一地名只显示一行。矢量底图的供应商地名层在克隆后隐藏，由页面共享地名层呈现，避免双语重复、粗体和强描边；保留底图原始资源。
