# 验收标准

首次生成 Dashboard 产物时，打开实际页面，按下面几方面检查。既看首屏，也动手筛选、定位和打开分析面板，看看变化后的页面是否仍然清楚、舒服。

## 整体布局

- 一眼能看出地图是主角，也能找到核心指标和重点发现。地图要留出一整块能看、能操作的区域，不能被卡片挤成一条缝。
- 默认按左侧概览、底部分析的 L 形布局摆放。两区各用一个完整容器，里面再放卡片；边缘对齐、间距一致，不零零散散地飘在地图上。用户指定布局时按用户要求检查。
- 按 [L-Card](L-card.md)保留四周留白，底部来源和状态收成一行，不另占一大块空间。首屏没有无关的 LOGO、占位标题或模板残留文案。

## 地图表现

- 初始视野能看清当前地域和主要数据，定位后目标落在露出的地图区域里，不藏在左栏、底栏或弹窗后面。
- 点位、区域和选中状态容易分辨，大小、颜色有明确含义；底图有细节，但不能比业务数据更抢眼。图例和必要说明能找到、看得清。
- 地图标签、提示框和控件不互相压住；缩放后仍能辨认重点，点位密集时也不糊成一片。来源署名保留可见。

## 卡片与文字

- 玻璃容器能透出一点地图纹理，有柔和的模糊、反光和阴影，不用粗边框。里面的小卡片只做轻微层次，不一层层叠毛玻璃。
- 标题、主数值、单位和辅助说明有清楚的大小区别。同级指标字号一致，长数字完整显示，更新时不忽大忽小。
- 文字和图表在地图明暗变化处也能读清。支持深浅主题时，底图、卡片、控件、图表、表格和弹窗一起切换，不出现一半深色、一半浅色。

## 筛选与分析

- 全局筛选集中在地图右上角，刷新和设置紧随其后，标题放在控件组下方。控件样式统一，当前选项一眼可见；下拉展开不挤动页面，也不被卡片裁掉。
- 趋势、排行和构成图有足够的展示空间，坐标、图例和标签不挤在一起。颜色含义前后一致，明细列对齐，长内容可以滚动查看。
- 可分析的指标和图表标题旁有常驻的小入口。打开后标题、当前范围、返回和关闭按钮清楚可见，提示框不被弹窗挡住；关闭后回到原来的筛选和地图视野。

## 加载与动效

- 首次加载有明确提示，就绪后平稳进入主屏，不先闪出空卡片或错位图表。加载失败能看到原因和重试入口，空结果也有说明。
- L 形布局按 [L-Card](L-card.md)先左栏、再底栏平稳翻开，之后标题、控件和页脚淡入；同一容器里的内容一起出现，不让每个小块各翻各的。
- 筛选和刷新时数字、图表平滑更新，卡片不跳位，也不重播整页入场。地图不突然飞走，空间动效不挡住读数；开启减少动态效果时直接显示最终状态。

## 小屏与遮挡

- 宽屏、较矮的桌面窗口和手机宽度都看一遍。窄屏放不下时改成纵向排列，地图保留独立高度，卡片和图表不硬挤、不压扁。
- 筛选器可以换行，长列表和表格可以滚动，页面整体不横向溢出。地图操作、分析入口、返回和关闭按钮始终够得着。
- 实际走一遍筛选、定位、下钻返回和刷新，确认地图、指标与明细显示的是同一范围；分析联动按[地图场景验收](metric-analysis.md#地图场景验收)检查。
