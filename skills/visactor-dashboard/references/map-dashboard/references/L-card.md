# L-Card

采用左侧概览、底部分析的 L 形布局时，两区各用一个完整玻璃容器，Card 放在容器里面。

- 页面顶部、左右各留 `20px`，底部留 `28px`。底部空间只放一行居中的 footer，不再叠加间距；文案保留数据来源、必要状态和署名，窄屏可横向滚动。
- 不放左上角 LOGO 和名称占位。左侧容器贴齐顶部留白，所有全局筛选集中在地图区右上角并贴齐右侧留白，刷新和设置图标紧随其后；放不下就靠右换行，不散落到标题旁或地图各处。
- 顶部控件共用一套玻璃样式，并跟随深浅主题，高约 `32px`、字约 `11px`，不加边框和投影；少量选项平铺成组，多选项才用下拉，选中态用柔和底色区分。刷新只显示图标，保留提示和键盘焦点。地图标题在控件组下方，缩放和复位可留在地图边缘。
- 先让左侧容器、底部容器依次平稳翻开，无回弹；两者完成后，标题、控件和 footer 再一起淡入。等待期间控件不可点击或聚焦，刷新和筛选不重播；开启减少动态效果时直接显示。

## 玻璃与内容

外层采用透明玻璃、约 `14px` 的背景模糊、柔和阴影和淡淡反光，不描边；默认圆角 `20px`、内边距 `10px`。浅色用白色透光，深色用蓝黑透光，保留背后的地图纹理。材质和文字颜色统一使用宿主的深浅主题 token，布局组件不各自硬编码 UI 颜色。

内层 Card 用低透明度渐变增加层次，默认圆角 `13px`、间距 `8px`，不重复叠加毛玻璃。左侧按指标关系组织概览与重点记录，卡片数量由分析内容决定。底部分析 Card 放在同一个容器里，长内容在内层滚动。

底图只展示适合当前深浅主题的选项；切换主题时保留兼容底图，否则匹配同主题底图。入口统一放在右上角设置图标内，复用宿主主题和底图管理能力，保留业务图层。默认外观与是否持久化由任务决定；恢复外观默认值不清空筛选或地图视野。地形明暗反差较大时，仅增强玻璃底色遮罩，保留模糊、反光和柔和阴影。不支持透明效果时使用实色背景。标题、指标和图表随所属容器一起翻开，不给每个小块另做翻转。入场结束后清理临时动画资源。

左栏展示真实指标、单位和当前范围，底栏按需要放构成、排行、趋势或明细，不补造数据。每个指标 Card 与图表名称右侧提供常驻小图标，点击进入[地图指标深入分析](metric-analysis.md)对话框，初始化与窄屏布局见[布局](layout.md)。验收时检查边距、筛选聚合、入场顺序、键盘操作和窄屏溢出。
