# VBI 核心能力

VBI 通过 DSL 描述可保存、恢复和复用的 BI 状态，通过 Builder 完成领域操作，核心能力可脱离 UI 使用。使用默认实例 `VBI`，或通过 `createVBI()` 创建具有独立图表、洞察资源表的实例。

| 能力       | 核心说明                                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据接入   | 注册 Connector，以 `discoverSchema()` 提供字段信息、`query()` 执行查询；图表通过 `connectorId` 关联数据源。                                                    |
| 图表配置   | 管理维度、指标、别名和视觉编码；支持明细表、透视表、柱条图、折线、面积、双轴、散点、饼环图及层次、流向等图表。切换类型时自动调整编码，可查询支持和推荐的编码。 |
| 分析计算   | 支持日期粒度聚合，求和、均值、计数、去重计数、极值、中位数、分位数等指标聚合，以及维度/指标排序、结果条数限制和数值格式。                                      |
| 数据筛选   | `whereFilter` 筛选聚合前数据，`havingFilter` 筛选聚合结果；均支持嵌套 AND/OR 条件组。日期筛选支持固定范围、相对时间、当前周期和指定周期。                      |
| 仪表盘     | 组合图表和洞察组件，管理标题、描述、多断点网格布局及主题；组件通过 `chartId` / `insightId` 引用资源。                                                          |
| 洞察文本   | 通过 `setContent()` 管理调用方提供的分析结论或说明，可独立保存并在仪表盘中复用。                                                                               |
| 资源复用   | 图表和洞察具有 UUID；支持注册、查找、列出、注销和快照导出。通过实例创建的图表、洞察 Builder 自动注册为资源。                                                   |
| 状态与协作 | 导出 JSON DSL、从 DSL 恢复 Builder；基于 Yjs 支持变更订阅、撤销/重做、状态更新导出与合并。持久化存储和协作传输由应用接入。                                     |
| 展示与扩展 | 支持图表主题、语言和仪表盘主题；可替换查询与可视化 DSL 适配器，对接自定义查询和渲染链路。                                                                      |

默认图表链路：`build()` 导出 VBI DSL；`buildVQuery()` 生成查询 DSL；`await buildVSeed()` 经 Connector 查询后生成含数据的 VSeed DSL，再交给 VSeed 构建 VChart/VTable 配置并由渲染器展示。

使用时注意：

- 可保存的分析与布局状态放入所属 DSL，通过 Builder 修改；界面交互和具体渲染由 UI 实现。
- 保存仪表盘时同时保存引用的图表、洞察资源；仪表盘 DSL 保存资源 ID，资源内容通过 `resources.snapshot()` 导出。
- 新增仪表盘组件需提供 `layouts.lg`；布局通过组件集合的 `add` / `update` 回调提交。仪表盘与引用资源各自维护文档及撤销历史。
