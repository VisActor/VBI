      #API-Überblick

      Die aktuellen Exporte von @visactor/vbi-react sind in zwei Teile aufgeteilt:

      ModulImportpfadInhalt
      Hooks@visactor/vbi-reactuseChartType, useDimensions, useHavingFilter, useMeasures, useVBI, useVSeed, useWhereFilter
      Components@visactor/vbi-react/componentsBuilderLayout, ChartRenderer, ChartTypeSelector, FieldPanel

      Alle Hooks/Components arbeiten mit VBIChartBuilder und halten keine zusätzliche Quelle für Business-State.
