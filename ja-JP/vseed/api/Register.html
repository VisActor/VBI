      #registerCustomTheme

      説明

      カスタムテーマを登録します。

      function registerCustomTheme(key: string, themeConfig:
    | CustomThemeConfig
    | ((props: { lightTheme: CustomThemeConfig; darkTheme: CustomThemeConfig }) => CustomThemeConfig)): void

      パラメータ:

      • テーマの一意な識別子
      • テーマ設定オブジェクト、または設定オブジェクトを返す関数 関数の場合、lightTheme と darkTheme を含むオブジェクトを引数として受け取り、既存テーマを基に拡張しやすくします。

      例:

      registerCustomTheme('myTheme', { ... }); // またはライトテーマを基に変更 registerCustomTheme('myTheme', ({ lightTheme }) => ({ ...lightTheme, ... }));

      #registerDarkTheme

      説明

      ダークテーマ (Dark Theme) を登録します。 登録後、Builder.getTheme('dark') で取得できます。
