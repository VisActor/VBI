      #registerCustomTheme

      설명

      커스텀 테마를 등록합니다.

      function registerCustomTheme(key: string, themeConfig:
    | CustomThemeConfig
    | ((props: { lightTheme: CustomThemeConfig; darkTheme: CustomThemeConfig }) => CustomThemeConfig)): void

      매개변수:

      • 테마의 고유 식별자
      • 테마 설정 객체 또는 설정 객체를 반환하는 함수 함수인 경우 lightTheme와 darkTheme을 포함한 객체를 매개변수로 받아 기존 테마를 기반으로 쉽게 확장할 수 있습니다.

      예:

      registerCustomTheme('myTheme', { ... }); // 또는 라이트 테마를 기반으로 수정 registerCustomTheme('myTheme', ({ lightTheme }) => ({ ...lightTheme, ... }));
