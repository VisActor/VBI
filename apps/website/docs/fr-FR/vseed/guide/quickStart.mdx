# Démarrage rapide

**VSeed** est un DSL (langage spécifique au domaine) standardisé pour le domaine d'analyse. Simplifiez la visualisation des données grâce à une orchestration élégante des données.

<Steps>
  ### Installer

Installez la bibliothèque principale `vseed` et le moteur de rendu sous-jacent `vchart`, `vtable`.

<PackageManagerTabs command="install @visactor/vseed @visactor/vchart @visactor/vtable" />

### registre

Enregistrez les capacités et les thèmes des graphiques à l'entrée de l'application (vous ne devez le faire qu'une seule fois).

```tsx pure title="App.tsx"
import { registerAll } from '@visactor/vseed'

// Enregistrer tous les types de graphiques et thèmes intégrés
registerAll()
```

### construire

Convertissez VSeed Spec en une configuration Spec rendu via `Builder`.

```tsx pure title="logic.ts"
import { VSeed, Builder } from '@visactor/vseed'

// 1. Définir l'intention d'analyse (DSL)
const vseed: VSeed = {
  chartType: 'line', // Type de graphique
  dataset: [
    // Source de données
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
    { date: '2021', profit: 30, sales: 300 },
    /* ... */
  ],
}

// 2. Générer la Spec rendable
const spec = Builder.from(vseed).build()
```

### rendu

Transmettez le Spec généré au composant VChart pour le rendu.

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { registerAll, VSeed, Builder } from '@visactor/vseed'

registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
    }

    const spec = Builder.from(vseed).build()
    const vchart = new VChart(spec, { dom: containerRef.current })

    vchart.renderSync()
    return () => vchart.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```

## concepts de base

VSeed est conçu pour séparer **"que voulez-vous analyser"** (Spec) de **"comment dessiner le graphique"** (Spec).

### 1. VSeed DSL

L'objet de configuration principal se concentre sur les **données** et la **sémantique métier**. Vous n'avez pas à vous soucier des détails visuels tels que les axes de coordonnées et la disposition des légendes. VSeed Définit les spécifications visuelles prêtes à l'emploi en fonction du type de graphique.

```typescript
const vseed: VSeed = {
  chartType: 'line',
  dataset: [
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
  ],
  dimensions: [{ id: 'date', alias: 'Date' }],
}
```

### 2. Builder

Un moteur de conversion chargé de traduire le DSL concis en Spec VChart/VTable détaillée. Il intègre de nombreux traitements de données et spécifications visuelles.

```typescript
// Le mode Builder prend en charge les appels chaînés et pourra intégrer davantage de traitements intermédiaires.
const spec = Builder.from(vseed).build()
```

## Avancé : analyse de perspective

La puissance du VSeed réside dans l'**analyse multidimensionnelle**. Ajoutez simplement des définitions de dimensions (Dimensions) et d'mesures (Measures) pour générer des perspectives ou des combinaisons complexes.

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { register, PivotChart } from '@visactor/vtable'
import { registerAll, VSeed, Builder, ColorIdEncoding } from '@visactor/vseed'

register.chartModule('vchart', VChart)
registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
      // Définir les dimensions et les mesures
      dimensions: [{ id: 'date', alias: 'Date' }],
      measures: [
        { id: 'profit', alias: 'Profit', parentId: 'profit-group' },
        { id: 'sales', alias: "Chiffre d'affaires", parentId: 'sales-group' },
      ],
    }

    const spec = Builder.from(vseed).build()
    const tableInstance = new PivotChart(containerRef.current, spec)

    // Exemple : interaction liée
    tableInstance.on('legend_item_click', (args) => {
      tableInstance.updateFilterRules([
        {
          filterKey: ColorIdEncoding,
          filteredValues: args.value,
        },
      ])
    })

    return () => tableInstance.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```
