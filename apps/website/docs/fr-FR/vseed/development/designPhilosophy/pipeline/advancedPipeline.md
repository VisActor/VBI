# advanced Pipeline

## advanced pipeline

`advanced pipeline`Reçoit un vseed DSL, génère un VSeed avancé DSL

`advancedVSeed` est une structure de données conçue sur la base d'une syntaxe graphique, utilisée pour décrire uniformément des graphiques et des tableaux, et constitue un pont entre les bibliothèques métier et les bibliothèques de graphiques.


`advancedVSeed` lui-même est également entièrement sérialisable, il peut donc être construit dans l'environnement Node.js, transmis à la spécification pipeline via http et restitué dans le graphique frontal.
