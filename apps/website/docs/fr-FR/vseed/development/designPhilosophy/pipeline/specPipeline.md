# spec Pipeline

## spec pipeline

`spec pipeline`Recevoir un AdvancedVSeed DSL, générer une spécification

`spec` est la structure de données d'entrée de VChart ou VTable, utilisée pour décrire les éléments de configuration du graphique


`spec` lui-même ne peut pas être sérialisé, il ne peut donc pas être construit dans un environnement Node.js et ne peut être utilisé que dans un environnement de navigateur.
