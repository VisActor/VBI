## 面积图：二月到三月分类色带

已有 selector 正例：选中二月、三月，纵向铺满绘图区。沿 x 的历史边界是选中类别中心加 outerPadding（默认 4px），不是面积曲线下方，也不是完整 band 外沿。

## 散点图：无数据点的目标区域

目标矩形内没有数据点也可绘制。axisMax 指当前最终坐标轴上限，此处手动设置为 100%；它不是数据最大值 60%。TypeScript 可从 @visactor/vseed 导入 AxisBoundaryEnum.Min / Max，JSON 使用 axisMin / axisMax。

```tsx preview
import { VSeedRender } from '@components'

export default () => {
  const vseedConfig = {
  "chartType": "scatter",
  "dataset": [
    {
      "channel": "A",
      "cost": 10,
      "conversion": 0.1
    },
    {
      "channel": "B",
      "cost": 60,
      "conversion": 0.3
    },
    {
      "channel": "C",
      "cost": 130,
      "conversion": 0.6
    }
  ],
  "dimensions": [
    {
      "id": "channel",
      "encoding": "color"
    }
  ],
  "measures": [
    {
      "id": "cost",
      "encoding": "xAxis"
    },
    {
      "id": "conversion",
      "encoding": "yAxis"
    }
  ],
  "yAxis": {
    "min": 0,
    "max": 1,
    "autoFormat": false,
    "numFormat": {
      "type": "percent"
    }

  "annotationArea": {
    "range": {
      "x": {

  return <VSeedRender vseed={vseedConfig} />

```

## 散点图：成本窗口
