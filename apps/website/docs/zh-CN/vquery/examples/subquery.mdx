# From

`from` 接收一份 Query DSL，将内层查询结果作为外层输入，对应 SQL 的 `FROM (SELECT ...)`。省略 `from` 时，直接查询当前连接的数据集。

外层使用内层输出的列名或别名；每一层的筛选、聚合、排序和 limit 各自生效。数据集或物理表名由连接与编译选项指定。

## basic

内层重命名销售额，外层通过该别名选列并再次重命名，保留每一条明细记录。

```tsx preview
import { VQueryResultRender } from '@components'

  const vqueryConfig = {

  "vquery": {
    "from": {
      "select": [
        "region",
        {
          "field": "sales",
          "alias": "amount"
        }
      ]
    },
    "select": [
      "region",
      {
        "field": "amount",
        "alias": "revenue"
      }
    ],
    "orderBy": [
      {
        "field": "revenue",
        "order": "asc"
      }
    ]
  },
  "dataset": [
    {
      "region": "East",
      "store": "A",
      "sales": 10
    },
    {
      "region": "East",
      "store": "A",
      "sales": 20
    },
    {
      "region": "East",
      "store": "B",
      "sales": 40
```

## aggregation

先按类别求和，再对分组结果计算行数和最大值；外层统计的是分组结果。

```tsx preview
import { VQueryResultRender } from '@components'

export default () => {

  "description": "先按类别求和，再对分组结果计算行数和最大值；外层统计的是分组结果。",
  "schema": [
    {
      "name": "category",
      "type": "string"
    },
    {
      "name": "value",
      "type": "number"
    }
  ],
  "dataset": [
    {
      "category": "a",
      "value": 3
    },
    {
      "category": "a",
      "value": 4
    },
    {
      "category": "b",
      "value": 2
    }
  ],
  "vquery": {
    "from": {
      "select": [
        "category",
        {
          "field": "value",
          "alias": "total",
          "aggr": {
            "func": "sum"
          }
        }
      ],
      "groupBy": [
        "category"
      ]
    },
    "select": [
      {
        "field": "*",
        "alias": "groups",
        "aggr": {
          "func": "count"
        }
      },
      {
        "field": "total",
        "alias": "maximum",
        "aggr": {
          "func": "max"
        }
      }
    ]
  }
}

  return <VQueryResultRender vqueryConfig={vqueryConfig} />
}
```
