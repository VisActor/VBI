# Expression

在 `select` 中使用 `{ expr, alias }` 添加数值计算列。从简单算式开始，再使用括号、参数、函数和子查询。

## basic

销售额减去成本得到利润；expr 定义算式，alias 为结果列命名。

```tsx preview
import { VQueryResultRender } from '@components'

export default () => {
  const vqueryConfig = {
  "datasetId": "expression-basic",
  "description": "销售额减去成本得到利润；expr 定义算式，alias 为结果列命名。",
  "vquery": {
    "select": [
      "sales",
      "cost",
      {
        "expr": "sales - cost",
        "alias": "profit"
      }
    ]
  },
  "schema": [
    {
      "name": "sales",
      "type": "number"
    },
    {
      "name": "cost",
      "type": "number"
    }
  ],
  "dataset": [
    {
      "sales": 120,
      "cost": 80
    },
    {
      "sales": 90,
      "cost": 60
    }
  ]
}

  return <VQueryResultRender vqueryConfig={vqueryConfig} />
}
```

## 表达式校验与边界

`VQuery.validateExpression(expr, { parameters, columns })` 可独立校验表达式，合法时正常返回，非法时抛错；无需实例或数据集。省略 `columns` 时仅校验语法和参数绑定，传入完整 schema 时也校验字段存在且为数值类型。

`expr` 是当前输入列上的数值 SQL 表达式，必须提供输出 `alias`。支持括号、一元正负号、四则运算以及 ABS、COALESCE、NULLIF；COALESCE 和 NULLIF 接收两个参数。常量可用 `?` 和 `parameters` 绑定。字段可用标准双引号引用。

表达式按 AST 校验和编译，数值操作数按 DOUBLE 处理，数值溢出报错；NULL 传播、除零返回 NULL，输出比例 0.1 表示 10%。表达式层不混合聚合、GROUP BY 或 HAVING；通过 `from` 明确先聚合再计算、先计算再聚合，以及计算后的筛选。表达式不能引用同层新定义的别名，也不接受任意 SQL、子查询或数据库专用函数。
