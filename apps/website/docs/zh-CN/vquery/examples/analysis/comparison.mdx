# Comparison

先比较实际与目标，再比较两组转化率。目标达成率 1.2 表示 120%；转化率从 50% 到 75% 相差 25 个百分点。

## target-attainment

按同一地区和月份汇总实际销售额与目标，计算差额和目标达成率。1.2 表示达成 120%，0 表示实际销售额为 0；目标为 0 或缺失时达成率返回 NULL，缺失实际记录不自动补零。
