# spec Pipeline

## spec pipeline

`spec pipeline`Erhalten Sie eine erweiterte VSeed DSL, Ausgabe einer Spezifikation

`spec` Ist Eingangsdatenstruktur von VChart oder VTable, Konfigurationselemente, die zur Beschreibung des Diagramms verwendet werden


`spec` Es kann nicht selbst serialisiert werden, Es kann also nicht in einer Node.js-Umgebung erstellt werden, Kann nur in einer Browserumgebung verwendet werden.
