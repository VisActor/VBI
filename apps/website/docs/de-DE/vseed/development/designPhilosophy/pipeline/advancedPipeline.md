# advanced Pipeline

## advanced pipeline

`advanced pipeline`Erhalten Sie eine vseed DSL, Ausgabe eines AdvancedVSeed DSL

`advancedVSeed` ist eine Datenstruktur, die auf grafischer Syntax basiert, Wird verwendet, um die Beschreibung von Diagrammen und Tabellen zu vereinheitlichen, und bildet eine Brücke zwischen dem Unternehmen und der Diagrammbibliothek


`advancedVSeed` Es ist auch für sich allein vollständig serialisierbar, damit es in einer Node.js-Umgebung erstellt werden kann, Übertragung über http an SPEC-Pipeline, Zum Front-End-Rendering-Diagramm
