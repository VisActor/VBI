# Schnellstart

**VSeed** ist eine standardisierte DSL (Domain Specific Language) für den Bereich Analytics.Erleichtern Sie die Datenvisualisierung mit eleganter Datenorchestrierung.

<Steps>
  ### Installieren

Kernbibliotheken installieren `vseed` und zugrunde liegenden Rendering-Engines `vchart`、`vtable`。

<PackageManagerTabs command="install @visactor/vseed @visactor/vchart @visactor/vtable" />

### Registrieren

Registrieren Sie Diagrammfunktionen und -themen im App-Portal (Sie müssen dies nur einmal tun).

```tsx pure title="App.tsx"
import { registerAll } from '@visactor/vseed'

// Alle integrierten Diagrammtypen und Themes registrieren
registerAll()
```

### Build

Bestanden `Builder` Konvertiert ein VSeed DSL in eine renderbare Spec-Konfiguration.

```tsx pure title="logic.ts"
import { VSeed, Builder } from '@visactor/vseed'

// 1. Analyseabsicht (DSL) definieren
const vseed: VSeed = {
  chartType: 'line', // Diagrammtyp
  dataset: [
    // Datenquelle
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
    { date: '2021', profit: 30, sales: 300 },
    /* ... */
  ],
}

// 2. Renderbare Spec erzeugen
const spec = Builder.from(vseed).build()
```

### Rendering

Übergeben Sie die generierte Spezifikation an die VChart-Komponente zum Rendern.

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { registerAll, VSeed, Builder } from '@visactor/vseed'

registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
    }

    const spec = Builder.from(vseed).build()
    const vchart = new VChart(spec, { dom: containerRef.current })

    vchart.renderSync()
    return () => vchart.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```

## Kernkonzepte

VSeed Das Gestaltungskonzept soll **"Was möchten Sie analysieren?"** (DSL) Und **"Wie man Diagramme erstellt"** (Spec) Trennen.

### 1. VSeed DSL

Kernkonfigurationsobjekte, Fokussierung auf**Daten**Und**Geschäftssemantik**。Sie müssen sich nicht um visuelle Details wie Achsen, Legendenlayout usw. kümmern. VSeed legt sofort einsatzbereite visuelle Spezifikationen basierend auf dem Diagrammtyp fest

```typescript
const vseed: VSeed = {
  chartType: 'line',
  dataset: [
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
  ],
  dimensions: [{ id: 'date', alias: 'Datum' }],
}
```

### 2. Builder

Konvertierungs-Engine, die für die Übersetzung von prägnanten DSLs in detaillierte VChart/VTable-Spezifikationen verantwortlich ist.Es verfügt über eine Vielzahl von integrierten Datenverarbeitungs- und visuellen Spezifikationen.

```typescript
// Der Builder-Modus unterstützt Kettenaufrufe und künftig weitere Zwischenschritte.
const spec = Builder.from(vseed).build()
```

## Erweitert: Perspektivische Analyse

VSeed Die Kraft der**Mehrdimensionale Analyse**。Komplexe Perspektiv- oder Kombinationsdiagramme können einfach durch Ergänzung der Dimensions- und Measures-Definitionen generiert werden.

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { register, PivotChart } from '@visactor/vtable'
import { registerAll, VSeed, Builder, ColorIdEncoding } from '@visactor/vseed'

register.chartModule('vchart', VChart)
registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
      // Dimensionen und Kennzahlen definieren
      dimensions: [{ id: 'date', alias: 'Datum' }],
      measures: [
        { id: 'profit', alias: 'Gewinn', parentId: 'profit-group' },
        { id: 'sales', alias: 'Umsatz', parentId: 'sales-group' },
      ],
    }

    const spec = Builder.from(vseed).build()
    const tableInstance = new PivotChart(containerRef.current, spec)

    // Beispiel: interaktive Verknüpfung
    tableInstance.on('legend_item_click', (args) => {
      tableInstance.updateFilterRules([
        {
          filterKey: ColorIdEncoding,
          filteredValues: args.value,
        },
      ])
    })

    return () => tableInstance.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```
