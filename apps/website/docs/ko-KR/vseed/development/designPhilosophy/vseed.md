# VSeed

:::info 한 줄 요약
위로는 비즈니스의 유연한 요구를 수용하고, 아래로는 데이터 접근 형식을 제약하여 데이터를 통일적으로 편성하고 복잡함을 단순화합니다.

## VSeed란 무엇인가? 

`VSeed`는 데이터 분석을 위한 시각화 도구로, 다양한 차트 유형 간에 높은 일관성의 데이터 변환 기능을 제공하는 데 중점을 두며, 가벼운 데이터 분석 요구를 충족하기 위해 몇 가지 즉시 사용 가능한 기능도 함께 제공합니다.

## VSeed의 장점은 무엇인가

> 우선 정말 사용하기 좋고, 다음으로 실제로 매우 유연하며, 마지막으로 VSeed 내부에는 많은 캡슐화된 기능이 있어 VSeed가 데이터를 어떻게 재구성하는지 이해해야 완벽하게 활용할 수 있습니다.

1. 가장 직관적인 차트 전환 방식 [Demo](/vseed/guide/intro/chartTypeSwitch)
2. 가장 사용하기 쉬운 피벗 차트 [Demo](/vseed/guide/intro/pivotAndCombine)
3. 강력한 데이터 재구성 능력, 어떠한 데이터 처리도 필요 없이 임의의 수량 차원, 지표, 모든 차트 유형으로 차트를 생성할 수 있습니다 [Demo](/vseed/guide/intro/dataReshape)
4. `VSeed`는 완전히 직렬화 가능하므로, 크로스 플랫폼 `VSeed DSL` 전송을 지원합니다 [Demo](/vseed/guide/intro/crossPlatformRender)
5. 즉시 사용 가능: 숫자 형식, 국제화(i18n), 라이트/다크 테마, 일반 스타일 등 [Demo](/vseed/guide/intro/internationalization)
6. 우수한 데이터 처리 성능, `Node`에서 데이터 처리를 지원하고 `Web`에서 시각화를 지원합니다 [Demo](/vseed/guide/intro/separateBuild)

## VSeed의 단점은 무엇인가

1. `VSeed`는 단일 차트의 모든 세부 사항을 다듬는 역할을 하지 않습니다. 이러한 요구는 `VChart`, `VTable`에서 제공하며, `VSeed`는 `spec`을 유연하게 수정할 수 있는 기능만 제공합니다. 사용자는 자신의 필요에 따라 차트의 모든 세부 사항을 유연하게 수정할 수 있습니다.
2. `tidyData` 규격에 부합하는 데이터셋만 `VSeed`로 시각화할 수 있습니다. 표준화되지 않은 데이터셋은 `VSeed`에서 허용되지 않습니다.
3. `VisActor` 에코시스템을 기반으로 구축되었으며, 사용자는 `VChart`와 `VTable`의 기본 개념을 이해해야 합니다.

## VSeed의 원칙은 무엇인가?

1. `VSeed`는 반드시 직렬화를 지원해야 합니다.
2. `VSeed`는 과도한 스타일 설정 기능을 제공할 필요가 없으며, 차트와 데이터 간의 관계를 처리하는 데 집중해야 합니다.
3. `VSeed`는 분석 영역에서 일반적으로 사용되는 공통 기능(숫자 형식, 국제화, 테마, 일반 스타일, 일반 기능)을 캡슐화하여 즉시 사용 가능하게 해야 합니다.
4. 더 유연한 맞춤형 요구는 사용자가 직접 커스터마이징해야 하므로, VSeed는 VChart, VTable의 spec을 구축하기 위한 Spec Builder만 외부에 제공합니다.
   - 사용자는 VChart Instance와 VTable Instance를 유연하게 제어할 수 있습니다.
   - 사용자는 자신의 필요에 따라 VChart, VTable의 spec을 유연하게 수정할 수 있습니다.


## VSeed를 설계한 이유는 무엇인가?

1. `VChart`는 `VTable`로 완전히 원활하게 전환할 수 없으며, 그 반대도 마찬가지입니다. 이러한 요구에 직면하면 상위 수준의 추상화 캡슐화가 자연스럽게 등장하게 됩니다.
2. `VChart`, `VTable`을 사용하는 사용자는 반드시 직접 데이터를 처리해야 하며, 이 작업은 무의식적으로 수백 수천 번 반복됩니다. `VSeed`는 일반적인 시나리오의 데이터 처리 복잡성을 낮추고 반복 작업을 줄이고자 합니다.
3. 어느 정도 `VChart`와 `VTable`의 사용 문턱을 낮출 수 있습니다. 예를 들어 `VTable`을 사용하여 `PivotChart`를 렌더링하는 경우입니다.
4. `VSeed`는 궁극적으로 `HeadlessBI`의 서브 모듈로 발전하여 범용 데이터 분석 도구를 구축하는 데 사용될 수 있습니다.
