# 데이터 리쉐이프 - 원리

:::info 데이터 리쉐이프
VSeed는 데이터 시각화의 진입 장벽을 더욱 낮추기 위해 범용적인 차원 리쉐이프 방법을 제안합니다.
:::

데이터 리쉐이프는 데이터를 한 구조적 형태에서 다른 구조적 형태로 변환하는 과정으로, 데이터의 무결성을 유지하면서 다양한 분석 또는 처리 요구에 맞게 데이터의 구성 방식(예: 행, 열, 인덱스, 계층)을 변경하는 것이 핵심입니다.


## 차원 리쉐이프
Python 및 R 언어에는 이미 차원 리쉐이프를 지원하는 도구가 있습니다.
1. Python Pandas는 데이터 리쉐이프를 위해 `pivot`과 `melt`를 제공합니다.
2. R tidyverse는 데이터 리쉐이프를 위해 `pivot_longer`와 `pivot_wider`를 제공합니다.


## 차원 증가와 차원 감소

차원 증가와 차원 감소는 정신적으로 범주론의 개념(객체와 사상, 그리고 동형)에 부합하지만, 구현상 엄격하게 범주론을 따르지는 않습니다.
특별히 강조:
1. 차원 증가 시 존재하지 않는 "측정값 이름"과 "측정값 값" 정보가 "무에서" 생성됩니다.
2. 차원 감소 시 데이터에 존재하는 "측정값 이름"과 "측정값 값" 정보가 "제거"됩니다.

차원 증가는 데이터를 완전히 변환할 수 있지만, 차원 열 이름에 null 값이 나타날 수 있으므로 추가 정보를 채워 넣을 수 있습니다.
차원 감소는 정보 내용이 손실되므로, 진정한 의미의 동형 변환을 달성하려면 추가적인 변환 정보 저장이 필요하며, 그렇지 않으면 정보가 반드시 손실됩니다.

## 그룹화된 차원 증가와 차원 감소

일반적인 차원 증가 및 차원 감소와 유사하게 정보 추가 또는 정보 손실 시나리오가 있습니다. 또한 그룹화 도입으로 인해 더 많은 null 데이터가 발생할 수 있습니다.
역할 및 의의:
1. 지표 그룹화: 그룹화를 통한 차원 확장으로 세부 데이터를 신속하게 처리합니다.
2. 다중 그룹 조회: 여러 SQL을 통해 여러 세부 데이터를 쉽게 가져올 수 있으며, 그룹화를 통한 차원 축소 방식으로 하나의 데이터로 병합할 수 있습니다.

## 규칙 도출

### 차원 확장

![rule](/images/ruleDataReshape.png)

![commonDataReshape2](/images/commonDataReshape2.png)

:::tip
1. 다중 지표 차원 확장 시 지표 수가 하나가 되며, 1개 지표 차원 확장 후에도 지표는 여전히 1개입니다.
2. 다중 차원 차원 확장 시 차원이 하나 더 추가되며, 0개 차원도 1개가 추가됩니다.
3. 0개 차원 1개 지표는 반복적으로 차원을 확장하여 임의의 차원과 1개 지표를 얻을 수 있습니다(따라서 하나의 지표로도 막대 차트를 그릴 수 있습니다).

:::

:::tip

2. 다중 차원 차원 축소 시 여러 차원 값이 데카르트 곱이 되어 새로운 차원이 됩니다.

:::
