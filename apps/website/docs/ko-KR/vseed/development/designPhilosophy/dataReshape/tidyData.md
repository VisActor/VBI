# TidyData

:::info 의미
TidyData는 '변수는 열로, 관측값은 행으로'라는 핵심 원칙을 통해 데이터 정제의 복잡성을 대폭 줄여, 데이터 형식 변환보다 비즈니스 문제에 더 집중할 수 있게 합니다.
:::

## 논문

논문 저자 `Hadley Wickham`, 논문은 데이터 처리의 작은 모듈인 데이터 정리에 대해 논의합니다. 깔끔한 데이터셋은 조작, 모델링 및 시각화가 용이하며 특정 구조를 가지기 때문입니다.

해당 논문은 일독을 매우 권장합니다. 참조: [Tidy Data](https://www.jstatsoft.org/article/view/v059i10)


## VSeed에서의 TidyData 활용

VSeed DSL의 `dataset` 설정은 `TidyData` 형식의 데이터셋입니다.

핵심 특징은 다음과 같습니다:
1. 각 변수는 하나의 열: 변수 값이 별도 열에 저장됩니다(예: '나이', '성별').
2. 각 관측값은 하나의 행: 각 관측 대상의 모든 변수 값이 하나의 행을 구성합니다(예: 한 사람의 나이 및 성별 정보).
3. 각 관측 단위는 하나의 테이블: 서로 다른 유형의 관측 단위(예: 사람, 시간, 장소)는 별도로 저장되어야 합니다.


따라서 `SQL` 쿼리 결과를 `VSeed`의 `dataset` 설정에 직접 전달하여 추가 데이터 처리 없이 신속하게 분석 및 시각화를 수행할 수 있습니다.
