# 애니메이션

VSeed 애니메이션 기능은 입장, 캐러셀, 분위기, 업데이트 및 퇴장 단계를 지원합니다. 아래에서는 막대 차트, 꺾은선/면적 차트, 파이 차트, 레이더 차트 및 산점도 차트의 애니메이션 예제를 함께 보여주어, 다양한 차트 유형의 구성 방식을 비교하기 쉽도록 합니다.

## 막대 차트 애니메이션

모든 예제는 대시보드 테마(다크 모드)를 기반으로 하며, 테마 목록을 제공하여 다양한 테마로 전환할 수 있습니다.
테마 목록 출처: `https://lf9-dp-fe-cms-tos.byteorg.com/obj/bit-cloud/theme.json`

### 1. 입장 애니메이션

입장 애니메이션은 차트가 처음 렌더링될 때의 애니메이션으로, 시각적 리듬을 만들고 주의를 끌기 위해 사용됩니다.
현재 막대 차트 시리즈의 입장 애니메이션은 `growth`를 지원합니다.

          marginBottom: 12,
          color: '#EAF7FF',
          background: 'rgba(0, 213, 255, 0.18)',
          border: '1px solid rgba(0, 213, 255, 0.45)',
          padding: '6px 12px',
        }}
      >
        {Object.entries(themes).map(([key, value]) => (
          <option key={key} value={key} style={{ color: '#000' }}>
            {value?.name || key}
          </option>
        ))}
      </select>
      <VSeedRender vseed={vseedConfig} />
    </div>
  )
