# Test process

VQuery was tested using the `rstest` framework. **All commands must be executed in the root directory. **

## Testing mechanism
The tests for VQuery cover:
- **Unit**: Tool functions and compiler logic.
- **examples**: Complete SQL generation and data query process.

## Common commands

### Run all tests
```bash
pnpm --filter=@visactor/vquery run test
```

### Update snapshot
If the logical changes generated by SQL are as expected, the snapshot needs to be updated:
```bash
pnpm --filter=@visactor/vquery run test:update
```

### Coverage Report
Generate and view test coverage:
```bash
pnpm --filter=@visactor/vquery run test:coverage
```
