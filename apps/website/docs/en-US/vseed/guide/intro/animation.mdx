# animation

VSeed animation capability supports entry, carousel, atmosphere, update and exit stages. Below, animation examples of column charts, line/areas, pie charts, radar charts, and scatter charts are combined and displayed to facilitate comparison of the configuration methods of different chart types.

## Column chart/bar chart animation

All examples are based on the large screen theme (dark), and a theme list is provided for switching different themes.
Topic list source: `https://lf9-dp-fe-cms-tos.byteorg.com/obj/bit-cloud/theme.json`

### 1. Entrance animation

The entry animation refers to the animation when the chart is first rendered and is used to establish visual rhythm and attract attention.
The entry animation for the current bar/bar chart series supports `growth`.
