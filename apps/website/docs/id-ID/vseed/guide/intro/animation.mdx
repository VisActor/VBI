#animasi

VSeed Kemampuan animasi mendukung tahap masuk, carousel, atmosfer, pembaruan, dan keluar. Di bawah ini, contoh animasi diagram kolom, diagram garis/area, diagram lingkaran, diagram radar, dan diagram sebar digabungkan dan ditampilkan untuk memudahkan perbandingan metode konfigurasi berbagai jenis diagram.

## Animasi bagan kolom/bagan batang

Semua contoh didasarkan pada tema layar besar (gelap), dan daftar tema disediakan untuk berpindah tema yang berbeda.
Sumber daftar topik: `https://lf9-dp-fe-cms-tos.byteorg.com/obj/bit-cloud/theme.json`

### 1. Animasi pintu masuk

Animasi entri mengacu pada animasi saat bagan pertama kali dirender dan digunakan untuk menetapkan ritme visual dan menarik perhatian.
Animasi entri untuk rangkaian diagram batang/batang saat ini mendukung `growth`.
