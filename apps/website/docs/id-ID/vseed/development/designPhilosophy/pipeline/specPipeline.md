# spec Pipeline

## spec pipeline

`spec pipeline` menerimaVSeed DSL tingkat lanjut dan mengeluarkan spesifikasi

`spec` adalah struktur data masukan dari VChart atau VTable, digunakan untuk mendeskripsikan item konfigurasi bagan


`spec` sendiri tidak dapat diserialkan, sehingga tidak dapat dibangun di lingkungan Node.js dan hanya dapat digunakan di lingkungan browser.
