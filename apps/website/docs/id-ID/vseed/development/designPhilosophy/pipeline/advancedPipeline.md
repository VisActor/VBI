# advanced Pipeline

## advanced pipeline

`advanced pipeline` menerima vseed DSL dan menghasilkan outputVSeed DSL tingkat lanjut

`advancedVSeed` adalah struktur data yang dirancang berdasarkan sintaksis grafis, digunakan untuk mendeskripsikan bagan dan tabel secara seragam, dan merupakan jembatan antara perpustakaan bisnis dan bagan.


`advancedVSeed` sendiri juga sepenuhnya dapat diserialkan, sehingga dapat dibangun di lingkungan Node.js, dikirimkan ke pipeline spesifikasi melalui http, dan dirender ke bagan front-end.
