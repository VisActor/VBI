# データリシェイプ - 原理

:::info データリシェイプ
VSeed は汎用的なディメンションリシェイプ方法を提案し、データ可視化のハードルをさらに下げることを目指します。
:::

データリシェイプとは、データをある構造化形式から別の構造化形式へ変換するプロセスです。中核は、データの完全性を保ちながら、異なる分析や処理の要件に合わせてデータの組織方法（行、列、インデックス、階層など）を変えることにあります。


## ディメンションリシェイプ
Python と R には、すでにディメンションリシェイプをサポートするツールがあります。
1. Python Pandas は `pivot` と `melt` によるデータリシェイプを提供します。
2. R tidyverse は `pivot_longer` と `pivot_wider` によるデータリシェイプを提供します。


## 次元上げと次元下げ

次元上げと次元下げは、思想としては圏論の考え方（対象と射、および同型）に沿っていますが、実装として厳密に圏論に従うものではありません。
特に強調すべき点:
1. 次元上げでは、存在しない「メジャー名」と「メジャー値」の情報を「何もないところから」作成します。
2. 次元下げでは、データ内に存在する「メジャー名」と「メジャー値」の情報を「削除」します。

次元上げはデータを完全に変換できますが、ディメンション列名に空値が発生するため、追加情報の補完をサポートします。
次元下げは情報内容を失うため、真の意味での同型変換を達成するには変換情報を追加で保存する必要があります。そうしなければ情報は必ず失われます。

## グループ化された次元上げと次元下げ

通常の次元上げと次元下げと同じく、情報の追加または情報の損失が発生する場面があります。さらにグループの導入により、より多くの空データが発生します。
役割:
1. メジャーグループ化：グループ化された次元上げによって、明細データをすばやく処理できます。
2. 複数グループのクエリ：複数の SQL によって複数の明細データを簡単に取得でき、それらをグループ化された次元下げの方式で 1 つのデータへ統合できます。

## ルールの導出

### 次元上げ

![rule](/images/ruleDataReshape.png)

![commonDataReshape2](/images/commonDataReshape2.png)

:::tip
1. 複数メジャーの次元上げでは、メジャー数は 1 になります。1 個のメジャーを次元上げしても、メジャーは 1 個のままです。
2. 複数ディメンションの次元上げでは、ディメンションが 1 つ増えます。0 個のディメンションでも 1 つ増えます。
3. 0 個のディメンションと 1 個のメジャーは、繰り返し次元上げでき、任意個のディメンションと 1 個のメジャーを得られます（そのため 1 つのメジャーだけでも棒グラフを描けます）。

:::

### 次元下げ

![rule](/images/ruleDataReshape2.png)

![groupedDataReshape2](/images/groupedDataReshape2.png)

:::tip
1. 複数メジャーの次元下げでは、ディメンション値とメジャーがデカルト積になり、新しいメジャーになります。
2. 複数ディメンションの次元下げでは、複数のディメンション値がデカルト積になり、新しいディメンションになります。

:::
