# アニメーション

VSeed のアニメーション機能は、入場、ローテーション、雰囲気、更新、退場などの段階をサポートします。以下では縦棒、折れ線/面、円、レーダー、散布図のアニメーションサンプルをまとめて示し、異なるチャートタイプの設定方法を比較しやすくしています。

## 縦棒/横棒グラフのアニメーション

すべてのサンプルは大画面テーマ（ダーク）を基にしており、異なるテーマへ切り替えるためのテーマリストを提供します。
テーマリストの出典：`https://lf9-dp-fe-cms-tos.byteorg.com/obj/bit-cloud/theme.json`

### 1. 入場アニメーション

入場アニメーションとは、チャートが初めてレンダリングされるときのアニメーションです。視覚的なリズムを作り、注意を引くために使います。
現在、縦棒/横棒系列の入場アニメーションは `growth` をサポートします。
