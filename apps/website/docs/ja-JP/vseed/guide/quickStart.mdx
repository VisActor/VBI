# クイックスタート

**VSeed** は分析領域向けの標準化 DSL（ドメイン固有言語）です。洗練されたデータ編成により、データ可視化をシンプルにします。

<Steps>
  ### インストール

コアライブラリ `vseed` と下位レンダリングエンジン `vchart`、`vtable` をインストールします。

<PackageManagerTabs command="install @visactor/vseed @visactor/vchart @visactor/vtable" />

### 登録

アプリケーションのエントリでチャート機能とテーマを登録します（一度だけ実行すれば十分です）。

```tsx pure title="App.tsx"
import { registerAll } from '@visactor/vseed'

// すべての組み込みチャートタイプとテーマを登録
registerAll()
```

### 構築

`Builder` を通じて VSeed DSL をレンダリング可能な Spec 設定へ変換します。

```tsx pure title="logic.ts"
import { VSeed, Builder } from '@visactor/vseed'

// 1. 分析意図 (DSL) を定義
const vseed: VSeed = {
  chartType: 'line', // チャートタイプ
  dataset: [
    // データソース
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
    { date: '2021', profit: 30, sales: 300 },
    /* ... */
  ],
}

// 2. レンダリング用 Spec を生成
const spec = Builder.from(vseed).build()
```

### レンダリング

生成された Spec を VChart コンポーネントに渡してレンダリングします。

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { registerAll, VSeed, Builder } from '@visactor/vseed'

registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
    }

    const spec = Builder.from(vseed).build()
    const vchart = new VChart(spec, { dom: containerRef.current })

    vchart.renderSync()
    return () => vchart.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```

</Steps>

## 中核概念

VSeed の設計思想は、**「何を分析したいか」** (DSL) と **「どのようにチャートを描画するか」** (Spec) を分離することです。

### 1. VSeed DSL

中核となる設定オブジェクトで、**データ**と**業務セマンティクス**に集中します。座標軸や凡例レイアウトなどの視覚的な詳細を意識する必要はありません。VSeed はチャートタイプに応じて、すぐ使える視覚仕様を設定します。

```typescript
const vseed: VSeed = {
  chartType: 'line',
  dataset: [
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
  ],
  dimensions: [{ id: 'date', alias: '日付' }],
}
```

### 2. Builder

変換エンジンであり、簡潔な DSL を詳細な VChart/VTable Spec へ変換します。多くのデータ処理と視覚仕様を内蔵しています。

```typescript
// Builder モードはチェーン呼び出しに対応し、今後さらに中間処理を拡張します。
const spec = Builder.from(vseed).build()
```

## 応用：ピボット分析

VSeed の強みは**多次元分析**にあります。ディメンション（Dimensions）とメジャー（Measures）の定義を補うだけで、複雑なピボットチャートや組み合わせチャートを生成できます。

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { register, PivotChart } from '@visactor/vtable'
import { registerAll, VSeed, Builder, ColorIdEncoding } from '@visactor/vseed'

register.chartModule('vchart', VChart)
registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
      // ディメンションとメジャーを定義
      dimensions: [{ id: 'date', alias: '日付' }],
      measures: [
        { id: 'profit', alias: '利益', parentId: 'profit-group' },
        { id: 'sales', alias: '売上', parentId: 'sales-group' },
      ],
    }

    const spec = Builder.from(vseed).build()
    const tableInstance = new PivotChart(containerRef.current, spec)

    // 例: インタラクション連動
    tableInstance.on('legend_item_click', (args) => {
      tableInstance.updateFilterRules([
        {
          filterKey: ColorIdEncoding,
          filteredValues: args.value,
        },
      ])
    })

    return () => tableInstance.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```
