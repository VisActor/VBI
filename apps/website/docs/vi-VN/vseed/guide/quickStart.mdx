# Bắt đầu nhanh

**VSeed** là DSL (Ngôn ngữ dành riêng cho miền) được tiêu chuẩn hóa cho miền phân tích. Làm cho việc trực quan hóa dữ liệu trở nên đơn giản thông qua việc sắp xếp dữ liệu tinh tế.

<Steps>
### Cài đặt

Cài đặt thư viện lõi `vseed`và công cụ kết xuất cơ bản `vchart`, `vtable`.

<PackageManagerTabs command="install @visactor/vseed @visactor/vchart @visactor/vtable" />

### Đăng ký

Đăng ký các khả năng và chủ đề của biểu đồ ở lối vào ứng dụng (bạn chỉ cần thực hiện việc này một lần).

```tsx pure title="App.tsx"
import { registerAll } from '@visactor/vseed'

// 注册所有内置图表类型与主题
registerAll()
```

### Xây dựng

Chuyển đổi DSL VSeed sang cấu hình Spec có thể hiển thị thông qua `Builder`.

```tsx pure title="logic.ts"
import { VSeed, Builder } from '@visactor/vseed'

// 1. 定义分析意图 (DSL)
const vseed: VSeed = {
  chartType: 'line', // 图表类型
  dataset: [
    // 数据源
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
    { date: '2021', profit: 30, sales: 300 },
    /* ... */
  ],
}

// 2. 生成渲染配置 (Spec)
const spec = Builder.from(vseed).build()
```

###Kết xuất

Chuyển Spec đã tạo cho thành phần VChart để hiển thị.

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { registerAll, VSeed, Builder } from '@visactor/vseed'

registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
    }

    const spec = Builder.from(vseed).build()
    const vchart = new VChart(spec, { dom: containerRef.current })

    vchart.renderSync()
    return () => vchart.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```

</Steps>

## Khái niệm cốt lõi

Triết lý thiết kế của VSeed là tách biệt “những gì bạn muốn phân tích” (DSL) khỏi “cách vẽ biểu đồ” (Spec).

### 1. VSeed DSL

Đối tượng cấu hình cốt lõi tập trung vào **dữ liệu** và **ngữ nghĩa kinh doanh**. Bạn không cần phải lo lắng về các chi tiết trực quan như trục tọa độ và bố cục chú giải. VSeed đặt ra các thông số trực quan vượt trội dựa trên loại biểu đồ.

```typescript
const vseed: VSeed = {
  chartType: 'line',
  dataset: [
    { date: '2019', profit: 10, sales: 100 },
    { date: '2020', profit: 30, sales: 200 },
  ],
  dimensions: [{ id: 'date', alias: '日期' }],
}
```

### 2. Builder

Công cụ chuyển đổi, chịu trách nhiệm dịch DSL ngắn gọn thành Thông số VChart/VTable chi tiết. Nó có rất nhiều tính năng xử lý dữ liệu và thông số kỹ thuật trực quan tích hợp.

```typescript
// Builder 模式允许链式调用，未来支持更多中间处理
const spec = Builder.from(vseed).build()
```

## Nâng cao: Phân tích phối cảnh

Sức mạnh của VSeed nằm ở **phân tích đa chiều**. Chỉ cần thêm các định nghĩa về kích thước và thước đo để tạo biểu đồ phối cảnh hoặc biểu đồ kết hợp phức tạp.

```tsx
import { useRef, useEffect } from 'react'
import VChart from '@visactor/vchart'
import { register, PivotChart } from '@visactor/vtable'
import { registerAll, VSeed, Builder, ColorIdEncoding } from '@visactor/vseed'

register.chartModule('vchart', VChart)
registerAll()

const Demo = () => {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return

    const vseed: VSeed = {
      chartType: 'line',
      dataset: [
        { date: '2019', profit: 10, sales: 100 },
        { date: '2020', profit: 30, sales: 200 },
        { date: '2021', profit: 30, sales: 300 },
        { date: '2022', profit: 50, sales: 400 },
        { date: '2023', profit: 40, sales: 500 },
      ],
      // 定义维度与指标
      dimensions: [{ id: 'date', alias: '日期' }],
      measures: [
        { id: 'profit', alias: '利润', parentId: 'profit-group' },
        { id: 'sales', alias: '销售额', parentId: 'sales-group' },
      ],
    }

    const spec = Builder.from(vseed).build()
    const tableInstance = new PivotChart(containerRef.current, spec)

    // 示例：交互联动
    tableInstance.on('legend_item_click', (args) => {
      tableInstance.updateFilterRules([
        {
          filterKey: ColorIdEncoding,
          filteredValues: args.value,
        },
      ])
    })

    return () => tableInstance.release()
  }, [])

  return <div ref={containerRef} style={{ height: 300 }} />
}

export default Demo
```
